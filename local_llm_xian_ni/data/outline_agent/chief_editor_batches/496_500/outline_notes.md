# 主编知识库总纲｜通用网文写作

## 1) 主线推进与阶段节点（模板）
- **<大型事件容器>**：将**庆典、仪式、集会**（如寿宴、拜师）设计为阶段性主线容器，强制汇聚多方势力，集中引爆冲突、揭示信息、推进核心竞争（如争夺封号、名额）。**【触发条件】**：地图探索告一段落，需进行势力清算与主角地位确认时。
- **<公开竞争环节>**：在容器事件中设置**即时性、有明确奖励的竞争环节**（如临场比试、登山考验），快速决出阶段优胜者，为主角提供展示舞台并明确下一阶段核心目标。**【检查点】**：竞争规则是否清晰？奖励是否诱人且与下一阶段强相关？
- **<能力与规则展示>**：通过**顶尖强者公开演示高规格能力**（法术、意境），直观定义当前力量天花板；并借**高位者讲解**，自然完成对读者和主角的关键世界观与规则灌输。**【编辑动作】**：描述演示景象后，必须通过角色对话或内心活动点出其意义与层次。
- **<平衡打破者>**：安排**长期缺席的关键角色**（如师兄、宿敌）在节点回归，其携带的新信息、实力或立场，直接打破现有平衡，制造新的冲突焦点与成长参照。**【触发条件】**：主角地位初步稳固，需要更强大对手或更复杂人际时。
- **<极限压力考验>**：设计**越级挑战、意志威压或环境试炼**，逼迫主角在公开场合动用底牌、展示特殊特质（如免疫、悟性）或实现“道”的明悟，为实质性升级埋下伏笔。**【检查点】**：考验是否触及主角核心特质（意境、体质）？突破后是否有明确的下阶段指向？
- **<阶段收束与转场>**：节点末尾需有**仪式性收束**（赐予封号、身份）和**强制性指令**（下令下山、前往某地），并授予象征新身份的凭证，实现平滑而有力的转场。**【编辑动作】**：收束后，立即通过路人反应兑现身份提升的“爽感”，并用时间限制（如三月之期）制造新紧迫感。

## 2) 节奏结构与卡点（规则库）
- **<单章节奏模板>**：采用 **“平静铺垫 → 事件爆发 → 悬念收尾/短暂平息”** 的三明治结构。高强度冲突后必须安排“收”的环节（如调停、认输），防止情绪疲劳。
- **<信息密度调节>**：在动作/冲突场景中，穿插**角色内心活动、旁观者反应或世界观碎片**，避免纯打斗的单调。在展示性场景（如万千神通）中，用“时间流逝感”营造玄妙。
- **<张力制造与控制>**：
    - **攀爬蓄势**：用具体、可量化的困难（登X步、闯X关）积累张力。
    - **倒计时加压**：为关键决策设置明确时间限制（如半柱香）。
    - **权威降临**：在张力顶点，由至高存在出手化解，完成释放。
- **<视角运用>**：在主角专注时，**短暂切换至高位者或其他关键角色的观察视角**，提供全局信息，暗示深层谋划，并侧面烘托主角特殊性。
- **<战斗与对话节奏>**：
    - **非关键战斗留白**：展示核心变化后，可借对话快速收尾。
    - **对话如博弈**：高位者间或与神秘存在的对话应简短、充满机锋，节奏紧凑。
    - **探索与悬疑转换**：在规律性展示中，插入“异常项”，节奏立刻由平铺转为悬疑聚焦。
- **<章节衔接>**：阶段结束后，主角行动节奏应立刻加快（“直奔”），体现执行力。利用**传送阵、接引使者**等标准化设施实现地图间平滑过渡。

## 3) 章末钩子库（可直接套用）
1.  他/她，到底看到了什么？
2.  这一眼，看得XX连忙低头，沉默不语。
3.  否则的话……
4.  你是否想看看，我的（更高层次）之力？
5.  现在，是（下一阶段）！
6.  弟子，弃权！/ 弟子，便抢夺一次！
7.  你，没有成为我师兄/师姐的资格！
8.  此术，不是这样用的！
9.  你，可动心否？
10. 若只是这些，你无法获得（破格奖励）。
11. 此子心机过人/不错/有些意思。（高位者点评）
12. 这一指/这一步，乃是道之指/步。
13. 他，是第三千六百零一个！/ “多了一个！” （数量异常）
14. 一双灰色的眼睛，看了过来。/ “别来烦我！” （神秘存在现身）
15. “把你的意境，施展出来！” / “向我，进攻！” （挑衅与测试）

## 4) 冲突模板与推进套路
- **<冲突类型>**：
    - **资格/地位冲突**：回归者质疑主角“不配”，通过贬低与压制逼迫回应。
    - **资源争夺冲突**：对具体事物（宝物、灵力）的索要与拒绝，迅速升级。
    - **规则理念冲突**：围绕既有规则的理解、利用或挑战产生分歧。
    - **意志考验冲突**：高位者以威压、环境施加压力，考验主角道心。
    - **隐性博弈冲突**：表面和谐的赐予与接受下，暗含师徒间的算计与权衡。
- **<冲突推进手法>**：
    1.  **展示与回应**：一方演示，另一方以行动或言语对抗。
    2.  **旁观拱火**：第三方点评、嘲讽，激化矛盾。
    3.  **层级递进**：从言语冲突，到小规模切磋，再到底牌尽出的搏杀。
    4.  **借力打力**：主角利用环境、规则或道具，对抗无法战胜之敌。
    5.  **高位调停**：最终由现场最高权威划定边界，强行收尾。
- **<冲突收尾与转化>**：
    - **埋恨转进**：表面服软，用微表情埋下未来再战的伏笔。
    - **潜力认可**：强势方因主角表现给予复杂关注，对抗关系变质。
    - **代价预设**：调停或赐予时，明确违反规则的惩罚，为未来埋雷。

## 5) 升级/爽点/回报机制（公式）
- **<即时认可爽>**：
    - **身份认可**：在庄严仪式中获得正式名分（封号、弟子）。
    - **实力认可**：越级展示手段，令高境者侧目。
    - **潜力认可**：多次描写高位者投来赞赏、深思的目光。
- **<资源获取爽>**：
    - **破格许诺**：高位者打破常规给予额外奖励（自选神通、法宝）。
    - **保命底牌**：获得功能、规则清晰的护身法宝，增加操作空间。
    - **隐藏机缘**：从标准化奖励中，凭自身特质发现独家选项。
- **<成长预期爽>**：
    - **意境突破**：压力下对“道”的理解质变，明确指向下一大境。
    - **传承匹配**：获得与核心特质高度契合的专属传承。
    - **门槛跨越**：克服艰难但明确的门槛（如登山），过程即爽点积累。
- **<心理优越爽>**：
    - **知识/信息碾压**：展现超越现场常识的认知，获他人惊叹。
    - **身份碾压**：新身份使昔日平视者毕恭毕敬。
    - **选择权尊重**：在强者面前保有并行使最终选择权，体现独立。

## 6) 世界观/规则投放手法（边写边讲）
- **<演示讲解法>**：借**高位者演示能力**（仙术），同步讲解其原理、层级与地位。
- **<问答解惑法>**：角色A向博学的角色B提问，**权威解答中带出宏大设定**（联盟、排名）。
- **<物品承载法>**：关键物品（晶石、光华）出现，必附对其**名称、特性、来历**的介绍。
- **<考验释义法>**：设置考验时，直接说明其**名称、难度层级、危险性**，建立认知坐标。
- **<体系分级法>**：清晰抛出**力量、地域、行政的层级体系**（仙术品阶、修真国等级），勾勒立体格局。
- **<对话侧写法>**：高位者对话中的机锋，隐含**势力关系、历史恩怨**。
- **<旁观共识法>**：用大量路人的议论与反应，烘托事件/人物的**罕见与重要**。
- **<规则嵌套法>**：在大规则下，于具体事件中逐步揭示**小规则**（总门规下的七子争夺规）。
- **<设施展现法>**：描写**超大型设施**（传送阵）的规模与维护，展现文明层级。
- **<留白神秘法>**：对最高层信息（修真联盟）只做**名词化提及**，营造高远莫测感。

## 7) 人物功能与关系推进（分工）
- **<师尊/宗主>**：**规则制定者、资源分配者、最终调停者**。功能是设局、考验、认可，其本身应成为深层谜团（如分身、理念）的载体。
- **<归来师兄姐/宿敌>**：**“鲶鱼”/平衡打破者**。功能是测试主角成色，制造直接冲突，态度经历“轻视→惊讶→认可/敌视”转变。
- **<同辈竞争者>**：**直接比较对象与垫脚石**。可通过“弃权”衬托主角，或通过战斗展示主角部分实力。
- **<神秘同门/分身>**：**长线伏笔工具人与传承考验官**。表面特殊，知晓内情，以冷漠态度进行最终测试与条件谈判。
- **<敌对势力魁首>**：**外部压力源与宏大背景板**。其嚣张言行与主角方高位者对峙，将内部矛盾置于更大博弈下。
- **<见证长老/贵客>**：**权威“旁白”与气氛组**。其点评、佐证能极大提升事件逼格。
- **<工具人弟子/路人>**：**“反应器”与氛围组**。通过其敬畏、恐惧的内心戏，快速确立主角的地位与凶名。
- **<接待势力>**：**势利眼与价值衡量尺**。其超规格接待体现主角身份的外部价值，铺垫未来利益或冲突。
- **<系统功能（宗门体系）>**：**无感情的服务提供者**。提供标准化路径（任务、传送），确保世界有序运行。

## 8) 伏笔：埋点→回收（规则）
- **<显性异常埋点>**：
    - **数字异常**：在固定数量体系（如三千神通）中，让主角数出“多了一个”。
    - **色彩/理念悖论**：在全体系推崇某色（七彩）时，出现完全相反的异类（灰衣）。
- **<条件与规则埋点>**：
    - **传承附加极端条件**（如“杀戮不留活口”），预设未来道德困境。
    - **明确规则惩罚**（触犯门规法宝失效），为未来可能触规行为预设代价。
    - **设置硬性时间锁**（三月后抵达），强制推动剧情并在截止日制造事件。
- **<态度与关系埋点>**：
    - **高位者对某事轻描淡写但行动重视**，暗示深层算计。
    - **提及未现身的名字**（死去的师兄），埋下过往恩怨线。
- **<地点与物品埋点>**：
    - **新任务地点**（五级修真国）本身可关联旧怨或宝藏。
    - **授予的关键物品**（令牌、法宝）附带未明说的限制或秘密。
