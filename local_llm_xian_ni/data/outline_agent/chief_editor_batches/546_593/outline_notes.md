# 主编知识库总纲｜通用网文写作

## 1) 主线推进与阶段节点（模板库）
**核心原理**：将主线拆解为明确的、可复用的“剧情功能包”，每个节点既是目标，也是驱动剧情转向的引擎。
- **<心魔劫/瓶颈点>**：**触发条件**：角色经历重大变故、抵达新境界门槛或处于静默期。**写法**：通过强烈的心绪波动（追忆、执念、乡愁）引动内在力量失衡，作为修炼或成长的关键卡点。
- **<外力破局/契机>**：**触发条件**：内在危机（心魔、瓶颈）累积至临界点。**写法**：由外部突发事件（挑衅、战斗、特定能量注入）打破僵局，常将危机转化为融合新力量、突破瓶颈的契机。
- **<新地图入场券>**：**触发条件**：主角需要进入更高级舞台。**写法**：① **职务空降**：被上级任命至新旧势力交织的集体，形成“权威真空”；② **资格认证**：通过破解试炼（禁制、战斗）获得令牌或认可；③ **合作邀约**：与本地势力达成交易，获得身份与引荐。
- **<静默蓄势期>**：**触发条件**：进入新环境（如空降职务）或面临集体排斥。**写法**：主角长期不表态、不行动，以沉默积蓄矛盾压力。**检查点**：需穿插对手的不断挑衅与内部人员的焦虑，持续给“沉默”加压。
- **<规则内清算>**：**触发条件**：沉默蓄势至顶点，等待“合乎规则”的出手时机。**流程模板**：摩擦点火（对手低级挑衅）→ 标杆立威（选择中级头目，依规果决制裁）→ 暴力清场（镇压嫡系反抗）→ 高阶调停（出示证据，迫使对方退让）。
- **<技术/勘探破局>**：**触发条件**：进入遗迹、洞府或面对专业难题。**写法**：将冲突转化为专业技能（禁制、阵法、推理）攻坚，实现“以巧破力”，提升逼格。
- **<回归-清算-守护>**：**触发条件**：主角离开后回归。**流程模板**：回归发现旧部受难 → 问责并武力破局（层层闯关）→ 拯救/复仇 → 安排后续（赏罚、传承）。
- **<势力博弈与转型>**：**触发条件**：主角需与一方势力建立新关系。**写法**：通过展示肌肉（实力或能力）→ 谈判 → 达成临时协议，将敌对或中立转为有限合作，解锁新地图。
- **<盛会/竞赛驱动>**：**触发条件**：需要阶段性高潮与公开表现舞台。**写法**：设置规则明确的公开比试（妖将大比、敲鼓），作为短期核心目标，凝聚矛盾与期待。
- **<修炼副本突破>**：**触发条件**：主线平缓期需进行关键升级。**写法**：进入与世隔绝的副本（监狱、血潭），在特殊规则下（杀戮复活）完成功法质变，常伴随 **<意外升维>**，触怒更高存在。

## 2) 节奏结构与卡点（规则库）
**核心原理**：通过控制信息、情绪与冲突的释放与收缩，制造有规律的阅读心跳。
- **<张弛交替铁律>**：紧张段落（心魔、战斗、破解）后必接舒缓段落（日常、清点、赶路）。**编辑动作**：检查连续三章是否同质；用“饮酒、听琴、闲谈”作为缓冲锚点。
- **<冲突同心圆>**：冲突应层级递进：内心冲突 → 小型外部冲突 → 中型集体冲突 → 引入高层调停 → 引出远期关联。避免越级跳转。
- **<信息差掌控>**：主角知晓关键信息（规则、计划）而对手和读者不知，制造悬念。**检查点**：在主角隐忍时，须通过内心活动或回忆，向读者部分揭示其目的。
- **<沉默/蓄势压强>**：主角沉默/蓄势时间越长，读者期待越强。**写法**：必须用对手的反复挑衅、旁观者的议论、环境压力的描写来持续“加压”。
- **<钩子前置与接力>**：在章节中段或结尾，提前引出下个矛盾点的关键人物或信息。**关键**：解开一个悬念时，立即抛出下一个更核心的悬念，形成连续吸引力链。
- **<视角限定>**：严格跟随主角视角。对手密谋、第三方计划仅做有限披露（如会议结果），保持主角行动的神秘性与突然性。
- **<战斗详略切换>**：非关键战斗（清杂兵）速写，重起势、收势及效果；关键战斗（BOSS战、验证战）详写，需分解为“气势对垒-见招拆招-底牌反转”多个层次。
- **<倒计时与压力恒定>**：施加明确时间限制（三天之约）或环境风险（深渊、规则抹杀），为行动增加恒定紧迫感。
- **<情绪冷却期>**：高强度情节（连胜、突破）后，必须安排主角独处、思考或低冲突日常，避免读者情绪疲劳。
- **<收放循环>**：完成一个“爆发-收获-平静”周期后，不立即进入下一冲突，转入发展线（修炼、交易）或闲笔，让节奏呼吸。

## 3) 章末钩子库（可直接调用）
**用法**：直接选用或微调后置于章节末尾，强制引发追读欲。
- **危机显现**：他眼中露出追忆，一股魔念，悄然而生。/ 一道杀机/银芒，破空而至！
- **力量异变**：力量疯狂钻入体内，而他眼中的迷茫，正缓缓消散。/ 他眼中，终于露出明悟。
- **身份揭晓**：“摘下头盔，正是那酒楼内，一脸阴沉之人！” / 他，看到了一个熟人。
- **规则宣判**：“已过十三息……”、“此轮规则，改为……！”
- **悬念质问**：“这新任统领，到底在想什么……”/ 他脑中唯一的念头，就是：为何？
- **杀机定格**：王林眼中寒芒一闪，右手如电，一把抓住了对方的脖颈。
- **交易博弈**：“我可以为你提供所有仙玉！”/ “条件，是什么？”
- **宝物现身**：她手中多出一个蜡丸，符文闪烁，“此物，名为……”
- **环境突变**：窗外妖月之中，紫光透出。/ 四周景物骤然大变！
- **强者注目**：二人目光乍一接触，彼此眼中，爆出一团精芒。/ 所有的目光，瞬间凝聚在一人身上。
- **内心抉择**：这一掌，他究竟会不会按下？/ 遗忘，还是铭记？他站在了道心的岔路口。
- **意外中断**：“受死！”一声大喝，裹挟毁灭之光，自身后骤然袭来！

## 4) 冲突模板与推进套路
**核心原理**：冲突是引擎，需标准化启动流程与升级路径。
- **<摩擦升温模板>**：无视 → 轻蔑 → 试探 → 攻击 → 集体围攻 → 规则反杀。适用于“空降立威”场景。
- **<规则反杀套路>**：对手先违规 → 主角隐忍收集证据 → 于公开场合引用规则条文制裁 → 在管理方见证下完成合法碾压。
- **<真假博弈局>**：抛出重宝（丹药、情报）→ 暗示真伪问题 → 主角通过细节推理识破 → 反将一军或夺取真正利益。
- **<盟友背刺流程>**：1. 共同克服难关；2. 短暂放松或消耗；3. 一方突袭夺宝/控制；4. 留下威胁话语或封印。
- **<旧部受难-回归清算>**：主角离开 → 旧部因弱受欺 → 主角携力回归 → 问责并武力破关救人 → 情感满足与势力巩固。
- **<修炼阻道>**：主角修炼/突破时，总有不长眼者挑衅，成为测试新力量的“木桩”与经验包。
- **<公开赌约碾压>**：权威者挑衅设赌 → 主角接下 → 以远超认知的方式轻松完成 → 当众索要赌注（肢体、尊严），完成打脸闭环。
- **<技术尊严挑衅>**：被质疑专业能力（禁制、炼丹）→ 以实际破解成果打脸，获得尊重与资格。
- **<信息茧房博弈>**：对手利用虚假“常识”设局 → 主角凭借更深层逻辑或观察识破，实现认知碾压。
- **<心理战与威慑>**：冲突不仅是武力比拼，更是气势、眼神、言语的较量，旨在瓦解对方战意与道心。

## 5) 升级/爽点/回报机制（公式库）
**核心原理**：成长需可见、可感，爽点需及时、多层。
- **<危机转化式成长>**：走火入魔的危机，因外来力量（敌对妖力）注入，反成融合新力量的契机。
- **<吸收反馈循环>**：击败敌人后，直接吸收其能量本源，形成“战斗-吸收-变强”的即时正反馈。
- **<规则爽点>**：当全员以为主角受规则束缚时，主角利用更深规则理解，发起合法且无法反驳的凌厉反击。
- **<身份地位反转>**：从被轻视的“空降者”、“弱者”，通过一次合规暴力或公开表现，逆转为令人恐惧、尊敬的“权威者”。
- **<认知升级爽>**：主角获得对世界规则、阴谋本质的更深理解，用智慧与信息差实现降维打击。
- **<资源暴富与转化>**：清点战利品获得“十倍”资源；或将海量基础资源（仙玉）通过独门法门转化为即时战力（仙晶）。
- **<隐性能力展露>**：关键时刻揭示主角早已掌握但未明示的底牌（如三千生之烙印），制造“原来他这么强”的惊喜。
- **<代价豁免对比>**：主角施展他人需付出沉重代价的神通，却显得举重若轻，形成优越感。
- **<意境与气势碾压>**：用意境、道心层面的高层次力量，碾压单纯的力量堆砌，实现不战而屈人之兵。
- **<掌控感奖励>**：冲突后不仅击败对手，更在信息、资源、生杀大权上获得完全掌控，提供终极权力爽感。

## 6) 世界观/规则投放手法（边写边讲）
**核心原理**：设定在情节中自然流淌，忌大段说明文。
- **<规则前置>**：在新情节展开前，通过主角回忆或内心活动，提前说明核心规则（如军规），使后续行为立即合理。
- **<对话揭露法>**：通过角色间问答（向知识库NPC提问）或闲聊，自然带出物品、体系、历史常识。
- **<体验教学法>**：让主角亲身体验现象（被妖力冲击）或规则（测试挑战），在过程中逐步揭示全貌。
