# 主编知识库总纲｜通用网文写作（融合最终版）

## 1) 主线推进与阶段节点（模板）
**核心原则**：主线由一系列“目标-行动-升级-新目标”的节点闭环串联，每个节点结束必须开启新悬念。
*   **<阶段目标设立>**：
    *   **触发条件**：上一核心冲突（如营救、逃亡）告一段落，主角处于安全或缓冲期。
    *   **模板选择**：
        1.  **成长突破型**：`破境渡劫`（修为+天劫）、`技能研习`（炼丹、阵法）。
        2.  **探索扩张型**：`地图转换/解锁`（通过记忆、战利品或被迫逃亡进入新图）、`资源获取`（为技能或升级搜集材料）。
        3.  **冲突解决型**：`终极任务触发`（NPC临终托付）、`旧线收束`（取回遗体、了解恩怨）。
    *   **检查点**：目标是否具体、可衡量？是否与主角核心需求（变强、复活、揭秘）相关？
*   **<目标执行与升级>**：
    *   **触发条件**：主角开始向目标行动。
    *   **推进套路**：
        1.  `信息/危机牵引`：被更高层信息或突然危机（强敌驱离）被动改变路径。
        2.  `代价破门`：为推进必须付出明确代价（分身死亡、消耗重宝）。
        3.  `意外卷入/收获`：探索中意外闯入高级别冲突，并`火中取栗`获得关键物品或信息。
        4.  `实力标定/认知升级`：通过战斗或感悟，明确当前实力定位，或获得对下一境界的全新认知。
    *   **检查点**：是否有意外转折？是否获得了超出原计划的收获或信息？主角实力或认知是否有可见提升？
*   **<节点闭环与新钩>**：
    *   **触发条件**：阶段目标达成（或失败）。
    *   **收尾动作**：
        1.  `资源整合/回报清算`：系统清点收获（物品、信息、势力关系），转化为明确资产。
        2.  `情感结算/关系推进`：完成对盟友、导师的情感回报或承诺兑现，关系升温或明确化。
        3.  `余波荡漾/仇恨升级`：通过敌方视角（魂灯碎裂、宗主震怒）展示事件影响，将个人冲突升级为势力冲突。
        4.  `新线开启/悬念前置`：从收获中解析出下一阶段线索，或由NPC直接交付新任务，无缝衔接。**必须设置一个明确的后续悬念**。
    *   **编辑指令**：检查本阶段所有伏笔是否回收或转入下一阶段。确保结尾有“闭环感”，同时抛出更强的“开环钩子”。

## 2) 节奏结构与卡点（规则库）
**核心原则**：张弛交替，悬念不断，在高潮点精准切割。
*   **<单元节奏模板>**：
    *   `高压-释放循环`：高强度战斗/逃遁（2-3章）→ 日常/疗伤/感悟（1-2章）→ 新的危机/探索（2-3章）。
    *   `张弛交替`：动作/渡劫场景后，必接安全区交流、整理收获的缓和段落。
    *   `三波定律`：大型危机（如天劫、兽潮）分三波来袭，一波强过一波。
*   **<具体卡点技法>**：
    1.  **悬念前置**：章节中段或结尾，提前揭示神秘现象/人物但不解释。
    2.  **情绪蓄力**：重要角色牺牲前，用遗言、交付物品等细节渲染，积蓄情绪。
    3.  **行动中断**：在成功前一刻（如抬起山峰），引入意外阻碍（神秘金锁）强行打断。
    4.  **环境倒逼**：利用空间崩溃、毒雾扩散等环境变化作为天然计时器。
    5.  **对话中断**：关键信息揭露瞬间，被战斗或意外打断。
    6.  **视角切换**：主角陷入绝境时，切至敌对势力行动线，制造时间差紧迫感。
    7.  **能力临界**：主角触摸到突破边缘，“将破未破”时断章。
    8.  **代价支付**：主角决定支付巨大代价（燃烧元神）的瞬间卡住。
    9.  **收尾悬停**：在最高潮行动（钥匙插入锁芯）完成的刹那戛然而止。
*   **<战斗节奏细分>**：
    *   `技能连招`：按“闪避→防御→控场→爆发”顺序描写，体现战术。
    *   `层次解构`：高境界战斗分四层：①规则对撞、②神通演化、③本源揭秘、④心境对抗。
    *   `速度线`：用“残影”、“音爆”等词汇反复强调速度感。
    *   `损耗可视化`：持续描写元力、伤势、法宝耐久度的消耗。
*   **<编辑检查点>**：连续三章内是否至少有1个悬念钩子？战斗描写是否超过两章未分层次？缓和章节是否过于平淡、缺少暗流？

## 4) 冲突模板与推进套路
**核心原则**：冲突需多维度、动态变化，并持续升级压力。
*   **<冲突类型库>**：
    1.  **力量对抗型**：`天人之争`（战天劫）、`降维打击`（高维存在现身）、`凶兽猎食`（原始生存冲突）。
    2.  **势力博弈型**：`势力博弈/乱斗`、`围点打援`、`资源/传承争夺`。
    3.  **心智信息型**：`信息战/欺诈`、`认知差异/冲突`、`理念立场冲突`。
    4.  **内部隐患型**：`内部隐患/猜忌`、`情感回避冲突`（因旧伤疏远）。
    5.  **环境规则型**：`环境即敌`（世界崩溃）、`规则压制`（神通禁用）。
*   **<冲突推进引擎>**：
    *   **启动**：`破坏者介入`（第三方乱入打破平衡）、`强权逼迫`（逼婚、索宝）、`误入战场`。
    *   **升级**：`代价揭示`（获胜需付沉重代价）、`信息引爆`（获知秘密导致冲突变质）、`连锁反应`（杀一人引一宗）。
    *   **转换**：`追逃转换`（逃窜中反打）、`借势造势`（利用环境或他人技能）、`祸水东引`（转移矛盾）。
    *   **解决**：`雷霆破局`（实力碾压）、`诛首恶`（斩杀核心）、`战略达成`（以阻止报信为目标）。
*   **<编辑指令>**：检查当前冲突是否至少包含两种类型？冲突解决后，是否立即有余波（敌方反应）或升级（仇恨转移）？

## 5) 升级/爽点/回报机制（公式）
**核心原则**：爽点需有层次、有代价、有认知突破。
*   **<力量升级爽点>**：
    *   `逆天改命`：从“渡劫”到“战天”，心态升华。
    *   `力量掌控`：号令天地元素，展现规则驾驭。
    *   `战力碾压/瞬杀立威`：新力量对旧敌形成纯粹碾压。
    *   `以弱创伤`：用战术对强敌造成可观伤害。
*   **<认知与格局爽点>**：
    *   `认知升级`：获知世界本质真相（如“天道已死”）。
    *   `信息差获利`：主角知真相而他人不知，掌控全局。
    *   `见证/参与历史`：推动影响世界格局的大事件。
    *   `体系降维`：用高维知识解析/碾压当前世界体系。
*   **<资源与地位爽点>**：
    *   `遗产继承/接收`：完成力量与使命的传承。
    *   `火中取栗/捡漏专家`：高端战场边缘夺取重宝。
    *   `势力尊崇`：命令得到整个族群不惜代价执行。
    *   `隐性资格认证`：获得顶级强者认可或传承资格。
*   **<情感与策略爽点>**：
    *   `计谋得逞`：复杂计谋成功，玩弄各方于股掌。
    *   `情感债结算`：完成承诺，获得心灵释然与道心巩固。
    *   `代价反转式获利`：付出代价后获得超额回报。
    *   `清理门户/道德制裁`：击败邪恶对手，赋予正义性。
*   **<爽点公式>**：明确差距（或期待）→ 展现底牌/智慧 → 付出代价 → 获得超额回报/认知提升。**必须描写旁观者的反应（震惊、呆滞）来烘托效果。**
