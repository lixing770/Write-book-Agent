# 主编知识库总纲｜通用网文写作（融合最终版）

## 1) 主线推进与阶段节点（终极模板）

**核心原则**：目标清晰，拆解执行，收放有序，节点闭环。
*   **终极目标锚定**：主角在阶段内必须有一个明确、迫切的最高目标（如归乡、复仇、结婴），所有情节向其收敛。
*   **次级目标链**：将终极目标拆解为连续、具体的次级目标（如获取地图→修复传送阵→清理外围→最终对决），形成强驱动链条。
*   **节点设计（可组合使用）**：
    *   **<场景为假/终点>**：以为抵达目标（宝藏、传承），实为陷阱或外围，需二次破解。（触发条件：探索类情节；编辑动作：在“得到”前增加一个反常细节，如能力失效、环境不匹配）
    *   **<能力失效/限制>**：依赖的核心金手指在关键场景暂时失效或受限，迫使主角用基础能力或环境特性破局。（触发条件：进入特殊规则区域；编辑动作：提前1-2章暗示环境特殊性）
    *   **<环境特性利用>**：发现并利用当前场景独有的物理/神识规则，转化为战术优势。（触发条件：任何非标准战斗场景；编辑动作：在环境描写中加入1-2个可量化、可交互的特性描述）
    *   **<三方混战入场>**：主角、前期Boss、隐藏Boss三方在场，形成动态平衡，主角作为“关键变量”渔利。（触发条件：中型副本收尾或资源争夺高潮；编辑动作：确保三方目标明确且互斥）
    *   **<信息差碾压>**：主角因获得关键信息（传承记忆），看破所有算计，实现降维打击。（触发条件：涉及复杂阴谋或上古秘辛的情节；编辑动作：提前至少5章投放核心信息碎片）
    *   **<满载而归与转场>**：阶段末尾，必须清点收获（知识、体质、材料、法宝），形成闭环满足感，并利用新获得的能力/知识主动开启通往新场景的通道。（触发条件：任何副本/地图结束；编辑动作：列出收获清单，并使用一个新能力作为“钥匙”开门）

**阶段转换检查点**：
1.  旧地图核心目标是否已完成？
2.  是否已处理“目击者”或“知情者”（清尾）？
3.  主角是否获得了进入新地图的“钥匙”（信息、能力、道具）？
4.  新地图的短期目标（如入城、获取情报）是否已确立？
5.  是否通过“向导”或亲身体验快速建立了新地图的基础规则认知？

## 2) 节奏结构与卡点（终极规则库）

**核心心律**：张弛交替，悬念不断，钩子连环。
*   **宏观节奏（张弛交替）**：高密度战斗/算计章节（2-3章）后，必须接1-2章偏静态的成长（吸收传承）、日常（交易、赶路）或情感互动章节，调节呼吸感。
*   **单元节奏（三幕式）**：小剧情单元遵循“遭遇冲突→周旋/对抗→解决并获新信息”的结构，确保单元内完整。
*   **卡点技巧库**：
    *   **<悬崖卡点>**：章末停在“技能已吟唱”、“攻击已发出”但结果未显的瞬间。（适用：高潮战斗）
    *   **<信息差卡点>**：揭露一方底牌或真实身份，但对其具体能力/目的留白。（适用：新反派登场或阴谋揭露）
    *   **<代价卡点>**：施展需要“祭献”或“承受代价”的大招，章末点出代价，下章展效果。（适用：角色爆发）
    *   **<环境突变卡点>**：稳定环境中突然出现“空间裂缝”等异象，带压迫感的新角色登场。（适用：节奏需要陡升时）
    *   **<心理时间拉伸>**：用“不知过了多久”描述主角在混沌、吸收状态中的时间感，营造漫长与质变。（适用：重大升级或悟道）
    *   **<反杀前置>**：绝境中提前描写主角“目光闪动”、“心底冷笑”，暗示已有后手，延迟满足。（适用：被围攻或陷入陷阱）
*   **节奏加速器**：
    *   **倒计时压迫**：为主角设置明确的时间限制（如天劫倒计时、追兵将至）。
    *   **多线并行剪辑**：快速切换主角、反派、第三方势力的视角与行动，制造信息拼图与紧迫感。
    *   **速通与聚焦**：对主角已形成碾压的关卡采用“速通”一笔带过；对关键战斗进行“三段论”描写（试探、底牌对撞、胜负分晓）。

## 3) 章末钩子库（终极工具箱）
1.  就在他/她即将得手的瞬间，异变陡生！
2.  “原来，这一切都是个局。” / “你的算计，我早就看穿了。”
3.  他嘴角露出一丝冰冷的微笑，心中已然有了决断。
4.  巨大的代价，往往伴随着难以置信的力量。
5.  古老的封印，在这一刻，松动了。
6.  眼前的世界轰然破碎，露出了其后隐藏的、令人战栗的真相。
7.  无数记忆洪流席卷而来，几乎要将他的自我意识彻底淹没。
8.  一道横跨天际的空间裂缝，毫无征兆地撕裂开来。
9.  他低头看着自己全新的身躯，一股难以言喻的力量在血脉中奔涌。
10. 螳螂捕蝉，黄雀在后。而黄雀之后，还有猎手。
11. 新的地图，更强大的敌人，以及……关于这个世界本源的线索。
12. 一个冰冷的声音，自虚空传来：“你，是在找我么？”
13. 距离那个日子/最终时刻，仅剩下最后 [时间]。
14. 幕后之人看着水镜中的画面，轻轻放下了茶杯：“棋子，该动了。”
15. 所有追击者的神识同时锁定了他，而他的身影，却在下一瞬诡异地消失无踪。

**使用要诀**：钩子必须与本章核心情节强相关，是情节发展的自然结果，而非生硬拼接。

## 4) 冲突模板与推进套路（终极武器）

**核心逻辑**：冲突需有层次、有升级、有意外。
*   **基础冲突类型**：
    *   **<实力/信息碾压型>**：主角隐藏实力或掌握高阶信息，形成认知落差，瞬间反杀或智取。
    *   **<资源争夺型>**：围绕稀缺资源（宝物、地图、资格）展开多方争夺。
    *   **<生存/时间赛跑型>**：主角身负致命危机（毒、咒）或处于倒计时中，行动本身引发冲突。
    *   **<规则/理念对抗型>**：个人行为与宗门规则、世界潜规则或他人理念发生碰撞。
    *   **<情感/道德困境型>**：在血脉亲情、个人情感与复仇道义间做出残酷抉择。
*   **高级推进套路**：
    *   **<阳谋逼迫与将计就计>**：一方以巨大诱惑驱使第三方围攻目标，主角看破并利用此算计反向执行计划。
    *   **<背叛围攻与混乱阶梯>**：临时盟友反水围攻Boss→主角趁乱行动→行动引发Boss一致对外，混乱升级。
    *   **<寄生/分身/傀儡戏法>**：敌人使用分身、寄生体、傀儡制造数量压制与战术迷惑，需找出本体或核心。
    *   **<代价破门与工具反噬>**：为达成关键目标，次要角色需祭献或承受代价；或主角依赖的法宝/魔头产生反噬风险。
    *   **<环境破局/杀>**：不直接击败强敌，而是利用场景独有规则（绝灵、毒潭、空间裂缝）达成目标或杀敌。
    *   **<第三方搅局与黄雀在后>**：双方死斗时，引入更高级势力或黄雀，瞬间改变平衡。

**冲突构建检查点**：
1.  冲突双方的目标是否明确且互斥？
2.  是否利用了信息差、环境特性或规则漏洞？
3.  是否有第三方势力介入或搅局的可能？
4.  冲突解决后，是否产生了新的资源、信息或仇恨？

## 5) 升级/爽点/回报机制（终极公式）

**核心等式**：付出（冒险、算计、资源） → 可视化、多维度的回报。
*   **实力提升爽**：
    *   **公式**：越级认知/技术破解 + 实力验证战（碾压旧敌）。
    *   **操作**：凭借高阶知识看破对手根脚，并以新获得能力轻松取胜。
*   **资源获取爽**：
    *   **公式**：险中夺取/闷声发大财 + 资源连锁反应/可视化收割。
    *   **操作**：在混战中精准夺取核心遗产，战后有条不紊清点战利品并立即转化为实用资源。
*   **智力碾压爽**：
    *   **公式**：信息差全局看破 + 将计就计/规则利用。
    *   **操作**：主角知晓全局，利用敌方陷阱反向布局，四两拨千斤。
*   **情感/地位满足爽**：
    *   **公式**：旧怨清算/认知颠覆 + 旁观者震惊/势力屈服。
    *   **操作**：昔日仇敌在恐惧中被碾压，整个势力态度从轻视变为敬畏讨好。
*   **成长可视化爽**：
    *   **公式**：特殊体质进化/稀有兽宠收服 + 能力分层展示/测试。
    *   **操作**：描写肉身重组、星点浮现的过程；展示兽宠吞噬成长后的新能力。
*   **计划通爽**：
    *   **公式**：长期隐忍布局 + 多线收网，一切尽在掌控。
    *   **操作**：揭示主角所有行动均为最终目标服务，配角反应都在预料之中。

**关键原则**：每次重大升级或收获后，必须安排一场“能力验证”情节，并将新资源整合进主角的能力体系。

## 6) 世界观/规则投放手法（终极心法）

**核心心法**：边写边讲，化整为零，切忌说明。
*   **五大黄金手法**：
    1.  **<对话/闲聊解释法>**：通过角色间问答、争论、八卦，自然带出设定。解释者应带有个人目的或情绪。
    2.  **<实战/体验揭示法>**：在角色使用能力、遭遇现象、触碰规则时，通过其感受、回忆或失败代价即时解释原理。
    3.  **<记忆/典籍承载法>**：将高密度设定打包进“传承记忆”或古籍残卷中，随主角探索逐步阅读揭示。
    4.  **<环境/物品隐喻法>**：环境本身（死海、裂缝）或关键物品（丹炉、玉简）即是规则的载体，其状态、功能直接体现设定。
    5.  **<代价/限制确立法>**：任何强大效果都必须伴随清晰代价或限制，借此强力确立世界平衡规则。
*   **投放节奏**：
    *   **初期**：通过“导游式”对话和亲身体验，快速建立新地图基础认知。
    *   **中期**：在战斗、破解谜题时，结合实战揭示深层规则和力量体系。
    *   **后期**：通过高层对话、古籍、记忆碎片，揭露世界背景、历史秘辛和更高层级格局。
