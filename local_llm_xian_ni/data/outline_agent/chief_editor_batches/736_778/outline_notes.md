# 主编知识库总纲｜通用网文写作（融合增强版）

## 1) 主线推进与阶段节点（模板）
- **<地图切换驱动>**：主角通过**高调、非常规方式**进入新核心场景，立即建立特殊性。驱动模式二选一：A.**探索驱动**（寻找遗迹/资源）；B.**危机驱动**（被追杀/解决困境）。
- **<规则与目标速递>**：进入后，立即通过**角色对话、观察或现象**，快速交代新地图的**基础规则、核心资源与终极目标**（如入口条件、珍贵资源、传说宝藏）。
- **<冲突立即上门>**：入场后并非一帆风顺，立即陷入**限制性情景区**（被困、被质疑、资源遭觊觎），并迅速升级为**外部冲突**（争夺、立威、追杀）。
- **<实力验证与成长>**：通过一场**越级或势均力敌的艰苦战斗**，验证主角在新环境下的战力。战斗必须展现**手段升级**（试探→常规→底牌）并明确**付出代价**。
- **<资源与信息解锁>**：破局或战斗后，自然获得**独有资源线索**（法宝碎片、源器）并**研究战利品**，揭示新设定（如道念储物），同时通过**探索、对话或幻象**解锁世界观碎片。
- **<格局扩展与钩连>**：主线间隙，**切入其他视角**，将**过往恩怨、关键人物**与新地图主线勾连。同时，通过**高位存在自语或行为**，暗示事件背后有**跨越时代的更大阴谋**。
- **<节点转换>**：一个阶段结束（如击败BOSS、获得宝藏）后，利用 **“盟友遇险”**、 **“遗迹开启”** 或 **“强敌传送”** ，无缝切换至下一张地图或冲突漩涡，保持主线永动。
- **<编辑检查点>**：
    1.  主角进入新地图的方式是否**高光/独特**？
    2.  新地图的 **“核心规则”** 和 **“终极目标”** 是否在三章内清晰？
    3.  第一个**冲突**是否在五章内爆发？
    4.  阶段结束时，是否埋下了**勾连旧线**或**暗示更大阴谋**的钩子？

## 2) 节奏结构与卡点（规则库）
- **<张弛交替铁律>**：高强度情节（战斗、揭秘、追杀）后，必须接入**缓冲带**（疗伤、探索、交谈、感悟），用于解释设定、铺垫下文、积蓄情绪。
- **<三章一小爆>**：约每三章需安排一个**阶段性成果或冲突**（如获得关键物品、破解谜题、击败一名重要对手），维持阅读粘性。
- **<压力递进设计>**：在单一情境内设置**多重障碍**（如禁锢、假出口、追兵），或让 **环境、身体、人际** 三重压力至少维持其一，并随时间逐步加码。
- **<悬念与反转卡点>**：
    - **悬念前置**：章节开头或环节开始，先抛出一个**反常现象**或**未解之谜**。
    - **悬而不断**：发现蹊跷后，不立即解决，穿插其他行动拉长张力。
    - **反转时机**：在章节中段或末段设置**小型反转**（身份揭露、态度突变、计划外露），打破读者预期。
- **<战斗节奏分层>**：
    - **秒杀立威**：对杂鱼，用 **“一招制敌”** 或 **“气势碾压”** 快写。
    - **详写升级**：对关键战，按 **“试探-常规-底牌”** 层层升级，并穿插 **“内心分析”** 与 **“代价强调”**。
- **<信息投放节奏>**：关键世界观信息**分批投放**，拆解到 **“行动前”**、 **“过程中”**、 **“遭遇后”** 三次给出。利用 **“对话藏真”** 和 **“内心独白”** 自然释放。
- **<高潮与余波>**：高潮部分（最终对决、陷阱引爆）采用 **“延时升级”** 写法（启动→入瓮→挣扎→引爆→结果）。高潮后必须有 **“余波描写”**（影响、代价、新线索），避免情绪断崖。
- **<章末钩子公式>**：
    1.  **强敌降临式**：“一股恐怖神识，席卷天地。”
    2.  **计划启动式**：“他眼中寒光一闪，‘爆！’”
    3.  **惊悚发现式**：“那漩涡中心的眼球，缓缓转向了他。”
    4.  **悬念质问式**：“这一切，到底是……还是……？”
    5.  **转场切入式**：在新场景开启、冲突爆发前一刻掐断。

## 3) 冲突模板与推进套路（工具箱）
- **<资源争夺>**：最基础模板。一方发现宝物，另一方强行索要或抢夺。可**升级**为争夺过程中**揭示宝物关联更大秘密**。
- **<尊严与资格>**：通过 **“言语挑衅”**、 **“背景轻视”**（你不够格）引发冲突，为 **“打脸”** 铺垫情绪。
- **<信息差博弈>**：冲突核心是**认知不对等**。一方掌握全盘计划/真相，另一方靠**观察细节**（法术波动、情绪异常、知识超纲）逐步推理逼近。
- **<环境绝杀>**：将冲突场景（天劫、崩溃空间、上古禁地）转化为武器，利用 **“天地规则”** 实现越级杀伤。
- **<阳谋对决>**：向对手**公开部分计划**，利用其性格弱点（多疑、重情、贪婪）使其**明知是计也不得不入局**。
- **<盟友变局>**：临时盟友**中途翻脸**，揭露真实意图，将主角从合作者变为**棋子或障碍**。
- **<心理攻防>**：武力对抗前后，持续进行**语言攻心**，利用**信息差**（告知根基被毁、人质安危）打击对手心神，制造破绽。
- **<第三方搅局>**：当双方僵持或主角劣势时，引入**更高位、动机古怪的第三方**强行改变局势，制造祸福相依的转折。
- **<触发条件检查>**：
    1.  冲突是否**在五章内**发生？
    2.  冲突根源除了资源，是否含有 **“尊严”**、 **“信息”** 或 **“信念”** 层面？
    3.  是否设计了**利用环境**或**规则**的破局点？
    4.  冲突结果是否留下了**代价**或**后续引线**？

## 4) 升级/爽点/回报机制（公式库）
- **<越级反杀爽>**：**公式**：实力悬殊 + 智谋/环境/规则利用 + 底牌尽出 + 付出代价 = 艰难胜利。**关键**：战前渲染压迫感，战后强调代价与收获。
- **<智识碾压爽>**：**公式**：对手布设精巧 → 主角通过细节看破 → 关键节点揭露或反利用。**关键**：让读者与主角同步推理。
- **<资源获取爽>**：
    - **意外收获**：战斗/探索后，发现**未预料的重宝**（源器碎片、古神皮甲）。
    - **战利品组合**：获得A物品，恰好是炼制B神器/完成C任务的关键材料。
    - **资源复用**：早期不起眼的物品，后期成为破局王牌。
- **<成长突破爽>**：
    - **代价前置式**：承受极致痛苦（燃烧、雷劈）→ 肉身/元神淬炼 → 瓶颈松动。
    - **掠夺式**：吞噬/夺取敌人**修为精华、血脉、道念**化为己用。
    - **天劫为薪式**：引导天劫之力淬炼自身或法宝。
- **<身份与声望爽>**：
    - **名号立威**：一战之后，获**公认名号**，旁观者传播。
    - **背景无视**：对方报出来历威胁，主角**不屑一顾直接出手**。
    - **认知优越**：主角因特殊知识，对现象的理解**远超旁人**。
- **<编辑动作>**：
    1.  安排爽点间隔约 **3-5章**，避免连续平淡或疲劳。
    2.  每次获得资源后，增加 **“清点研究”** 环节，具体描述功效。
    3.  突破升级后，立即安排一场 **“实力验证”** 战斗。

## 5) 世界观/规则投放手法（“边写边讲”指南）
- **<现象导入法>**：开篇描写一个**震撼现象**（流星撞门、铁链连星），引发角色和读者对其成因的追问。
- **<对话透露法>**：在角色对话中，自然带出**地图背景、势力信息、资源情报**。注意用 **“争论”**、 **“讲解”** 形式，避免枯燥。
- **<战斗展示法>**：在战斗中，通过施展的**神通效果**、**法宝特性**，具体化力量体系概念（如道念、元力）。
- **<探索发现法>**：主角在探索环境、研究物品时，**逐步发现**新规则（如符文含义、阵法原理）。结合 **“角色推理”** 过程。
- **<遗迹即史书>**：通过对**遗迹景象**（破碎大陆、壁画、手札）的描写，展现世界历史。**高阶手法**：触发 **“幻象回溯”** ，亲历历史片段。
- **<代价阐明法>**：每当使用**禁术**或**特殊能力**时，立即阐明其**具体代价**（修为跌、元神损、宝物流），建立体系严肃性。
- **<分层揭露法>**：先揭露**物理层**（仙界破碎），再**力量层**（境界体系），最后**历史恩怨层**（上古战争、家族诅咒）。
- **<规则制约法>**：展示规则如何**切实制约行为**（如情绪波动引发奴印反噬、违规尝试遭天罚），让规则“活”过来。
- **<编辑检查点>**：
    1.  新章节引入新设定时，是否至少使用了以上**两种手法**？
    2.  设定的解释是否**融入情节**，而非作者旁白？
    3.  核心规则是否在后续情节中成为 **“胜负手”** 被验证？

## 6) 人物功能与关系推进（角色分工表）
- **<核心主角>**：**功能**：行动轴心、战力标杆、最终决策者。**关系**：所有角色关系皆围绕其展开。
- **<专业辅助>**（如禁制大师）：**功能**：提供专业知识、解锁地图、负责“提问”以引导解说。**关系**：信任，但主角需关键时刻把控方向。
- **<引路/见证者>**：**功能**：提前入场、提供部分信息、见证主角高光并强化忠诚。**关系**：从属或坚定追随。
- **<拦路/测试者>**：**功能**：制造冲突、测试主角战力极限、被击败后提供战利品与信息。**关系**：纯粹的敌对与垫脚石。
- **<高位/布局者>**：**功能**：制造悬疑困局、关注主角、暗示更大阴谋、行为难以揣测。**关系**：遥远的操控与博弈。
- **<情报/工具人>**：**功能**：携带关键情报（历史、地图）、在适当时机释放后，可退场或转化。**关系**：临时合作或利用。
- **<偏执反派>**：**功能**：被单一执念驱动（复仇、复活），行为极端，是冲突与悲剧感的稳定源。**关系**：不死不休。
- **<背景板群体>**：**功能**：通过反应（震惊、恐惧、交谈）构建场景氛围、衬托主角、补充零星世界观。**关系**：无关的旁观者。
- **<心机博弈者>**：**功能**：与主角进行心理博弈，关系在 **“合作-防备-利用”** 间动态平衡。**关系**：亦敌亦友，高度不确定。
- **<关系推进口诀>**：**关系随利益与信息变动而变**。设计 **“陌生人→盟友→潜在敌人→真相揭露后的对立者→事件后的新关系（如恩人/陌路）”** 的转化链。
