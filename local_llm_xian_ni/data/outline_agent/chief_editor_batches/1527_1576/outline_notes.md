# 主编知识库总纲｜通用网文写作（融合终版）

## 1) 主线推进与阶段节点（模板）
- **<个体到集体的升维>**：将个人恩怨（必杀令、私仇）作为导火索，完美嵌入并引爆阵营/种族/文明级的宏大冲突，使主角情感与宏观战局深度捆绑。**触发条件**：主角完成对首个关键仇敌的击杀或重创。**检查点**：敌方阵营是否因此产生整体性反应（如通缉、战争动员）。
- **<“屠神”标志性胜利>**：连续击杀或击败敌方关键高层（军师、老祖、传承者），作为阶段性胜利标志，逐步瓦解敌方组织度与士气。**编辑动作**：检查三场关键战斗是否分别展示了“智取”、“力压”、“绝杀”的不同爽感。
- **<资源/神器牵引主线>**：引入远超当前战力体系的传说级资源（神器、道果、秘境），其出现与争夺直接成为主线切换（如从战争转向更高层次探索）的核心节点。**触发条件**：当前主线冲突（如战争）陷入短暂僵局或取得阶段性胜利后。
- **<幕后黑手落子与棋局揭示>**：通过敌方领袖的布局、对话，或超然存在的介入，揭示当前战役只是更大棋局的一部分。**检查点**：1）揭示信息是否颠覆主角部分认知；2）是否立即抛出一个新的、更宏大的悬疑目标。
- **<大战收束与格局重置>**：一场重大战役结束后，必须立即描写其对“世界格局”（势力范围洗牌）与“阵营情绪”（狂热、恐惧、悲壮）的双重影响，并结算主角的核心得失（声望、代价、新目标）。**编辑动作**：要求明确列出战损清单、势力地图变动、主角获得/失去的物品清单。
- **<“失踪/蜕变”悬念制造>**：在主角声望达到顶峰时，安排其因重伤、闭关、被困秘境而“离线”，制造最大悬念。**触发条件**：主角刚完成一项决定性贡献。**检查点**：需通过多势力（敌、我、友）的不同反应来维持叙事宽度。
- **<归乡/锚点闭环>**：安排主角回归故事起点或情感核心地图（故乡、师门）。这不是简单的怀旧，而是带着满级实力重新审视过去，完成情感宣泄、成长认证，并往往触发新的悬疑（故人未死、历史真相）。**编辑动作**：检查回归途中有无设置展示成长的“刻度尺”事件（如轻松解决昔日强敌）。
- **<救赎/传承任务>**：将主线阶段性目标明确为“拯救关键人物”或“完成传承交接”。过程本身串联各方势力、揭露世界规则。**触发条件**：主角获得新力量或身份后，或旧友/师长陷入绝境时。**检查点**：拯救过程是否伴随巨大代价和认知升级。
- **<隐秘探索与信息解锁>**：将模糊的宏观悬念转化为具体的遗迹/秘境探索任务。通过“破解封印-发现实物-追溯历史”的流程，直接获取关于世界背景的核心情报。**编辑动作**：要求探索终点获得的信息必须能立即转化为驱动后续行动的明确目标或可使用的资源。

## 2) 节奏结构与卡点（规则库）
- **<情绪过山车公式>**：压抑（敌强我弱）→ 小爆发（破局/斩将）→ 再压抑（援军未至/新危机）→ 大爆发（援军至/底牌出）→ 骤停/反转（超规格力量介入/真相揭露）。**检查点**：每个情绪转折处是否有足够的描写篇幅支撑。
- **<张弛交替定律>**：高强度情节（战斗、揭秘、痛苦蜕变）之后，必须接入缓冲带（情感交流、日常插曲、喜剧调剂）。**编辑动作**：标出连续三章的高压情节，强制插入一章“缓冲章”。
- **<多线并进-高速收束>**：在大场面中，同时描写“个人对决”、“军团厮杀”、“阵法破解”、“幕后对话”多条战线，在章节末或关键剧情点迅速收束，汇聚于同一焦点（如阵法缺口、神器现身）。**触发条件**：涉及阵营级大战或大型副本攻关。
- **<技能释放的文本节奏>**：描写关键技能时，采用“蓄势（环境异象/内心决意）→ 释放（慢镜头细节/特有名词）→ 效果（群体性结果/敌人反应）→ 余波（环境破坏/规则震动）”四段式，拉长高光时刻。
- **<延迟满足与即时反馈交替>**：一边延迟解决核心悬念（“能否斩杀本尊？”），一边即时给予小规模胜利反馈（清剿杂兵、破解副阵）。**检查点**：每拖延一个核心悬念，必须给予至少两个即时爽点作为“利息”。
- **<身份/实力揭露的卡点>**：主角以新形象回归，不急于自报家门。通过敌人逐渐“认出”（手段、特征、恐惧）的过程，在其心理防线崩溃的瞬间完成确认，爽感最大化。**编辑动作**：将“他是XXX！”这句台词保留给敌方在崩溃时喊出。
- **<揭秘节奏控制>**：面对宏大历史真相，采用“主角主观推测”方式呈现。先给震撼结论画面，再以“他脑中渐渐浮现…”分段落拼凑。**禁止**大段旁白式历史讲述。
- **<静默时刻与终景定格>**：在极度喧嚣后，插入一个所有人屏息、动作凝固的瞬间（神器显现、大能降临）。或在阶段末尾，将画面定格在最具象征意义的动作上（如盘膝吸收、转身离开），形成“收尾即开头”的钩子。
- **<倒计时压力施加>**：为主角的关键行动（破阵、救人）设置隐性倒计时（身体崩溃、阵法反噬、强敌归来）。通过穿插描写痛苦和阻碍来强化紧迫感。**编辑动作**：在章节中明确写出“时间，不多了”或类似暗示。
- **<归途延宕与闲笔伏线>**：归乡/奔赴主战场路上不直接抵达，设置小型遭遇（故人被追杀、听闻传奇），既展示成长，又快速切入当前矛盾。**闲笔**需同时承担调节节奏、投放线索、引入新角色的功能。

## 4) 冲突模板与推进套路
- **<必杀令闭环>**：主角立誓必杀→遭遇阻碍（分身、护道者、地理隔绝）→使用追踪/跨界神通→完成击杀或重创。**核心**：誓言必须兑现，过程需展示“虽远必诛”的决绝。
- **<守护与突破>**：主角方守护关键点（阵法、缺口），敌方波次冲击→展示守护方牺牲→敌方投入更强力量→濒临崩溃时奇招爆发暂时守住→冲突升级为更强者对决。**检查点**：需有明确的“伤亡计数”和“阵法破损度”描写。
- **<神器/资源引诱>**：抛出无法拒绝的宝物作饵→明确规则（限次、需交换）→我方内部产生分歧→有人冒险出手→揭露陷阱或引发更高层次争夺。**关键**：饵的诱惑力必须足够大，规则需清晰。
- **<恩情与立场的两难>**：敌对阵营中有恩于主角者出面请求→主角陷入个人情感与集体利益冲突→通常选择坚守立场但表达歉意→恩人失望离去，留下未来伏笔。**编辑动作**：检查主角的“歉意”是否有具体行动体现（如不杀其部下、赠物）。
- **<阵营内奸揭露>**：在外部高压下，揭露己方（或友方）已投敌的高层叛徒。冲突从“一致对外”瞬间转为“清理门户”。**触发条件**：攻打敌方核心据点或获取关键情报时。
- **<“钓鱼”与“反钓”>**：敌方抛饵引诱我方关键人物→我方将计就计/另有高人截胡。**推进关键**：需安排一个角色（主角或军师）提前识破并部署，制造智力优越感。
- **<认知错位冲突>**：双方基于完全不同的心智水平与目标互动（一方算计机缘，一方只想玩耍），冲突源于误解与信息不对称，常产生喜剧效果。
- **<理念背叛与救赎>**：冲突源于徒弟/下属行为背离了师尊/上位者坚守的“道”。解决方式常为“师尊代偿”或“弟子赎罪”，将矛盾升华。**核心**：需清晰展现所背叛的“理念”具体为何。
- **<旧伤新痛叠加>**：内部“解除封印”的生理剧痛，与回忆带来的心理创伤同步爆发，形成内外交织的双重冲突。**描写要点**：将心理痛苦通过生理反应（幻听、幻视、心脏绞痛）外化。
- **<生存空间争夺（根本模板）>**：将具体战斗（抢阵地、宝物）与抽象的种族/文明生存空间绑定，赋予每次战斗以宏大意义。**检查点**：敌我双方领袖的动员令中，是否都提及了“生存”与“未来”。
