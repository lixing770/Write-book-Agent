## 1) 主线推进与阶段节点（模板）
**核心原则：** 主线是目标驱动的闯关游戏，需拆解为“获取-逃生-清算-重启”的循环单元，每个单元必须包含压力升级与类型转换。

| 节点模板 | 触发条件/目的 | 关键编辑动作 |
| :--- | :--- | :--- |
| **<开局：目标与关卡>** | 团队进入新地图/接受新任务。 | 1. **拆解目标**：将终极目标（如寻宝）拆为递进式关卡（层级、环境）。<br>2. **公开化**：在团队内部公开目标与分配方案，制造内部张力。<br>3. **信息解锁**：通过环境/敌人逐步解锁关键世界观。 |
| **<转折：获取即危机>** | 团队触及或获得关键物品时。 | 1. **异象引爆**：设计无法掩盖的天地异象，主动暴露位置。<br>2. **收益抉择**：立即面临分配问题，埋下背叛伏笔。<br>3. **退路封锁**：原路被更强力量封锁，迫使寻找非常规逃生路径。 |
| **<高潮：逃亡与求生>** | 退路封锁，强敌入场后。 | 1. **战力倾斜**：引入远超团队战力的追猎者。<br>2. **多重拦截**：设置“纠缠→拦截→封锁”的递进拦截网。<br>3. **底牌揭露**：在绝境中被迫使用铺垫过的终极底牌，展示代价。 |
| **<转场：地图切换>** | 逃生成功或陷入新绝境时。 | 1. **主动/被动转场**：利用道具/能力（如斩开空间）或外力（如跌入裂缝）进入规则迥异的新环境。<br>2. **状态重置**：可设计“力量尽失”、“坠入凡尘”，开启重启线。 |
| **<收官：清算与重启>** | 主角恢复实力或进入新地图后。 | 1. **执念必清**：返回原点，以压倒性实力了结过往因果，完成闭环。<br>2. **立威定调**：公开击败区域代表性强者，确立地位。<br>3. **铺路下一程**：获取关键线索，引发更高层关注，主动迈向新地图。 |

## 2) 节奏结构卡点库（规则与检查点）
**核心原则：** 张弛交替，压力有形。用倒计时、进度条和情绪曲线管理读者心跳。

| 节奏类型 | 适用场景 | 关键检查点/编辑动作 |
| :--- | :--- | :--- |
| **<探险节奏>** | 探索未知区域。 | 遵循“侦察（发现低等敌）→ 遭遇（精英战）→ 撤离（向目标点）”循环，保持紧凑。 |
| **<战斗节奏>** | 任何规模战斗。 | 设计为轮次：“试探→常规对轰→亮招牌技→逼底牌→决胜”。决胜时刻用慢镜头。 |
| **<逃亡节奏>** | 被强大敌人追逐时。 | 1. **速度差**：制造“爆发提速-力竭减速-敌迫近”的波动。<br>2. **骚扰卡点**：长时间追逃后，插入主角反向骚扰，打破沉闷。<br>3. **心理时钟**：明确标注丹药、灵石等关键资源的剩余量与消耗速度。 |
| **<压抑节奏>** | 主角陷入低谷（如力量尽失）。 | 1. **窒息开局**：详细描写无力与屈辱。<br>2. **希望微光**：立即给予一个微小但确定的希望（如发现灵眼）。<br>3. **阶梯突破**：将恢复过程设为多级小突破（凝气二层→六层），每级都是一个爽点。 |
| **<大战节奏>** | 重要BOSS战、宗门大比。 | 1. **战前静默**：用环境、对手微表情、旁观者介入拉满张力。<br>2. **先声夺人**：交手前以小动作（踏碎地面）实现气势碾压。<br>3. **解说回合**：攻防间穿插内心独白与体系说明，战斗即教学。<br>4. **围观反应**：关键节点必须插入旁观者的震惊，烘托层级。 |
| **<日常节奏>** | 高强度情节后。 | **必须插入**！内容为：疗伤、领悟、信息梳理、与情感锚点（孩童、灵兽）的温情互动。此为情绪呼吸阀。 |
| **<悬疑节奏>** | 阴谋揭露、身份谜团。 | 1. **信息挤牙膏**：关键信息通过对话、探索分多次小剂量释放。<br>2. **对话博弈**：重要对话频繁插入“目光闪动”、“内心沉吟”，拉长心理博弈。<br>3. **断章于势起**：在新冲突爆发前、新人物登场时果断切断。 |

## 4) 冲突模板与推进套路
**核心原则：** 冲突需多层次，从物理升级到心理、道德、理念层面。

| 冲突模板 | 核心驱动力 | 标准推进套路 |
| :--- | :--- | :--- |
| **<资源争夺>** | 对有限资源（宝物、洞府、名额）的占有欲。 | 觊觎 → 挑衅/设局 → 争夺战 → 胜者获取 →（可能）被更高阶掠夺。 |
| **<信息差碾压>** | 一方掌握关键信息或伪装实力。 | 弱势方隐忍 → 关键时机揭露信息/实力 → 形势瞬间逆转 → 完成碾压或反杀。 |
| **<理念/道路之争>** | 修行理念、道德立场、阵营归属的根本对立。 | 言语碰撞 → 行为冲突 → 上升至“道”的对抗（意境对决）→ 胜者否定败者之道。 |
| **<困兽之斗>** | 实力悬殊下的求生本能。 | 逃脱尝试 → 被规则/力量压制 → 利用环境/智慧周旋 → 耗尽强者耐心或等来变数。 |
| **<内部隐患>** | 团队内部的信任危机与利益分歧。 | 埋下隐患（隐瞒、暗伤）→ 危机中爆发（倒戈、失控）→ 信任破裂 → 重组或决裂。 |
| **<阳谋逼迫>** | 高阶者利用规则与势力进行降维打击。 | 下达无法拒绝的命令或赌约 → 主角明知是局仍需赴约 → 在局中寻找破绽反杀。 |
| **<身份认知>** | 对自我或他人真实身份的怀疑与揭露。 | 出现矛盾细节 → 调查与试探 → 身份揭露 → 引发情感冲击与关系重构。 |
| **<第三方搅局>** | 更强大的外力突然介入。 | 两方僵持 → 第三方入场打破平衡 → 冲突目标转移或升级为乱斗 → 主角趁乱行事。 |

## 5) 升级/爽点/回报机制（公式）
**核心原则：** 爽点必须及时兑现，回报需有形（资源）、有感（成长）、有声望（名望）。

| 爽点类型 | 触发条件 | 读者获得感 |
| :--- | :--- | :--- |
| **<认知碾压>** | 主角凭高维见识看破对手伎俩/世界规则。 | “智商优越感”。主角行动前，可让读者共享其洞察。 |
| **<以弱戏强>** | 实力悬殊下，靠智慧韧性让强者吃瘪。 | “以下克上”的情绪释放。需设计精巧的算计或韧性展示。 |
| **<融合质变>** | 不同力量体系（肉身、意境、法宝）深度融合。 | “1+1>2”的新奇感与力量美感。需详细描写融合过程与威能。 |
| **<绝境馈赠>** | 在最高压危机中，隐藏着最大机缘。 | “祸福相依”的爽感闭环。需提前铺垫危机与宝物的属性关联。 |
| **<清算快感>** | 实力恢复后，对前期欺压者进行碾压式报复。 | 压抑后的彻底宣泄。过程需果决，手段可残酷。 |
| **<万众瞩目>** | 公开场合下，成就被围观、惊叹、传播。 | 虚荣心与成就感满足。需多角度描写旁观者反应。 |
| **<权威认证>** | 被更高阶存在以平等或欣赏口吻对待并赠礼。 | 地位跃升的认可感。是侧面烘托主角潜力的重要手段。 |
| **<日常治愈>** | 血腥争斗后，描写与羁绊角色的温情互动。 | 情感补偿与节奏调剂。宜简短、细腻、有生活气息。 |
| **<战略胜利>** | 无法战胜时，成功从绝境逃脱或达成次级目标。 | “虽败犹荣”的满足感。需明确将逃脱定义为一种胜利。 |
