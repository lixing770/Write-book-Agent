# 主编知识库总纲｜通用网文写作

## 1) 主线推进与阶段节点（模板）
- **<主动破局与认知升级>**：主角核心目标必须包含“反向定义”（如为天劫降劫）或“规则对抗”（如反问资格），将被动考验变为主动试炼。在对抗中同步完成“认知跃迁”，看透现象本质（如天劫来源），实现智力碾压。**触发点**：安排主角遭遇世界级规则压迫（天劫、审判）时。
- **<阶段目标拆解与资源化>**：将宏大目标（走出洞府、杀仙尊）拆解为可执行、有时间锁的阶段性任务（守护三年、获取八滴精血）。**检查点**：每个小阶段结束时，主角是否获得了具体资源（法宝、记忆、精血）或解锁了新地图资格。
- **<世界规则交互与改写>**：主角通过关键行动（布阵、毁阵）永久性改变世界基础规则（香火限制、地域划分），将个人成长转化为世界格局变动。**编辑动作**：在主角晋级或获得重大力量后，必须设计一个“以我之名，重塑规则”的标志性事件。
- **<情感与理念锚定>**：世界观的残酷揭露必须与主角最核心的情感羁绊（亲友命运失踪）或个人理念（我命由我）强行关联，为“逆天”行为提供不可动摇的驱动力。**触发点**：在揭示世界真相（洞府论）的同一章内，揭示主角个人目标的关联性。
- **<多线汇集与终局舞台搭建>**：在最终高潮前，将所有支线人物、势力、矛盾清晰汇聚于核心战场（如罗天星域），勾勒战力对比与地理，形成“所有人都在此”的史诗舞台。**检查点**：进入终局前，是否已通过对话或视角切换，交代了所有重要角色的位置与状态。
- **<缓冲期与战略转换>**：大规模决定性战役后，必须安排“喘歇期”，主角从战略进攻转入“守护”或“消化”，同时通过敌方动员、情感线并进、新势力谈判铺设多条后续冲突线。**编辑动作**：高潮后2-3章内，必须插入时间跨度（如一年）和至少一个新势力/角色的登场。

## 2) 节奏结构与卡点（规则库）
- **<张弛波浪定律>**：节奏必须遵循“高强度战斗/揭秘（张）→ 静态独白/情感互动（弛）→ 中强度试探/展示（张）”的波浪循环。严禁连续超过三章纯战斗或纯文戏。**检查点**：每3-5章审视一次情绪曲线，确保有起伏。
- **<战斗单元分层法>**：单一战斗需分层：1）试探与信息分析；2）神通对轰与底牌互翻；3）决胜瞬间与战利品收割。群体战斗则用“神识笼罩—一掌覆灭”的快镜头。**触发点**：描写超过500字的战斗场面时。
- **<情绪蓄积与释放链>**：制造“假性崩溃”（主角疑似失败）→“寂静压迫”（配角限时等待）→“破静而出”（主角反转）的情绪链。终极释放前需将绝望感推向顶点（防线将破、信念动摇）。**编辑动作**：在高潮前，刻意安排一个己方重要角色受辱或将死的场景。
- **<信息与悬念卡点>**：在高强度情节中，以“角色惊呼”（“他是谁！”）或“画面揭示”（瞳孔收缩看到景象）方式抛出涉及世界设定的核心疑问，将胜负悬念升维为知识悬念。**章末钩子首选**。
- **<倒计时压力管理>**：使用明确数字制造紧迫感，如修真星数量、半柱香时间、三年期限。倒计时需在章节中反复提及，并显示消耗。**触发点**：任何需要凝聚紧张感的防守、等待、疗伤场景。

## 3) 章末钩子库（可直接抄）
**一、悬念揭示类：**
1.  他/她，究竟是谁？
2.  他看到了！
3.  这里是……（震撼地名）！
4.  要么这里，就是……（惊人猜测）！
5.  ……的命运，为什么不存在于这里？
6.  一个破碎的玉佩/字迹，缓缓显出，赫然是一个【仙/尊】！
7.  是左眼么？

9.  “给我滚！”

11. “有活人就好，……你的记忆，我要了。”
12. 想跑，晚了！
13. 既然来了，就别走了！
**三、宣言与挑战类：**

17. 界外之修，今日，你们一个人都不要离开了！
18. 打败我，你会知晓一切……敢，还是不敢？
19. 再迈一步，我便再杀你一次。

## 4) 冲突模板与推进套路
- **<规则对抗型>**：核心冲突是“秩序 vs 逆秩序”。主角挑战世界固有规则（被动渡劫、阶级尊卑），通过“反问资格”、“反向操作”引爆冲突。**推进**：让规则本身显化出实体（天劫太阳、天道）与主角对话或对抗。
- **<认知碾压型>**：主角因独特经历掌握高维信息（世界是洞府），与蒙在鼓内的所有角色（包括敌人、盟友）产生根本冲突。**推进**：通过私密对话向挚友揭露，利用倾听者的震撼挣扎强化冲突；或在谈判中直接道破敌方首领的虚假高位身份（“仙尊侍妃”）。
- **<镜像宿命型>**：制造与主角力量同源、招式一致的“本我镜像”或“传承竞争者”。冲突在于“自我认同”与“道路唯一性”。**破局关键**：必须智取，利用提前埋下的非力量型技能（定神术、骗道）制造细微不同步。
- **<资源争夺型>**：冲突双方目标明确汇聚于同一珍贵“物品”（天劫法宝、心头精血、传承资格）。**推进**：将物品设计为可被实时夺取、吸收的资源，战斗过程即是抢夺过程。
- **<绝境辱亲/护犊型>**：最强效的冲突催化剂。让敌方以淫邪、羞辱方式威胁主角重要女性亲属或道侣；或激发角色为保护刚刚相认的子女而燃烧生命。**触发点**：在主角看似无敌或需要爆发时使用。
- **<阵营凝聚型>**：将分散的个人仇恨，通过共同悲惨经历和主角号召，升维为统一的阵营对抗（界内vs界外）。**推进**：多用对比，描写己方同仇敌忾与敌方仓惶逃窜的镜像画面。
- **<车轮消耗型>**：反派核心策略是组织多波次、多特性的攻击（人海、凶兽、因果律），旨在逼迫主角消耗有限的终极底牌（如“两弓之力”）。**推进**：让主角逐一拆解攻势，系统性“展销”其技能库。
- **<威慑博弈型>**：冲突不在实战，而在心理与底牌较量。主角以虚弱状态展示终极威慑，迫使更强但更谨慎的敌人权衡后退却。**关键**：必须明确公示威慑武器的使用限制和剩余次数。

## 5) 升级/爽点/回报机制（公式）
- **<认知升级爽>**：主角（及读者）对世界本质的理解发生跃迁（洞府真相），是最高级的信息爽点。**手法**：通过记忆碎片、挚友对话、战斗揭秘分批投放，最后主角内心独白整合。
- **<吞噬进化爽>**：击败特定敌人后，直接将其吸收（精血、本源、元神）转化为自身核心力量的成长材料（古神星点、本源壮大），形成“打怪-即食”的直观闭环。
- **<以弱胜强智取爽>**：明确刻画主角状态不佳（重伤）、敌人强大
