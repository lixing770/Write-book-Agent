# 主编知识库总纲｜通用网文写作

---

## **1) 主线推进与阶段节点（核心模板库）**
**编辑动作**：规划章节时，从此库选取2-3个模板组合，形成“阶段目标-推进方式-节点爆点”的完整闭环。
*   **信息驱动类**
    *   **<信息递进式解锁>**：通过“遗迹文献”（日记、玉简）分层揭示核心秘密，将主角探索与历史揭露同步。**检查点**：每次信息揭露必须直接改变主角的当前目标或对世界的认知。
    *   **<锚点呼应法>**：将当前地图的终极秘密与主角早期经历中的伏笔（物品、人名、伤痕）强力绑定，实现剧情维度的收束与抬升。
    *   **<真相拼图>**：在多个独立场景（不同洞府、石像）获得信息碎片，最终在主角脑中拼合成完整背景故事（远古大战、强者阴谋）。
*   **地图探索类**
    *   **<生存-探索-解惑>三阶段**：先解决生存危机；再系统性探索环境搜集线索；最后整合信息，触及世界级谜团，完成从“求存”到“求解”的叙事升级。
    *   **<地图嵌套揭秘>**：在当前地图中，通过线索揭示更深层地图的存在与危险，并暗示其与主线核心的关联，驱动下一阶段目标。
    *   **<生态探查推进>**：将对新地图的探索，转化为对其“生态”（兽群、族群、规则）规模、层级和行为的系统性调查，调查本身即为主线推进。
*   **目标转化类**
    *   **<目标升维>**：主角进入副本的初始目标（寻宝、复仇）在探索中，被更宏大、更致命的终极目标（破解阴谋、阻止灾难）所取代，提升故事格局。
    *   **<承诺/使命倒逼>**：对盟友的公开承诺或无意继承的强者遗志，成为推动主角必须按时行动的核心驱动力。**检查点**：必须在阶段开头明确“承诺期限”。
    *   **<代价破门>**：突破核心阻碍（如石门）的瞬间，揭开更大灾难的序幕，将“得到”与“失去”绑定，制造剧情拐点。
*   **结构收束类**
    *   **<支线收束引爆>**：将多个独立支线线索通过一个核心信息点强行收束、串联，瞬间引爆剧情张力，指明最终方向。
    *   **<归途锚定>**：无论冒险如何深入，必须通过信息或内心独白，反复锚定主角的“最终归处”和“待办事项”，防止主线涣散。
    *   **<战力天花板提示>**：在中期副本中，通过信息揭露或惊鸿一瞥的接触，提前树立远超当前的终极战力坐标，拓展世界观深度与主角成长空间。

## **2) 节奏结构与卡点（实战规则库）**
**编辑动作**：审稿时对照此库，检查章节节奏是否符合“张弛交替”铁律，并确保每章末尾有明确“卡点”。
*   **日常章节奏（张弛交替）**
    *   **<探索-消化-爆发>循环**：单数章侧重外部行动与战斗；双数章侧重内部消化、谋划与提升。严禁连续三章同强度叙事。
    *   **<高强度战斗后置信息炸弹>**：激烈战斗章节末尾，通过搜魂或获得关键物品植入颠覆性信息，让读者在爽感未退时陷入更大悬疑。
    *   **<平静期的暗流涌动>**：主角安全修炼时，平行插入其他势力的动态，用多线叙事打破平静，预示风暴将至。
*   **战斗章节奏（层次递进）**
    *   **<战斗三板斧/三段式>**：“遭遇试探 → 底牌对轰 → 致命一击/搜魂”。清晰利落，避免拖沓。**高阶变体**：加入“道心/记忆对抗”作为精神层面决胜手。
    *   **<围观者视角调速>**：在主角高光时刻（破阵、秒杀），切入围观者的震惊反应，将节奏从“动态”拉至“静态特写”，放大爽感。
    *   **<能力组合秀>**：面对强敌，主角轮流展示多种核心能力，形成“你强我技多”的对抗节奏，维持期待。
*   **探索章节奏（悬疑牵引）**
    *   **<悬疑链条>**：上一个悬念未完全解开，立刻用新发现接续更根本的悬念，让读者始终被“问题”牵引。
    *   **<深入递增律>**：探索所见敌人的规模、质量、诡异程度必须呈现清晰递增梯度（如颜色、体型变化），制造压迫感。
    *   **<最终幕布揭>**：在层层递增的探索尽头，揭开终极画面的冰山一角，节奏在最高点戛然而止。
*   **卡点模板（直接使用）**
    *   **<中断式卡点>**：在战斗“启动瞬间”（神通对撞、凶兽扑面）切章。
    *   **<揭秘式卡点>**：在旁观者发出惊骇疑问（“他是谁？！”）时切章。
    *   **<行动前卡点>**：在主角决定发动关键一击、或新势力突然介入的瞬间切章。

## **3) 章末钩子库（可直接抄）**
**编辑动作**：章节写完，从此库挑选或模仿一句作为章末句，确保追读率。
*   **悬疑发现型**：他盯着手中的珠子，面色骤然大变！“天逆……”
*   **意识卷入型**：脑中轰的一声，他的神识被卷入了一个不可思议的漩涡深处。
*   **危机突现型**：就在这一刹那，黑芒直奔他触摸的手指而去！/ 一道长虹，骤然划破天际，直奔此地而来！
*   **强敌宣言型**：“吞了本尊道果，就这么想走了？”/ “XXX，今日必取你魂！”
*   **身份揭示型**：“老夫太古星辰蓝丝族，蓝梦道尊！”
*   **环境惊变型**：整个秘境竟化作一只巨掌，五指缓缓收拢！
*   **真相震撼型**：“没想到，他竟然是战星野！”“那杀他之人……莫非就是掌尊？”
*   **能力异变型**：三幅字帖融合，一个金色的虚幻“战”字，浮现眼前。
*   **记忆情感型**：“平儿，为父的第二式神通，便叫做流月，可好？”
*   **终极悬念型**：沉睡了百年的他，再一次，站起了身子！/ 血雾弥漫中，唯有一双冰冷的眼眸，愈发清晰。

## **4) 冲突模板与推进套路（火药桶设计）**
**编辑动作**：设计冲突时，明确冲突类型、升级路径和终结方式。
*   **生存冲突（基础）**
    *   **<生存空间争夺>**：在封闭地图内，多方势力对关键资源与地盘的必然争夺。
    *   **<螳螂捕蝉黄雀在后>**：明确展示“主角盯A，B组入局，C俯瞰全局”的多层嵌套关系。
    *   **<逃亡倒计时>**：冲突目标变为“在兽潮/绝境完全爆发前逃离”，与时间赛跑。
*   **理念冲突（升华）**
    *   **<理念与道路之争>**：冲突源于根本理念对立（顺修与逆修、圈养与超脱）。
    *   **<意志传承战>**：主角代表已逝前辈的意志，与敌人进行带有历史仇恨性质的战斗。
    *   **<尊严冲突>**：面对至高威压，冲突核心是“是否低头”，一个嘶吼定义角色精神。
*   **身份规则冲突（爽感）**
    *   **<信息差碾压>**：主角掌握对手不知的深层秘密，在冲突中形成降维打击。
    *   **<身份/血脉碾压>**：主角拥有对敌人在种族、血脉上的绝对上位身份，形成天然压制。
    *   **<规则内对决>**：在特定规则（擂台、单挑）下，主角利用规则漏洞或更深理解取胜。
*   **冲突推进与终结**
    *   **<阶梯式损耗>**：团队对抗时，成员按实力由弱到强依次退场，清晰展示代价。
    *   **<借势造冲突>**：主角悟道引发天地异象，无意吸引所有生灵，将平静变为冲突漩涡。
    *   **<情感纽带解围>**：冲突终极解药是主角携带的、与强敌有深切情感的“信物”，将武力冲突转化为因果冲突。

## **5) 升级/爽点/回报机制（成瘾性公式）**
**编辑动作**：设计爽点时，确保短期（战斗胜利）、中期（境界突破）、长期（身份解锁）爽点交织。
*   **认知类爽点（高格调）**
    *   **<认知升级>**：让主角先通过破解谜团实现世界观“升级”，获得掌控感，再兑现为修为提升。
    *   **<从“被布局”到“识破布局”>**：主角从棋子逐渐看清全局棋盘甚至棋手，被动到主动的转变即是高级爽点。
    *   **<知识降维打击>**：利用超越当前地图的“认知”解释现象或破局，形成智力碾压。
*   **战斗类爽点（即时反馈）**
    *   **<体系克制>**：设置专属能力（如雷龙元神克万雷），一旦用出即形成碾压，展现独特性。
    *   **<越级战力公式>**：低境界胜高境界 = 规则领悟（破防）+战术算计（时机）+特殊辅助（决胜）。
    *   **<吞噬进化/以战养战>**：战斗中吞噬敌人最擅长的力量，转化为自身养料，实现越战越强。
*   **资源身份类爽点（积累反馈）**
    *   **<风险投资式回报>**：险境中的探索战斗，必须获得对应价值的回报（信息、法宝），且价值随风险飙升。
    *   **<身份认同与反转>**：通过实力展现，获得阶梯式认同（敬畏→臣服→认可），最终取得新身份（新王）。或前期低调，关键时刻爆发真实实力/形态，形成双重震撼。
    *   **<势力扩增>**：像滚雪球一样收服部下（兽群、信徒），势力肉眼可见地增长。
*   **体验类爽点（情绪反馈）**
    *   **<万众瞩目归来>**：主角在远方取得重大成就时，主场景正因他缺席而受辱，铺垫“王者归来”。
    *   **<旧地重游，物是人非>**：以碾压级实力回归昔日险地，对方态度从平视变为恐惧，形成身份反转爽感。
