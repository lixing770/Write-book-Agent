# 主编知识库总纲｜通用网文写作（最终融合版）

## 1) 主线推进与阶段节点（模板）
- **〈传承破茧〉**：当主角获得核心传承或力量进化时，安排于特定仪式地点（如王座、心脏），伴随痛苦、记忆灌注等代价，作为长期主线的关键跃升节点。**触发条件**：地图核心遗迹、生死危机后、前辈托付。
- **〈衔尾追杀/清算归总〉**：主角实力大成后，确立一个明确、具体、可执行的短期目标（如“杀某某”、“了结四件事”），对过往所有恩怨进行一次集中、列表式的清算，标志旧篇章彻底终结。**检查点**：目标是否具体到人名/地名？是否与过往剧情强关联？
- **〈身份蜕变〉**：在获得新力量或完成仪式后，主角需有公开宣告新身份（如“从今以后，我是XX”）、或通过外界公认（万众参拜）完成“封尊”等仪式，实现定位的根本转变。**编辑动作**：设计一句标志性宣言，并安排群体反应。
- **〈归乡节点〉**：将主角回归初始地图或重要故地，作为一个承上启下的卷章节点。用于展示成长（战力验收）、清算旧怨（恩仇清单）、发现新疑点（旧怨新疑），并引出新冲突（故人引线）。**触发条件**：当前地图核心目标完成，或实力足以碾压故地。
- **〈威慑留痕〉**：在离开重要地点（故乡、宗门）前，留下蕴含自身力量的“标志物”（如雨剑、雕像），形成长期保护与传说。**检查点**：此物是否具备足够威慑力（第三步以下不可敌）？是否与主角核心能力挂钩？
- **〈地图转换/衔接新图〉**：在完成当前地图核心目标后，通过预设出口、获得新线索（如祭坛信息）、或被更高层事件（界外入侵）强行卷入，自然过渡到下一个舞台。**编辑动作**：确保当前地图所有主要伏笔已收束或转为长期线。
- **〈信息解锁〉**：从击败的强敌或新盟友处，逼问或交换出关乎世界格局的更高层面秘密（如异界阴谋、远古战争），将个人主线与宏大叙事绑定。**触发条件**：阶段BOSS战胜利后，或与同级别强者和解后。
- **〈终极备战〉**：通过宏观视角（星域大阵、修士动员）铺陈世界级冲突背景，将个人行动融入集体命运，提升格局。**检查点**：是否通过具体的人物和细节（如某个家族的牺牲）来体现，而非空泛描述。

## 2) 节奏结构与卡点（规则库）
- **〈战斗三段式〉**：重要战斗遵循“瞬压-反抗-碾压”或“破敌技→承伤借力→终极反击”结构。先展示主角优势，再让对手挣扎，最后主角破解并终结。**编辑动作**：为每场重要战斗明确划分这三个阶段。
- **〈张弛交替〉**：高强度战斗/传承章节后，必须接入文戏（谈判、回忆、喘息）。激烈冲突中也可插入短暂寂静或复杂心绪描写，让情绪缓冲。**检查点**：连续战斗章节不超过3章，必须穿插文戏或环境描写。
- **〈蓄势-爆发循环〉**：用多章详细描写战前准备、战术计算（蓄势），然后用极短的章节完成爆发性输出。**触发条件**：大战前、执行复杂计划（如猎兽）时。
- **〈数字锚定与认知反转〉**：用具体时间（“八息”）、层数（“九千万层”）量化敌人强度，再通过权威角色（鲁夫子）的误判，与主角实际表现形成对比，制造认知碾压爽感。**编辑动作**：为关键障碍设置可量化的“标尺”。
- **〈情绪波谷与高潮〉**：在回归故地、见到故人时，刻意放慢节奏，注入温情与感慨，形成与前后冲突场景的情绪反差。在冲突开场，则可用“怒吼开局”瞬间引燃情绪。**检查点**：情感篇章是否真正舒缓了节奏？高潮开场是否足够有力？
- **〈意外打断与99%陷阱〉**：在胜负将分或仪式将成（99%）时，引入第三方、新底牌或环境剧变，强行制造波折。**触发条件**：任何计划进行到最关键处。
- **〈群体反应烘托〉**：通过围观修士的骇然、狂热、死寂等集体情绪，以及敌方士兵的恐惧尖叫，作为节奏和情绪的放大器。**编辑动作**：每个重大场面，都必须有群体反应镜头。
- **〈转场提速与回马枪〉**：完成核心事件后，用短句快速串联收尾动作，节奏明快。但可在离开后，因新触发事件立刻折返，保持叙事流动性。**检查点**：转场是否干净利落？回马枪的理由是否充分（如感知故人）？
- **〈章末悬刃〉**：在关键出手瞬间、新危机降临瞬间、或惊天变故骤起时进行分章。**可直接抄的断点**：斧头斩下的刹那；七彩光芒惊起；虚空被猛烈冲击。

## 4) 冲突模板与推进套路
- **〈你阻我路〉**：核心模型。主角有明确目标（杀人、取物），反派集结力量阻挡，冲突天然成立。**推进**：设置多重递增强度的阻碍（大阵→禁术→诏令）。
- **〈传承/资源之争〉**：两名以上继承者于核心之地对决，争夺唯一资格，并引出传承本身的更高奥秘。**推进**：伴随“代价冲突”（失忆、殒命）与“借力破障”（用敌力助推仪式）。
- **〈威慑代战/心理碾压〉**：面对势力，不直接战斗，而是通过释放威压、隔空一击、连续亮出底牌（如多个三步奴仆），逐步击溃对手心理防线，迫使其自行屈服。**触发场景**：回归故地、势力对峙、高阶博弈。
- **〈阳谋逼迫/公敌诬陷〉**：反派利用大义名分（“界内奸细”），调动全局力量围剿，将个人恩怨上升为立场对立。**推进**：主角破局需结合“实力碾压”与“情报差反制”（早已救回人质）。
- **〈规则内文斗〉**：在高阶力量可能引发不可控后果时，引入“文斗”（炼器、道念）规则，以智斗和底蕴比拼替代蛮力。**推进**：主角在对手最自信的领域，以更深刻理解进行碾压。
- **〈陷阱与反陷阱〉**：将冲突设计为“诱饵-上钩-收网”。反派“失误”实为陷阱；主角“中计”实则将计就计。**检查点**：陷阱逻辑需自洽，反转前需埋下伏笔（主角的细微异常）。
- **〈守护与摧毁〉**：冲突围绕一方誓死守护的“家园/荣耀”与另一方欲将其摧毁或献祭的阴谋展开。**推进**：通过牺牲个体，激化冲突的情感烈度。
- **〈信息差碾压〉**：主角因新获记忆/传承，对规则理解远超旁人，能轻易做到他人无法做到之事（召宝、设陷、瞬移），形成降维打击。**触发条件**：刚获得传承后，进入新地图时。
- **〈旧怨新疑〉**：清算旧怨时，不只是复仇，而是通过成长后的视角重新审视，发现更深层阴谋。**编辑动作**：在复仇过程中，加入一个意料之外的线索或反转。

## 5) 升级/爽点/回报机制（公式）
- **〈仪式晋升〉**：升级必须伴随“仪式感”。在特定地点，通过痛苦、记忆灌注等代价完成，过程感拉满。**检查点**：是否有具体仪式步骤？是否付出了可见代价？
- **〈绝对力量碾压〉**：敌人手段尽出→主角评价“不过如此”→随手一击彻底摧毁。核心爽点在于“力量层级差”的直观展示。**编辑动作**：让敌人先充分展示其强大，再被碾碎。
- **〈认知颠覆爽〉**：通过权威角色（鲁夫子）的预判被主角表现狠狠推翻，其内心震惊与重估，是高级满足感。**公式**：预判（20息）vs 现实（8息）。
- **〈清算复仇〉**：对过往所有仇敌进行一次性、无遗漏的精准清除，实现“念头通达”。**公式**：列表式复仇 + 跨越时间的因果闭环。
- **〈身份/地位反转〉**：昔年需要仰望的老祖，直言“没有把握战胜”；当年需周旋的对手，如今可平静称为“道友”。**触发**：回归故地、公共场合亮相。
- **〈故人惊叹与馈赠〉**：通过故人的骇然、恐惧反应，印证主角变化。并对有情有义的配角，给予远超其付出的回报（传功、赠宝），形成情感满足。**检查点**：故人反应是否多层次？馈赠是否足够厚重？
- **〈资源/底蕴爆发〉**：在关键时刻，揭示并动用前人遗产或自身储备的稀有资源（古息叶、第三步奴仆），形成力挽狂澜的爽点。**前提**：需提前埋下底蕴伏笔。
- **〈场景破坏宏力爽〉**：将力量转化为对宏观场景的改造（一拳裂星、冰封万里），提供视觉化震撼。**编辑动作**：详细描写攻击余波对环境的连锁破坏。
- **〈传承逼格压制〉**：施展的能力对特定种族（古神、古妖）形成血脉层面的绝对压制，彰显位格。**触发**：面对特定种族敌人时。
- **〈荣耀归属爽〉**：在承担大义并成功后，获得群体自发认可与参拜（封尊），满足精神层面需求。**前提**：主角行为
