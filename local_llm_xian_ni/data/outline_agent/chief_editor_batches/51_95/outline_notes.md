# 主编知识库总纲｜通用网文写作（融合精要版）

## 1) 主线推进与阶段节点（模板与触发条件）
- **<危局降临>**：通过 **强敌压境**（外部势力碾压）或 **旧缘新劫**（过往人物带来麻烦），以绝对力量摧毁旧秩序（家园沦陷），迫使主角面临 **生死存亡的抉择**。**触发条件**：主角在旧地图达到阶段上限或获得关键物品后。**编辑检查点**：外部威胁是否具备“降维打击”的不可抗力感？旧秩序崩塌的象征（如护山大阵破碎）是否足够震撼？
- **<群体抉择与流离>**：危局下，内部 **分崩离析**（树倒猢狲散），通过大量配角的集体选择（留下、跟随、离去）勾勒世态炎凉，完成人际网络清洗。主角被迫 **下山/入世**，进入流离或逃亡阶段。**触发条件**：旧庇护所失效后。**编辑动作**：设计一个标志性的“离散场景”，用速写勾勒3-5类有代表性的配角选择。
- **<缓冲与锚定>**：安排 **归乡缓冲** 或 **短暂休整**。通过与至亲互动或独处消化信息，软化节奏，强化情感动机（守护），并为后续行动制定计划。**触发条件**：高强度冲突后，新冒险开始前。**编辑检查点**：是否有温情细节？是否埋下了后续“守护”或“复仇”的明确动机？
- **<入世与冲突嫁接>**：主角以新身份 **进入更广阔地图**（大城、宗门）。通过低姿态互动（迷路问询）接触新势力，并迅速将 **低层次江湖冲突**（镖局夺宝）与 **更高层级修真力量** 的介入相嫁接，实现剧情抬升。**触发条件**：主角进入新环境，需要快速建立冲突时。**编辑动作**：设计一个“三层冲突嫁接”：凡人冲突→低阶修士介入→主角展露实力或引更高阶势力注目。
- **<逃亡/探索新图>**：因被追杀或主动探索，进入 **新势力范围或险地**。通过“传送阵”或“被迫逃亡”完成场景转换，并立即面临新环境的 **规则验证**（如禁斗令）与 **身份适配**（需要获取合法身份）。**触发条件**：主角需要突破当前地图资源或剧情瓶颈时。**编辑检查点**：新地图的核心规则（如尸阴宗的尸傀文化）是否在进入后3章内通过视觉和对话自然展现？
- **<闭关跃迁/战力验证>**：在相对安全地点进行 **闭关**，实现修为稳固提升或功法转换。出关后，立即通过一场 **同阶或越阶生死战**，全面验证新战力体系，并消耗/补充底牌。**触发条件**：获得关键功法或资源后，需兑现战力时。**编辑动作**：战斗设计需系统性展示主角所有新技能、法宝的组合与优劣，避免“秒杀”，要有“试探-受挫-破解”的过程。
- **<目标链与压力转移>**：完成一个阶段目标（如筑基）后，立即引入 **更高层次目标**（修炼黄泉升窍决）与 **长期危机**（被元婴诅咒），形成目标链，保持张力不坠。**触发条件**：一个阶段性爽点释放后。**编辑检查点**：新目标是否与旧目标有逻辑关联？新危机是否比旧危机层级更高或更诡异？
- **<主动破局与信息解锁>**：主角实力提升后，行为应从 **被动应对** 转向 **主动探索/规划**（主动寻找极阴之地、研究阵法）。伴随实力提升，解锁关于世界和功法的 **更深层信息**。**触发条件**：主角具备初步自保能力后。**编辑动作**：设计一个主角主动研究、测试环境或功法的场景，让成长可见。

## 2) 节奏结构控制卡点（规则库与编辑指令）
- **<基础单元：张-弛-张>**：**高强度冲突**（战斗、破阵） → **情感/信息缓冲**（归乡、独处消化、群像抉择） → **新一轮冒险/危机开端**（入世遇险、敌袭降临）。**编辑指令**：检查每个大情节段落是否符合此波浪曲线，避免长时间紧绷或平淡。
- **<战斗节奏三段式>**：1）**试探与常规攻击无效**，制造悬念；2）**对手反击或展现特性**，主角陷入劣势，制造压力；3）**主角亮底牌、用智慧或环境破局**，释放爽点。**编辑检查点**：重要战斗必须有三段式节奏，忌一路平推。
- **<信息与动作的节拍器>**：在密集的动作或修炼描写中，每隔一段就插入 **主角心理活动、回忆或系统解说**，用以调节阅读节奏、投放世界观。**编辑动作**：在描写“冲窍”、“布阵”等过程时，刻意插入1-2句内心独白或知识讲解。
- **<悬念前置与倒计时压迫>**：章节开头或情节单元初期，抛出 **核心悬念**（尸傀为何叛变？）或设定 **明确倒计时**（雕像即将破碎）。利用资源消耗（灵气将尽）、敌人逼近来线性增加紧张感。**编辑指令**：在主角开始执行任务前，就明确其面临的限制（时间、次数、资源）。
- **<缓冲带与留白>**：激烈转折后，必须安排 **解说缓冲带**（由角色系统讲解世界观）或 **收尾留白**（主角沉思、规划）。给予读者消化信息的时间。**触发条件**：重大反转或信息揭露后。
- **<日常中断与意外升级>**：在 **温馨日常**（家庭团聚）或 **平淡过渡**（问路）中，突然被 **突发事件**（劫杀、高阶修士介入）暴力打断，将冲突层级瞬间抬升。**编辑动作**：在计划写温情戏时，反向思考如何用意外将其打破。
- **<多线并行暗示>**：专注主角线时，通过 **短暂视角切换**（如追杀者到达某地、废墟深处存在苏醒），暗示其他故事线正在推进，拓展世界维度。**编辑指令**：在主角闭关或赶路时，可用1-2段描写其他势力的动向。

## 3) 章末钩子库（可直接选用或改编）

3.  “罢了，所有弟子听令，随我等离开吧。”
4.  王林站在村口，遥望家门，内心此起彼伏。
5.  一股庞大的神识/威压立即出现，瞬间横扫全场/如山岳降临。
6.  ……再次出现时，已是在三百丈外。（用于瞬移、逃脱）
7.  他嘴角一翘，迅速离开。他离开后不久，追兵到了……（用于制造紧张差）
8.  答案，就藏在最不可能的角落。
9.  这一切，原来只是个开始。
10. 退路，已彻底断绝。
11. 真正的危险，从来不是眼前所见。
12. 阴影中，另一双眼睛缓缓睁开。
13. 传送的尽头，八双冰冷的目光同时睁开：“恭迎…前辈？”
14. 庞大的威压降临，一个阴森的声音直接在脑海中响起：“你，就是他的弟子？”
15. 他望着手中的物件，瞳孔骤然收缩。

## 4) 高频冲突模板与推进套路
- **<身份/信息差碾压>**：反派因严重 **低估主角实力**（视为凡人），作出愚蠢挑衅，随后被主角用 **基础法术轻描淡写制敌** 或 **展露高阶身份** 实现双重反转。**核心**：制造并利用认知差。
- **<身边毒蛇与黑暗决断>**：表面亲近的 **师父/同门** 因贪欲显露真面目，欲用阴毒手段控制主角。迫使主角完成 **“弑师”或“叛门”的第一次杀伐决断**，完成心性蜕变。**推进**：由“怀疑”到“证据确凿”再到“冷酷反杀”。
- **<资源争夺与险地借力>**：冲突围绕 **稀缺资源**（极阴之地、宝物）展开。主角将敌人 **引入危险环境**，利用原生威胁（怪物、毒瘴）借力打力。**核心**：环境成为战斗的第三方变量。
- **<旧识对立与理念冲突>**：故友因 **被控制** 或 **理念不同**（生存 vs 道义），被迫与主角对立。形成情感与立场的双重折磨。**推进**：试图唤醒 -> 失败 -> 不得已对抗 -> 留有余地或悲剧收场。
- **<降维打击与生存逃亡>**：**高阶修士/势力** 为夺资源，以无可抵御之势碾压而来。制造“绝望-逃亡”的生存危机，驱动地图转换。**核心**：压迫感必须绝对，不给“硬刚”的可能。
- **<规则挑衅与阵营筛选>**：在新地图中，主角或反派 **触犯当地铁律**（禁斗），引发与规则维护者的冲突。同时，通过一场灾难 **快速筛选** 出盟友、小人与旁观者。**功能**：立规并厘清人际关系。
- **<诅咒追杀与心理博弈>**：建立一种 **长期、单向的追踪关系**（元婴诅咒）。冲突体现在“隐藏与寻找”的智斗，以及主角利用信息差周旋。**核心**：追杀者是背景压力，冲突形式以心理和策略博弈为主。
- **<底牌对轰与第三方乱入>**：冲突双方 **轮流打出更强底牌**，将烈度逐步抬升。在僵持或将胜时，**引入不可控第三方**（强大怪物、其他仇家），彻底打乱战局。**作用**：避免战斗陷入单调，制造意外转折。

## 5) 升级体系与爽点制造公式
- **<认知升级爽点>**：主角实际水平远高于外界评价，由 **权威（魂老）在私密空间点破**，带来“原来我这么强”的快感。**公式**：外界鄙视 + 独处时权威揭秘 + 主角重新认知自我。
- **<越级洞察与掌控感>**：主角能 **看透所有人深浅**，而对方看不透他。形成信息碾压。**应用场景**：进入新环境、接触新角色时，主角内心给出准确判断，读者获得“上帝视角”爽感。
- **<代价破门式晋升>**：升级 = **巨大痛苦/风险描述**（阴寒噬体） + **主角的坚韧意志** + **突破后的质变描述**（寒丹形成）。**关键**：让读者清晰感知到代价与收获的等值。
- **<智慧破局与知识变现>**：爽点 = **前期积累的知识/技能**（阵法、药理） + **在关键时刻创造性应用** + **取得逆转效果**。此爽点与力量无关，凸显主角智慧。
- **<战利品连锁反应>**：击败强敌 -> **获得其储物袋** -> **发现远超当前阶段的宝物/功法** -> 由 **魂老鉴定** 揭示惊人价值 -> 此宝物又成为解决下一个危机的关键。**形成持续正反馈循环**。
- **<体系特殊性与隐性成长>**：揭示主角境界/功法 **非常规、具特殊优势**（凝气十四层、极境）。并通过 **细节**（吐纳效率提升、对环境的影响）展现其全方位渐进式成长，给予持续正向反馈。
- **<身份伪装与低调打脸>**：主角以 **低阶身份示人** -> 被挑衅 -> **展露部分真实实力形成碾压** -> 旁观者震惊。**经典套路**：凡人 -> 低阶修士 -> 隐藏大佬，完成双重反转。
- **<环境互动与探索发现>**：爽点源于主角 **主动测试、改造、利用环境**（测试光柱、挖洞布阵、吞噬阴气）。此过程本身即是“掌控感”和“智力优越感”的体现。
