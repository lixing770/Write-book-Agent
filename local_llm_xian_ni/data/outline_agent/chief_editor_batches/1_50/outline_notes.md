# 主编知识库总纲｜通用网文写作（1-50章核心框架）

## 1) 主线推进与阶段节点（复合模板）
**核心逻辑：** 遵循“确立平凡→引入变故→受挫压制→绝境转机→隐性成长→验证破局→再踏征途”的经典弧光，在50章内完成第一个情绪与成长闭环。

- **<平凡起点/绝境开场>**：开篇快速确立主角在世俗或初入超凡世界中的劣势地位（废柴、杂役、记名弟子），建立读者共情与低期待。
- **<目标确立与门槛>**：清晰给出主角的短期核心目标（如通过测试、突破凝气二层），并设立一个明确的、看似难以逾越的障碍（资质差、资源匮乏、时间紧迫）。
- **<贵人引路/代价准入>**：通过一位“引路人”（亲属、恩人）带来改变命运的外部机遇（名额、信物），但该机遇往往附带苛刻条件或卑微身份，并非坦途。
- **<规则初显与打压>**：主角进入新环境（门派），立刻通过入门测试、日常任务或阶层对比，残酷展现世界核心规则（如灵根决定论、森严等级），并遭遇首次系统性打压与羞辱。
- **<绝境转机与金手指激活>**：在情绪与实力的谷底（测试失败、任务无法完成），因意外（坠崖）或极端行为触发初始金手指（神秘石珠、体内老怪），获得一线非常规生机。
- **<隐性成长与功能探索>**：在绝对安全或相对自主的空间（洞穴、独立居所），主角对金手指进行基础实验与摸索，解锁初级功能（疗伤、梦境修炼），实现读者知晓而书中人不知的隐性成长。
- **<微型验证与情感回报>**：安排一个小型场景（短暂归乡、同门小比），让主角利用成长初步化解危机或获得微小认可，产生“衣锦还乡”爽感或收获真挚友情，完成首次能力验证与情感慰藉。
- **<新矛盾与任务加身>**：成长带来的新问题（资源暴露风险）或外部系统强行赋予的职责（管理杂务），制造“修炼”与“生存”的新一轮核心矛盾，推动故事进入更深层博弈。
- **<破局萌芽与主动规划>**：主角在应对新矛盾中，发现金手指的更深层潜力或世界的另一套规则，并据此制定清晰的短期修炼/破局计划，展现主观能动性。
- **<小成归乡或再踏征途>**：在解决或搁置当前阶段的主要矛盾后，主角或短暂回归完成情感闭环，或目标更明确地主动踏入下一个更广阔、更危险的核心地图，开启新阶段循环。

**【编辑检查点】**：检查第10章是否已完成“日常→变故”；第25章左右是否已完成“受挫→获机”；第50章是否已完成第一个“成长→验证”的小闭环，并埋下至少一个牵引后续50章的新矛盾伏笔。

## 2) 节奏结构与卡点（规则库）
**核心逻辑：** 通过“紧张-舒缓”的交替、“信息-情绪”的调控，以及明确的阶段性节点，控制读者的阅读心流。

- **<开篇三章定调>**：三章内必须完成“初始状态→外部变故→做出决定”的转变，抛出核心悬念（仙缘、金手指）。
- **<张弛交替律>**：高强度事件（羞辱、测试、危机）章节后，必须接一段舒缓章节（日常温情、路途见闻、实验探索），调节叙事呼吸，防止疲劳。
- **<信息分批投放>**：世界观、修炼体系、门派规则等信息，通过角色对话、内心活动、事件体验拆解投喂，严禁大段旁白说明。
- **<期望管理>**：在重大转折前，通过配角轻视、规则严苛、自身劣势反复铺垫低期望，为后续反差蓄积最大势能。
- **<情绪波谷与反弹>**：可安排“连续打击”（在不同维度受挫），将主角与读者情绪压至谷底，随后用“意外救场”（金手指触发）实现强力反弹，制造情绪落差爽感。
- **<日常中埋刺>**：在平缓的日常叙述中，插入细微的异常（被窥视感、物品微小变化）、不详预感或配角的一句闲谈，为后续冲突埋下伏笔。
- **<三章一小变>**：约每三章，主角的状态、认知或环境应发生一次可见变化（如获得珠子→发现功能→首次应用）。
- **<断章于势>**：章节结尾应在动作、决心、转折性话语的顶点，或新悬念刚抛出时断章，制造“且听下回分解”的钩子。
- **<节点高潮>**：每5-10章设计一个情节小高潮（突破小层次、成功交易）；每20-30章设计一个阶段性高潮（通过重要试炼、身份跃升）。
- **<收束与发散>**：解决一个旧矛盾的同时，必须自然引出至少一个新问题或更广阔的视野，让故事螺旋上升，避免原地停留。

**【编辑检查点】**：通读最近10章，检查“紧张”与“舒缓”章节是否交替出现；检查重大转折前是否有足够的“抑”来做铺垫；检查每个章节末尾是否留有有效的悬念钩子。

## 4) 冲突模板与推进套路
**核心逻辑：** 混合多种冲突类型（人际、体系、生存、内心），避免单一，并确保冲突能有效推动人物成长与剧情。

- **<人际关系冲突>**
    - **宿命对照**：设立与主角有亲缘/地缘关系的“天才”对手，全程作为比较与超越对象。
    - **世态炎凉**：通过家族宴会、同门议论等场景，集中展示势利眼人情，提供最原始的奋斗动力。
    - **言语机锋/公开羞辱**：在公共场合，通过对话进行人格贬损、揭露不堪过往，制造“社会性死亡”场景。
    - **信任试探与背叛**：与潜在盟友需经利益交换逐步建立脆弱信任，并可安排背叛戏码考验主角。

- **<体系规则冲突>**
    - **规则之壁**：将核心冲突抽象为与“世界规则”（如灵根资质）的对抗。
    - **规则不公/潜规则**：明面规则与潜规则并存，主角因不懂或无法利用而吃亏。
    - **阶层打压与资源争夺**：高阶者利用规则进行剥削；同阶层在生存资源上展开隐性竞争。
    - **职责与修炼的根本矛盾**：外部强加的世俗职责严重挤占修炼时间，形成结构性冲突。

- **<生存环境冲突>**
    - **绝境求生**：抛入纯物理绝境（悬崖、毒障），冲突对象是自然环境与生存本能。
    - **秘密危机**：身怀重宝，任何异常都可能引来杀身之祸，与环境互动时持续紧张。
    - **信息差冲突**：因地位低导致常识缺乏，不断因“无知”陷入被动。

- **<内心与观念冲突>**
    - **内心挣扎**：在重大选择时（跳崖、服毒），详细描写从恐惧、犹豫到决绝的过程。
    - **观念冲突**：“斩断凡尘”的修仙观念与主角重视亲情的情感需求直接对立。
    - **动机博弈**：与高阶者（师父）的关系建立在相互算计之上，进行心智较量。

**【编辑检查点】**：评估当前章节的主要冲突属于哪一类型；检查连续三场冲突是否类型有变化；确保每场冲突的结果都或多或少地改变了主角的状态或认知。

## 5) 升级/爽点/回报机制（设计公式）
**核心逻辑：** 爽点源于**铺垫-压抑-反转**的过程，或**信息差**带来的优越感，必须与主角的主动行动和核心秘密挂钩。

- **<期望反转类>**：众人（及读者）期望降至冰点→主角以意料之外的方式（毅力、奇遇、隐藏实力）触碰到机遇或实现小目标。**关键**：前期的“抑”要足够具体、残酷。
- **<信息差优越类>**：读者早于书中角色知晓主角底牌（金手指功能、真实修为）→期待秘密揭晓时他人的反应。**关键**：通过主角视角强化“只有我知道”的隐秘感。
- **<苦难兑换类>**：主角承受的生理痛苦（血肉模糊）与心理屈辱（当众嘲讽）越具体→后续获得回报时（哪怕是一句认可、一点恢复）爽感越强。**关键**：苦难描写要细腻，回报要及时。
- **<隐性成长类>**：在无法传统升级时，将成长体现在“意志力提升”、“认知加深”、“宝物功能解锁”上。**关键**：要通过主角的内心感受或细微变化，让读者明确感知到成长。
