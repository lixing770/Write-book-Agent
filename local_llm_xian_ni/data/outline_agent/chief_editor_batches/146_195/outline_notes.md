# 主编知识库总纲｜通用网文写作

## 1) 主线推进与阶段节点（核心模板）
**【编辑动作】**：每个大章节（约50章）必须完成一个从“困境”到“清算”再到“新悬疑”的完整循环。
1.  **目标锚定与危机驱动**：主角行动必须围绕一个**具体、短期、可达成的目标**（如获取炼丹炉、抵达安全区）。同时，需被更强的**外力（追杀、悬赏、规则）强行打断**，制造紧迫感。
2.  **逃亡/绝境中的成长**：将危机过程设置为突破的“前置条件”。逃亡需有**阶梯式压力**（单人→小队→大队围堵），并在绝境中给予**微小希望**（如洞府在望）。
3.  **绝地反扑与战力反转**：设定明确的逃亡终点或转折点（如回到洞府、完成突破）。在此实现**战力反转**，核心爽点在于对前期强敌的**“境界/认知碾压”**。
4.  **系统性清算与情绪闭环**：反杀后必须进行**系统性、公开化的清算**，按“追击名单”清除敌对势力。详细描写反派的惊骇与求饶，释放前期憋屈。
5.  **身份重塑与威名确立**：阶段性胜利后，主角需获得新的**身份标签**（如“XX境内元婴下第一人”）或**视觉化威名象征**（如头顶诛字、尸骸披风）。通过一场公开的碾压战斗或冷酷宣言确立。
6.  **悬念升级与舞台扩大**：在清算高潮时，引入**更大范围、更具风险的长期悬念**（如百日诛杀令、古神之地），将矛盾从个人恩怨升级为**世界规则或史诗阴谋**。
7.  **主动破局与地图跃迁**：面对新危机，主角需从被动承受转为**主动、强硬的应对**（如杀上总部、主动探秘）。通过传送阵、强者裹挟等方式，实现**地图跃迁**，进入更高级舞台。
8.  **信息解锁与目标拆解**：在新地图，通过高阶角色对话、遗迹信息，解锁世界观核心秘密。将宏大目标（如结婴、复仇）拆解为**可执行的资源清单**（功法、丹药、材料）或**具体地点**（识海、死海）。
9.  **嵌套博弈与终局转换**：主角被卷入多方博弈（如传承争夺），在被迫合作或充当“黄雀”时，发现**任务嵌套**（计中计）。阶段尾声常以**无法抗衡的强者介入**或**环境异变**，将剧情推向更高层次。

## 2) 节奏结构与卡点（规则库）
**【检查点】**：每3-5章必须有一个明确卡点；每10章需完成一次“张-弛-张”的完整节奏循环。
1.  **基础节奏模板**：
    *   **动-静-动**：高强度战斗/逃亡 → 战后盘点/学习/互动 → 新强敌出现/出发新目标。
    *   **张弛交替**：紧张比控制在3:1或4:1。安全期用于**疗伤、消化收获、研究技能**。
    *   **三年又三年**：用明确时间跨度（“七年过去”）进行大节奏切割，标注成长周期。
2.  **危机推进节奏**：
    *   **层层加码**：危机强度阶梯上升（预警→爆发→升级）。
    *   **倒计时压迫**：设置明确时限（灵力将尽、追兵逼近距离）或**资源消耗计数**（法宝剩余）。
    *   **心跳三连**：中型危机标配“**预警→爆发→险险避开**”三段式。
3.  **高潮与卡点设计**：
    *   **临门一脚**：将核心目标达成（丹成、破关）与外部防御被破的节奏同步，制造千钧一发。
    *   **静态爆发**：高潮前给主角一个“短暂定格”描写（闭目、宣言），蓄积情绪后瞬间释放。
    *   **悬念前置**：章节开头直接抛出反常结果或进入高潮动作，迅速抓住读者。
    *   **视角切换**：在主角线平稳时，切至追兵/竞争者视角，铺垫压力或揭示信息差。
4.  **探索与解密节奏**：
    *   **信息断点**：关键信息揭示前，被突发事件打断。
    *   **试探循环**：“**观察-假设-小成本试探-验证/修正**”构成探索基础单元。
    *   **伪安全区**：在危险后进入平静区，但通过主角心理暗示“不会这么简单”。

## 3) 章末钩子库（可直接选用）
**【触发条件】**：根据章节末尾剧情所处阶段（绝境、反转、揭秘前）选择对应钩子。
*   **危机降临**：身后咆哮已近在咫尺，而前方的路，却隐于迷雾之中。/ 所有的退路，在同一瞬间，被彻底封死。
*   **绝境抉择**：他握着那物，深知代价巨大，但眼中已然尽是决然。/ 此刻，摆在他面前的，只剩下最后一条路。
*   **悬念揭露**：玉简中的内容，让他脊背发凉，原来此地的真相竟是……/ 所有的线索都指向一个令人难以置信的结论。
*   **异变陡生**：但就在这时，异变骤生！/ 整座山峰，蓦然一颤。/ 天空的乌云，越来越近，其内一个紫色雷球，缓缓诞生。
*   **强敌登场**：一个冰冷的声音，徐徐从四面八方传来……/ “小友，老夫不想伤你，可否听老夫把话说完？”
*   **反杀开端**：他拖着敌人的尸首，如死神般，向下一个目标飞去。/ 嘴角冷笑，右手一散，收起了即将发动的致命一击。
*   **威慑收场**：他环视四周密密麻麻的贪婪目光，冷声开口：“三息之内，不滚则死。”/ 所有人看着那诡异的死状，贪念化为了寒意。
*   **认知颠覆**：光芒散尽，眼前所见，彻底颠覆了他的认知。/ “……原来，这才是真相。”

## 4) 冲突模板与推进套路
**【编辑动作】**：当剧情陷入平淡时，从以下模板中选取一个并注入当前设定。
1.  **夺宝冲突**：`怀璧其罪`（公开露财） → `误判实力`（反派轻视） → `连锁反应`（杀一人惹一宗）。
2.  **绝境反杀**：`困兽之斗`（被逼入绝地） → `底牌震慑`（付出代价破局） → `援军绝望`（优势再被压垮） → `临界突破`（压力下升级） → `猎杀反转`。
3.  **环境求生**：`环境即死敌`（规则杀局） → `信息不对等`（试错获取情报） → `资源耗尽战` → `能力意外生效`（特殊能力破局）。
4.  **多方博弈**：`螳螂黄雀`（A、B死斗，C夺利） → `囚徒博弈`（被迫合作，互相算计） → `祸水东引`（将危机导向第三方） → `黄雀在后`（第四方收割）。
5.  **智谋碾压**：`信息差冲突`（一方知全局，一方被算计） → `规则利用`（利用场景规则作战） → `算计反算计`（多层计谋套娃） → `误导与醒悟`（证据误导后反转）。
6.  **身份/理念冲突**：`师徒背叛`（养料与收割者） → `正统之争`（传承归属的道统冲突） → `认知欺骗`（虚假信息诱人入局）。

## 5) 升级/爽点/回报机制（核心公式）
**【检查点】**：每次升级或获得回报前，必须确保前期已充分铺垫“付出”、“憋屈”或“危险”。
1.  **情绪释放型**：`憋屈释放`：详细描写逃亡狼狈与反派嚣张，反杀时用敌方惊骇反应烘托。`代价回报`：为突破付出的代价（损伤、情感），需获得超额回报。
2.  **实力认证型**：`境界/技术碾压`：升级后对前期强敌秒杀。`身份奖励`：获得令人敬畏的称号或社会地位。`权威认证`：通过强者内心独白，详细罗列主角优点，完成“官方认证”。
3.  **资源掌控型**：`资源转化`：将冒险所得在关键时刻转化为破局关键，完成价值闭环。`掠夺快感`：详细盘点从强敌身上夺取的宝藏清单。`资源垄断`：将公共威胁转化为个人独家资源。
4.  **认知优势型**：`认知颠覆/升维`：让所有轻视者亲眼目睹实力产生震撼；或提前揭示更高层力量体系。`信息差碾压`：主角掌握全局信息，看破陷阱，享受智力优越感。`规则利用`：将不利规则公开宣示为反向利用的工具。
5.  **成长可视化**：`能力秀场`：在专属场景（如寂灭界对吞魂）彻底发挥优势。`进度条外显`：明确技能进度（如可画十个残影圈）。`命名权`：为自己创造的技能或器物命名。

## 6) 世界观/规则投放手法（边写边讲）
**【黄金法则】**：**绝不用旁白大段说明，所有设定必须包裹在情节、对话或角色体验中。**
1.  **情节包裹法**：
    *   `场景化投放`：通过进入店铺交易，带出货币、物价、阶层。
    *   `代价揭示`：在角色使用能力时，通过内心权衡或副作用揭示力量代价。
    *   `功能化投放`：规则立刻转化为影响生存的具体机制（如气浪是触手）。
2.  **对话与记忆法**：
    *   `NPC解说`：通过配角对话解释基础设定（比旁白自然）。
    *   `强者口述`：高阶角色对话带出势力背景、历史秘辛。
    *   `记忆承载`：将核心背景封装在“传承记忆”中，随吸收自然投放。
3.  **环境与体验法**：
    *   `环境叙事`：险恶环境本身就是规则的体现（如禁制山）。
    *   `感知体验`：让主角通过感官和灵力变化直接“体验”规则。
    *   `遗迹信息`：通过石刻、留言等被动讲述历史。
4.  **对比与冲突法**：
    *   `失败演示`：通过他人惨状展示违反规则的后果。
    *   `层次对比`：通过店铺楼层、地域差异（三级国/四级国）直观展示阶层。
    *   `冲突揭示`：在激烈对话中自然带出关键信息（“这里是妖神之地！”）。

## 7) 人物功能与关系推进（角色分工）
**【编辑动作】**：检查每个登场角色是否明确服务于以下至少一项功能。
1.  **核心轴心**：**主角**。目标驱动，情感内敛。所有关系以其为轴心。
2.  **压力与垫脚石**：
    *   `阶段性反派`：制造压力，拉仇恨，拓展地图，最终成为升级垫脚石。
    *   `压力源/清场者`：制造持续危机感，推动进入下一阶段（如魔化孟驼子）。
    *   `功能性垫脚石`：强大但令人反感的竞争者，用于展示关卡难度并成为主角“礼包”。
3.  **辅助与纽带**：
    *   `智囊辅助（红颜）`：提供专业知识（丹、阵）、情感慰藉、关系由利用向依存渐变。
    *   `武力仆从`：前期敌人被收服，心态经历“恐惧-敬畏-认同”转变，负责打手与管理。
    *   `导师/需求型NPC`：提供高阶视野和信息，制造主要动力，关系从捕猎者→胁迫性合作者。
4.  **工具与氛围组**：
    *   `工具人NPC`：触发特定剧情（店员、带路党），用完即弃。
    *   `围观群众`：提供环境反应（贪婪、震惊），烘托主角行为冲击力。
    *   `信息媒介`：通过其回忆或独白投放背景故事和设定。
5.  **关系推进关键点**：
    *   `共同经历危机`是关系深化核心触发器。
    *   `主从关系`通过恭敬带路、处理杂兵、献上魂血等动作快速确立。
    *   `情感伏笔`在紧张剧情中插入一句误解或关切。
