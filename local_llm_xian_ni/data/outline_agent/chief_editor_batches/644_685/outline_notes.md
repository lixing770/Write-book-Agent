# 主编知识库总纲｜通用网文写作（融合最终版）

## 1) 主线推进与阶段节点（全流程模板）
**核心原则**：每个阶段必须拥有一个清晰、可执行的**核心目标**，并经历“入局→破局→收获/转换”的完整循环。

- **<地图入场与目标锚定>**
    - **触发条件**：主角进入新地图（秘境、绝地、星辰、坊市）。
    - **编辑动作**：
        1.  **速写格局**：立即用1-2个特征（如“三足鼎立”、“死气弥漫”）勾勒当地势力或环境基调。
        2.  **明确靶心**：让主角的核心目的清晰化（获取某物、验证情报、复仇、寻求突破资源）。
        3.  **设置守门人**：在接近核心目标前，安排当地势力强者拦截，形成第一道冲突。

- **<多方博弈与僵局形成>**
    - **触发条件**：主角与多方势力因目标汇聚于同一封闭/半封闭空间。
    - **编辑动作**：
        1.  **信息迷雾**：主角对环境和敌人的信息掌握度≤50%。
        2.  **平衡架构**：设计至少三方（主角、敌对A、第三方B/环境怪物）相互制衡的脆弱平衡。
        3.  **信任试探**：通过共同危机或展示价值，与潜在盟友建立脆弱合作。

- **<破局引擎与节点转换>**
    - **检查点**：当剧情因对峙或探索陷入缓慢时启动。
    - **编辑动作**：
        1.  **环境突变**：引入不可抗规则变化（秘境收缩、怪物暴动、倒计时）。
        2.  **信息揭露**：通过环境异变或敌人自语，揭示困局部分真相（陷阱本质、宝物真身）。
        3.  **内部撕裂**：外部压力导致敌方或盟友内部产生决策分裂。
        4.  **螳螂黄雀**：明面冲突下，揭示暗处存在收割者（第三方势力或环境本身）。

- **<破局行动与高潮对决>**
    - **触发条件**：僵局被打破，主角做出“冒险深入”或“强势破阵”的抉择。
    - **编辑动作**：
        1.  **底牌博弈**：遵循“常规手段→特殊法宝→意境规则→底蕴请祖→终极呼唤”的层次，逐级亮牌。
        2.  **因果绑定**：将对决动机与早期重大伏笔（承诺、牺牲、恩怨）强关联，提升情感重量。
        3.  **围观定调**：安排第三方势力神识观战，通过其评价侧面烘托战局、解释设定。

- **<阶段收尾与地图转换>**
    - **检查点**：核心目标达成或失败，主要冲突暂告段落。
    - **编辑动作**：
        1.  **资源清点与整合**：系统消化本阶段战利品，将零散资源转化为即战力或伏笔。
        2.  **清理因果线**：兑现承诺、解决旧怨、安置部下，形成阶段性闭环。
        3.  **代价揭示/隐患爆发**：力量提升后，立即展示其负面代价或潜伏隐患。
        4.  **战略转移**：因强敌追踪或资源枯竭，主动切换地图。离开前可进行“战略欺骗”，扰乱敌方。
        5.  **信息枢纽**：通过关键人物（残魂、器灵）对话，投放下一阶段的核心世界观，铺垫新地图。

## 2) 节奏结构与卡点（规则库）
**核心原则**：通过“张弛交替”制造呼吸感，通过“悬念链”维持阅读动力。

- **<宏观节奏：三倍律与张弛>**
    - **规则**：重大战斗/情绪爆发后，需安排至少三倍篇幅的沉淀期（疗伤、复盘、修炼、日常）。
    - **编辑动作**：高潮后务必接入“意境感悟”、“故人重逢”、“温情互动”或“资源整合”等舒缓情节。

- **<单元节奏：三幕式闭环>**
    - **公式**：接触试探（起）→冲突爆发/意外发生（承）→底牌应对/局势逆转（合）。
    - **检查点**：单章或连贯章节内应完成此闭环，给予读者即时获得感。

- **<悬念与钩子控制>**
    1.  **信息投放卡点**：关键世界观信息不在平静时说明，而在角色最需要或最震惊时抛出。
    2.  **钩子-行动-小结果循环**：每小节都遵循“悬念→行动→微结果”模式，保持动力。
    3.  **终极钩子延迟**：最具冲击力的信息，在前序充分铺垫后，于章节末或谈判最后关头抛出。
    4.  **预期违背**：营造一种局势走向的预期，然后用敌人底牌或环境异变彻底颠覆。

- **<压力与紧迫感设计>**
    1.  **压力递增**：通过环境恶化、敌人底牌频出、时间限制，让紧张感阶梯式上升。
    2.  **倒计时压迫**：给出明确且无法抗拒的行动时限（如十息、雾气收缩）。
    3.  **战力对比悬疑**：始终保持主角与关键对手的实力差距，让“如何赢”成为核心悬念。

- **<战斗与特殊情节节奏>**
    1.  **呼吸感控制**：高强度战斗中，插入细微动作或感官描写（“手臂欲裂”），避免一味狂飙。
    2.  **闭关时间模糊化**：用“时光流逝”、“年复一年”等词配合环境细节体现时间感，避免具体数字引发焦虑。
    3.  **情绪过山车**：紧张冲突后插入短暂情感刻画，旋即用更强冲突推向更高点。

## 3) 章末钩子库（可直接选用）
**【异变陡生型】**
1.  就在他/她即将触碰到那物的瞬间，异变陡生！
2.  所有的算计与平衡，在这一刻被彻底打破。
3.  那沉寂已久的古老存在，睁开了双眼。

**【威胁降临型】**
4.  一个冰冷/戏谑/狂暴的声音，自虚空/雾中/身后传来：“……！”
5.  一股冰冷的神识，悄然锁定在他身上。
6.  一个冰冷的声音，如同从九幽传来：“你救她，XX灭族！”

**【震撼揭示型】**
7.  他/她瞳孔骤缩，看到了毕生难忘/无法理解的一幕。
8.  老者眼中露出前所未有的震惊，失声道：“这不可能！”
9.  原来，这从一开始就是一个针对他/她的局。

**【抉择悬念型】**
10. 他/她做出了一个疯狂的决定。
11. 代价，远比他/她想象的更为惨重。
12. 这一去，要么功成道显，要么身死道消，再无第三种可能。

**【身份悬念型】**
13. “前辈可是……雷仙使者？”
14. “姓许……”女子眼皮微不可查的一颤。
15. 四人面色大变，下意识退后，看向他的目光充满了惊骇。

**【能力悬念型】**
16. 他的元神，终究还是与凡人，有了不同。
17. 熟悉/陌生的波动传来，他/她体内的某物，产生了共鸣。
18. 这一眼，便可使得凶虫退开，这等神通，看的她心神一震。

## 4) 冲突模板与推进套路
**核心原则**：冲突需多层次，从外部武力对抗延伸至内部心理、伦理博弈。

- **<外部势力冲突>**
    1.  **三方制衡**：主角、敌A、第三方B（势力或怪物）相互牵制，任何两方动手都可能让第三方得利。
    2.  **祸水东引/代价转嫁**：将无法力敌的强敌仇恨转移至竞争对手，或将自身损失转化为攻击对手的筹码。
    3.  **阳谋逼迫**：利用环境规则或道德制高点，迫使对手做出不利选择。
    4.  **身份误认与利用**：对手因主角特征误判其背景，主角将计就计，获取便利或威慑。
    5.  **规则挑衅**：主角以力量直接挑战并粉碎当地上位势力的规则与颜面。

- **<内部与心理冲突>**
    1.  **囚徒困境**：临时合作双方高度不信任，互相猜忌，任何动作都可能引发先发制人。
    2.  **信息差博弈**：一方掌握关键信息，在试探与反试探中压制对手。
    3.  **背刺时机**：在脱困或目标达成前一刻，合作方突然翻脸。
    4.  **神物反噬/己身异化**：吞噬或融合高级存在时，遭遇其意识反抗或引发自身“非人化”认知危机。
    5.  **情感与理智**：冷静修行中被记忆、执念突然触动，产生强烈情感波动。
    6.  **道德绑架**：反派利用主角重视之人或道德感进行胁迫，制造两难。

- **<环境与绝境冲突>**
    1.  **环境吞噬**：与无法抗拒的自然/空间力量（超级引力、绝灵之地）对抗。
    2.  **资源诅咒**：看似天大的机缘，实则是致命陷阱，引发“取与舍”的内心挣扎。
    3.  **好奇与危险**：对神秘呼唤或未知深渊产生好奇，与生存理智产生冲突。

## 5) 升级/爽点/回报机制（可执行公式）
**核心原则**：爽点需具备“预期—颠覆—回报”的完整链条，且回报应多样化。

- **<智谋碾压类>**
    - **公式**：认知优势变现。
    - **触发**：主角凭借独家知识（传承记忆）识破他人未知的危险/宝物/真相。
    - **执行**：1. 展示众人蒙昧；2. 主角冷静点破；3. 利用信息差规避风险或获取利益。
    - **检查点**：读者获得“先知”视角的快感。

- **<以弱胜强类>**
    - **公式**：底牌震撼 + 规则对等级。
    - **触发**：对手炫耀强大神通或进行等级压制。
    - **执行**：1. 渲染对手强大；2. 主角用出层次更高或更诡异的底牌（特殊意境、规则之力）；3. 造成对手认知震撼与心理崩溃。
    - **检查点**：形成“你也不过如此”的压制感。
