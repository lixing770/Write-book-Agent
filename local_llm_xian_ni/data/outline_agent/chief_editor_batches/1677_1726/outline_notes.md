# 主编知识库总纲｜通用网文写作

## 1) 主线推进与阶段节点（模板）
**核心原则**：主线由一系列明确的“节点”驱动，每个节点都应是情节、格局或主角状态的质变点。
- **节点·收线与锚定**：在重大风暴（最终战、大冲突）前，安排“宁静期”，集中回收长期情感线、完成责任交接（如辞去称号、托付后事），为主角的情感世界与世俗牵挂做阶段性了结。**检查点**：主角是否已无后顾之忧？
- **节点·扩容与升维**：当个人恩怨陷入瓶颈时，插入能将格局拔高至世界级的“支线任务”（如重凝仙界、修复一界），使主角功业从“复仇/称霸”升级为“创世/救世”。**触发条件**：当前地图战力已接近天花板。
- **节点·认知颠覆**：通过可靠角色之口或确凿证据（记忆碎片、遗迹考古），抛出颠覆主角及读者既定认知的爆炸信息（如世界是洞府、梦境内核），使已“完结”的旧谜团重生，迫使主线深度与方向发生根本性改变。
- **节点·战力整合与归附**：在最终决战前，通过“情感羁绊”、“共同利益”或“实力威慑”，完成关键战力拼图。包括：1) **关键强者倒戈**；2) **一方势力整体归附**（如举族迁徙）；3) **核心战兽王者回归**并带来族群。
- **节点·静默蓄势与时限压迫**：用具体时间（如“最后一个月”）标注危机节点。在倒计时中，穿插支线探索、情感戏或日常，形成“风暴前的压抑”氛围。**编辑动作**：每隔3-5章重申一次剩余时间。
- **节点·分身并行与效率叙事**：在时间紧迫时，让主角分身处理支线任务（如研究禁制、探索地图），本尊坚守主线核心。实现双线并行，加快叙事效率，并可通过分身遭遇铺垫新危机。
- **节点·地图解锁与指引**：在完成当前阶段目标时，必须获得通往更高级世界/地图的明确“钥匙”或线索（如通道坐标、指引罗盘）。**规则**：旧地图价值耗尽前，必须埋好新地图的跳板。
- **节点·规则制定者跃升**：主角从利用规则，升级到为一方世界制定新规则（如设定飞升法则、重定轮回）。这是权力层级的本质跃升，需通过具体、可视化的“仪式”（聚大陆、引星河）来完成。
- **节点·终极谜题前置**：在最终高潮来临前，明确抛出故事最核心的未解之谜（如“第三魂是谁？”），将其作为贯穿高潮部分的终极悬念，牵引读者。**手法**：通过主角的内心梳理或智者对话提出。

## 2) 节奏结构与卡点（规则库）
**核心原则**：节奏是情绪和信息的控制器，通过“张弛交替”和“精准卡点”操纵读者体验。
- **节奏·三明治与对冲**：高强度战斗/冲突 → 深度文戏/情感抉择 → 日常探索/喜剧调剂。**关键**：将宏大世界观揭秘与细腻个人情感戏放在相邻章节，用情绪反差增强各自感染力。
- **节奏·悬停与膨胀**：在角色做出重大抉择或行动前，插入大段沉默、环境描写、他人视角观察，拉长心理时间，强化分量。**搭配**：“静默爆发”模式——长时间静止后突然睁眼展开雷霆行动。
- **卡点·信息爆点**：在章节末尾，借角色之口抛出颠覆性信息（如身份揭露、世界真相），直接切断。让主角与读者同时陷入震撼，且信息给到“七分留三分”。
- **卡点·情感临界点**：将主角的情感最终答复，卡在“对方即将彻底死心或离开”的临界点。或将深情角色的离别，卡在一个未完成的陪伴时长上（如“十一个月，还差一个月”），制造余韵。
- **卡点·援军登场与威慑**：在主角被多方锁定、局势压抑时，让关键援军以“代为出手”的方式高调登场，以一敌多，瞬间扭转气氛；或让主角端坐于巨兽之上，以“静态场景”宣告绝对掌控力。
- **卡点·探索发现**：在支线探索末尾，揭示远超预期的惊人真相（如通道通往更高级世界），直接拔高整条支线的战略价值。
- **节奏·解说分割**：大段世界观解说或技术讲解后，必须紧跟外部事件打断（敌袭）、动作描写或切入另一条故事线，避免冗长。
- **节奏·并行交叉与竞速**：在最终高潮，严格交替描写“主角行动线”与“反派进展线”，利用“谁更快”的信息差制造窒息般的紧迫感。
- **卡点·终极反问与宣告**：在智斗高潮，让主角提出一个直指对手核心弱点的终极质问（“你能复制这个吗？”）；或在其掌握优势时，发出“游戏结束”的宣告，标志清算开始。
- **节奏·单元闭环与引波**：一个剧情单元结束时，必须抛出下一个单元的明确目标。并在大阶段收尾后，平滑切换至另一独立势力的行动镜头，悄然拉开新篇章。

## 4) 冲突模板与推进套路
**核心原则**：冲突需多层次、多维度，从武力对抗升维至认知、规则、心理的博弈。
- **模板·情义两难与代价**：一方以巨大付出和牺牲为代价，要求主角在感情/道义上做出承诺，将恩义与个人情感/原则置于剧烈冲突中。**升级**：冲突核心是“拯救世界”的使命与主角需付出的“生命、名誉、羁绊”等个人代价之间的撕裂。
- **模板·认知之战与虚实**：用确凿证据冲击主角自我构建的认知（如“那是一场梦”），制造“何谓真实”的根本性迷茫。**进阶**：通过“镜像对手”复制主角能力，冲突核心变为“找出我与他的本质不同”。
- **模板·规则游戏与阳谋**：对手将对抗包装成有规则的“游戏”。高级破局在于主角接受并利用其规则，甚至制定新的“阳谋”规则，逼对手在明牌状态下对决。
- **套路·信息差碾压**：主角掌握敌方未知的关键信息（如世界真相、自身唯一性），在敌方尚在表层谋划时，主角已开始针对性布局，形成降维打击。**推进**：冲突即双方缩小“认知差”直至反超的过程。
- **模板·威慑平衡与博弈**：主角持有短期内无法被抵挡的“威慑性武器”（如限次神弓），与实力更强的敌人们形成恐怖平衡。冲突围绕“何时、如何打破平衡”以及彼此的误判展开。
- **模板·父权对峙与守护证明**：强势父辈角色为子女幸福，以武力、势力、道理三层压迫主角。冲突可转化为该父辈通过为保护主角阵营而战，来证明诚意、换取信任。
- **套路·解说完即破局**：当一方长篇解说自身悲惨过往或复杂局势后，另一方用简洁行动（如“我帮你封印了她”）或更高层次认知直接破局，形成节奏爽点。
- **模板·内部猜疑链与被迫合作**：在多人临时联盟中，制造信息不对称，使彼此猜忌。冲突从外部敌人延伸至内部，合作充满试探与潜在的背叛。
- **模板·宿敌的“养蛊”与反噬**：对手刻意培养主角，将其视为成熟的“果实”。冲突充满被操控的愤怒，高潮在于主角如何让对手的“养蛊”计划反向吞噬其自身。
- **模板·身份谜团与血脉冲突**：角色身份成谜（是谁的转世/分魂？），其自身认知与他人认知产生冲突。可结合“正统血脉后裔”与“野生奋斗者”的对比，制造关于天赋、努力与出身认可的深层冲突。

## 5) 升级/爽点/回报机制（公式）
**核心原则**：爽点是期待的兑现，回报是长期投入的闭环。需具体、可视、有对比。
- **爽点·权威屈尊与高位期待**：地位/修为远高于主角的权威强者（大天尊、一方老祖），为子女或道义，对主角放下身段、步步退让，甚至带有一丝哀求。或直接表达对主角的欣赏与期待，给予“身份预期”爽点。
- **爽点·全场见证的承诺与情感闭环**：在众人注视下，主角做出重大、艰难的情感承诺，粉碎所有顾虑。或角色经过漫长岁月，终于理解另一方的苦心，愧疚与感动交织，完成情感闭环。
- **爽点·唯一性破局与认知反超**：当所有常规能力被复制时，主角凭借其独有的、无法被复制的特质（特殊血脉、契约）打破僵局。或主角从被蒙蔽到彻底看穿对手全盘算计，实现智力碾压。
- **回报·战力整合与资源连锁**：长期失散的核心宠物/坐骑，以更强形态回归并带来族群。一处险地的探索，必须产出复合型、链条式回报（血脉、肢体、神通、本源），形成“一处冒险，全面发展”的高密度爽点。
- **爽点·仪式感晋升与对比碾压**：将关键升级设计成有特定地点、条件的“仪式”，伴随天地异象和外界（特别是高层次人物）的震惊围观。并详细描写“普通天才”的成就，再让主角大幅超越，制造对比爽感。
- **回报·能力回收与体系重构**：消散的本源力量以更宏大的方式（火海归目、雷霆入瞳）召唤回归。阶段胜利后，系统地、逐一重铸自身力量体系，清晰展示完整能力面板，并宣告获得参与下一阶段角逐的“资格”。
- **爽点·威慑力兑现与暴力美学**：前期铺垫的“威慑性武器”在关键时刻连续使用，威力符合甚至超出预期，干净利落解决强敌。强者战斗描写不重过程，重结果宣告与简洁判决，彰显绝对力量。
- **回报·信息优势与战略欺骗成功**：主角因知晓世界真相而制定的、被他人视为疯狂的计划，在最后一刻完美触发。或通过一系列行为成功误导所有敌人，使其对主角的真实意图产生严重误判。
- **爽点·身份揭露与逆袭打脸**：长期以滑稽/弱小形象出现的配角，其真实身份（与重要伏笔人物关联）被突然揭露。或描写高位反派因嫉妒产生的阴暗心理，为主角未来抵达高位后的“打脸”埋下预期爽点。
- **回报·守护家园与情感锚定**：个人成长后，将新获得的顶级能力用于加固家园防御或强化核心盟友，将个人力量转化为集体福祉，满足“荣归故里、福泽亲朋”的情感需求。
