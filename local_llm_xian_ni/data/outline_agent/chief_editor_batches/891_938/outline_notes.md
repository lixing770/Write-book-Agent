# 主编知识库总纲｜通用网文写作（融合最终版）

---

## 1) 主线推进与阶段节点（模板）
*用于规划剧情大阶段转换，确保主线不散、动力不竭。*

- **<情感锚点回归>**：主线高强度推进后，安排主角回归初始情感锚点（家乡、师门）。**触发条件**：完成一个大地图征服或重大复仇后。**编辑动作**：1）描写物是人非的强烈反差；2）安排一场情感宣泄（跪拜、静思）；3）回收或激活一条旧支线。**目的**：缓冲节奏，重塑人格，深化角色根基。
- **<外部冲突内化>**：将世界级宏大冲突（宗门大战、星域争端）通过具体事件（族人被害、故地被侵）牵引至主角个人圈层。**触发条件**：需要将“为天下”的宏大目标转为个人驱动力时。**编辑动作**：设计一个侵害主角核心守护对象的“导火索”事件。**目的**：使主线矛盾从“对外征服”升华为“对内守护”，极大提升代入感。
- **<战力验证与清场>**：进入新地图或回归旧地图时，设计一场“不对称碾压”战斗。**触发条件**：主角实力远超当前环境平均水平。**编辑动作**：采用“神识/领域一扫，杂兵清场”的写法，聚焦核心冲突。**目的**：直观展示主角当前段位的绝对实力，稳固读者“强者归来”的预期，快速推进剧情。
- **<信息拼图与阴谋揭露>**：通过击败特定敌人、搜魂或探索遗迹，揭露世界观核心设定的一块“拼图”。**触发条件**：表层冲突解决后，需将剧情推向更深层。**编辑动作**：1）让战利品（记忆、玉简、古籍）承载关键信息；2）信息分多次释放，逐步拼出庞大阴谋轮廓。**目的**：将剧情从“解决问题”升级为“探查根源”，牵引出更高层级的敌对势力。
- **<旧线回收与势力重组>**：回归故地时，主动触碰并回收尘封支线（旧势力、未解之谜），同时清算与重组旧有关系网络。**编辑动作**：1）通过旧识/后人的对话，侧面交代世界格局变迁；2）对过往恩怨（恩、仇）进行一次性了结或再绑定。**目的**：增加剧情厚度，为主角构建稳固的“基本盘”或明确的仇敌名单。
- **<目标转换：从被动到主动>**：主角从“躲避/探索”状态，转为“主动狩猎/破解”。**触发条件**：掌握足够信息，实力得到验证后。**编辑动作**：主角明确宣布下一个打击目标（如“凤栾星，尸阴宗”），并立刻展开行动。**目的**：增强主角的掌控感和剧情侵略性。
- **<资源整合与仆从收纳>**：击败强敌后，非必杀。可设计“强制收服”桥段。**触发条件**：敌人有特殊能力、身份或信息价值。**编辑动作**：以绝对手段（奴印、封印）收服，并点明其后续功能（战力、向导、信息库）。**目的**：增加主角方战力厚度，埋下“忠诚度”冲突伏笔，满足掌控感。
- **<心境淬炼与意义赋予>**：在故地独处或激战间隙，安排一场无声的“心境淬炼”。**编辑动作**：通过追忆过往，与自身对话，完成对当前力量的“意义赋予”（为何而战）。**目的**：为下一阶段更残酷的征战做好精神铺垫，提升角色深度。
- **<舞台升维与终极冒险>**：当当前地图矛盾激化到顶点，将核心冲突导入更高级空间（星空虚无、神兽体内）。**触发条件**：现有舞台无法承载更高层次的力量对决或秘密。**编辑动作**：引入环境规则突变（如压制所有元力），迫使所有人站在新起跑线。**目的**：开启新副本，为主角利用独特优势（如古神肉身）渔利创造舞台。
- **<离场铺垫与新征程预告>**：离开当前地图前，进行最后一次检视或意味深长的告别。**编辑动作**：1）“神识横扫”故乡；2）与关键旧人进行简短对话；3）通过外界信息（追杀令、大军动向）将视角拉回主舞台。**目的**：营造“事了拂衣去”的洒脱感，并明确预告下一阶段的主战场。

## 2) 节奏结构与卡点（规则库）
*控制章节张弛与阅读心流，确保每章都有钩子和闭环。*

- **<张弛交替定律>**：高强度战斗/冲突章节（1-2章）后，必须接续1章情感沉淀、信息交代或日常过渡。**检查点**：连续三章是否让读者神经紧绷？**编辑动作**：插入主角悟道、旧人重逢、环境描写等缓冲内容。
- **<战斗节奏模板>**：
    - **重要战斗三拍**：起势（敌方狰狞+旁观者预期）→ 碾压（主角轻描淡写破解）→ 收尾（结果+旁观者震撼）。避免冗长缠斗。
    - **五五三一法则**（势均力敌时）：五分试探，五分周旋，三分对轰，一分底牌决胜。
    - **层次感战斗**：仆从清场铺垫 → 主角神通对轰 → 底牌尽出碾压终局。
- **<信息投放节奏>**：关键信息绝不一次性抛出。**编辑动作**：1）先通过对话透露边角，制造疑惑；2）在后续行动中逐步验证、补全；3）一次遭遇只释放1-2个关键新信息。
- **<情绪管理>**：
    - **情绪蓄水池**：在铺垫章节中持续积累单一情绪（如悲哀），通过一个具体意象（坟冢、老树）触发决堤式宣泄。
    - **情感宣泄点前置**：在进入新紧张剧情前，先安排一个情感了结点，释放读者情绪。
- **<视角切换技巧>**：
    - **旁观者烘托**：主角展示实力时，果断切换至多个旁观者（敌、友、路人）的内心震惊，以烘托威势。
    - **收放自如**：广角（全局战况）→ 中景（关键对决）→ 特写（主角行动）。宏观与微观结合，避免疲劳。
- **<悬念与钩子设置>**：
    - **宁静中的风暴眼**：过渡章末尾，插入微小但反常的细节（路人惨案、天空异象），预示风暴。
    - **倒计时压力**：植入无形消耗（元力被持续封印），让所有行动与“流失感”赛跑。
    - **延迟满足**：主角获得新底牌后，不立即用于终极战，先清理杂兵进行“预演”，积累期待。
- **<章节闭环与收尾>**：
    - **小事件闭环**：单章内完成“发现异常→调查→解决→收获”的闭环，保证独立可读性。
    - **指令式收尾**：章末以主角简洁有力的指令结尾（如“塔山，把人带来”），自然衔接下章开场。
    - **留白式收尾**：用平静场景或内心独白收尾，留下余韵，不一定总是高潮钩子。

    3.  “修真联盟杀域界，特来取你性命！”

    5.  女子眼中惊慌，厉声道：“我是凤栾星七凤之一，你敢杀我！”
    6.  阵法开启中，他们的身影正在缓缓消失。“走不掉！”
    7.  威压滔天，他脚下的星空寸寸碎裂，整个人就要被压入虚无！

    3.  这密令的内容，以他的修为，竟也无法从记忆中搜出半分！

    5.  这一幕，即便是他，也不由得面色大变！
