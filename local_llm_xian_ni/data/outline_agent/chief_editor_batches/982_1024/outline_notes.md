# 主编知识库总纲｜通用网文写作（融合精修版）

## 1) 主线推进与阶段节点（操作模板）
*用于规划剧情大单元，确保推进有力、节点清晰。*

- **<道具/力量阶梯解锁>**
    - **触发条件**：获得关键道具（古神法器）或接触核心力量。
    - **检查点**：解锁过程是否多于一步？是否关联了更深层世界观或发布了新任务？
    - **编辑动作**：设计“解封-触媒-信息喷射”三连击。第一层解封获宝，第二层满足特殊条件（血脉、信物）触发核心封印，第三层破解后引发异象并喷射关键信息（如古神求救、传承线索），直接推动主线。

- **<感悟破境与外部冲突>**
    - **触发条件**：主角需要实现战力或境界的质变（如自创神通、觉醒血脉）。
    - **检查点**：长期“悟道”是否提供了外部冲突（偷袭、入侵）的时间窗口？突破瞬间是否有可视化、震撼性的展示？
    - **编辑动作**：安排主角进入长期（数月/年）沉浸状态。**必须**同时安排一条或多条外部时间线并行（如强敌动向、内患滋生），并在主角突破的**关键时刻**引爆冲突，实现“临阵突破、瞬间翻盘”。

- **<支线收束与主线绑定>**
    - **触发条件**：次要人物（神奴后裔）的独立支线（梦境、寻仇）发展到关键节点。
    - **检查点**：该支线的悬念是否通过一个动作（如滴血认证、传承共鸣）与主角的核心设定强行绑定？
    - **编辑动作**：将配角的个人谜题，转化为解读主角核心设定（古神、仙帝）的世界观拼图，并赋予配角新的功能（向导、宿敌、钥匙）。

- **<战力整合与公示>**
    - **触发条件**：一个剧情大阶段（如炼宝、悟道、收仆）结束，准备进入新地图前。
    - **检查点**：读者是否清晰主角当前所有底牌？新获得的力量是否有过“演示战”？
    - **编辑动作**：用一小节让主角清点收获（新法宝、新神通、新下属、新情报），形成明确的“战力组合包”。**必须**为标志性新力量安排一场“实力演示战”，用已知强敌（净涅修士）的惨败来量化其天花板。

- **<地图转换与舞台搭建>**
    - **触发条件**：当前地图核心目标完成，需开启新篇章。
    - **检查点**：转换是集体行为吗？新地图的规则和危机是否已初步显现？
    - **编辑动作**：通过主角行动（集齐钥匙）触发全图级异象，强制将所有势力传送至新地图。进入后，立刻通过主角“试错”遭遇环境危机（诡异旋风），亲身感受并总结**不可提前说明**的诡异规则（如攻击会倍增敌人），制造探索感与紧迫感。

- **<势力养成与王者归来>**
    - **触发条件**：主角离开某势力范围较长时期（数百章/年）后回归。
    - **检查点**：势力是否因主角留下的“种子”（功法、理念）而独立成长？回归时的情绪冲击（狂热崇拜）是否拉满？
    - **编辑动作**：用时间跳跃（数百年）展示势力指数级成长。主角回归时，描写旧部的绝对忠诚与集体狂热呐喊，享受“身份反转”（从外来者到精神象征）的顶级爽点，并直接接收现成的强大基业。

- **<终极悬念前置>**
    - **触发条件**：一个大型副本（如仙府）即将深入核心。
    - **检查点**：是否在阶段末尾设置了一个“静止的恐怖存在”？
    - **编辑动作**：在新地图深处（如桥头、王座）设置一个仅通过氛围（滔天煞气）、外貌（无眼流血）和低语（“饥饿”）渲染的终极存在，作为下一大阶段的终极悬念和Boss预埋，暂不展开。

## 2) 节奏结构与卡点（规则库）
*用于控制章节和段落内的情绪曲线，避免平铺直叙。*

- **<张弛交替铁律>**
    - **规则**：任何高强度情节（战斗、破解、危机）之后，必须接入低强度缓冲（对话、感悟、景色描写）。
    - **编辑动作**：明确规划情节波浪线：战斗→日常闲聊→技术攻关→情感深谈→大战前宁静。严禁连续三章同一高强度情绪。

- **<长线压抑，短线爆发>**
    - **规则**：长期的积累（行走、悟道、忍耐）必须用瞬间的、可视化的爆发来兑现爽点。
    - **编辑动作**：用超长篇幅铺垫压抑（半年孤独行走），在读者耐受极限时，安排一次彻底的、带有宏大异象的力量或情绪爆发（残夜撕天、雀鸣震界）。

- **<三幕式结构应用>**
    - **感悟三幕**：1) 偶然进入状态，懵懂追寻；2) 长期求不得，但感渐近；3) 契机下瞬间明悟，异象升华。
    - **危机三幕**：1) 初见危机，尝试常规应对；2) 应对失效，危机加剧；3) 找到关键解法或动用底牌，破局/惨胜。
    - **编辑动作**：将长剧情拆解为清晰的“起（铺垫）-承（发展）-转（高潮）”三阶段。

- **<信息与情绪卡点>**
    - **信息卡点**：关键世界观分两次投放。先展示现象（角色怪异行为、环境异象）引发疑问，后续再通过记忆、对话解释原因。
    - **情绪卡点**：在释放大型情感爆点（回忆故人）前，先进行小铺垫（取出信物、相似场景），让情绪自然累积，然后快速收束。
    - **章末卡点**：停止在：1) 新势力/人物突然介入；2) 关键问题被提出；3) 技能施展到一半；4) 重大真相揭晓前一刻；5) 认知被颠覆的瞬间。

- **<围观者效应与侧面烘托>**
    - **规则**：主角进行关键操作或展示实力时，必须安排多个层次的配角（同伴、敌人、路人）作为围观者。
    - **编辑动作**：通过围观者的震惊、议论、猜测和实力对比（“即便凌天候也做不到”），来侧面烘托场面的震撼程度和主角的实力位阶。

- **<多线预热与并行剪影>**
    - **规则**：当主线平稳时，需插入其他势力的动态；当大事件爆发时，需快速切换不同地点的反应。
    - **编辑动作**：用简短旁白或他人对话插入其他星域战事。在主角引发天地异象时，快速切换至天运子、虚空子等巨擘的震惊反应，证明事件影响力。

## 3) 章末钩子库（可直接选用）
*用于制造悬念，引导读者追读下一章。*

1.  就在这一瞬间，他瞳孔骤缩，看到了绝不该出现在此地之物！
2.  那威严的声音，竟来自一个早已被记载陨落万古的存在……
3.  “救我者，可得……（巨大悬赏）！”神念中的遗言，揭开了一场跨越时空的阴谋。
4.  庞大虚影缓缓低头，其眉心处旋转的星点，赫然是传说中的……（突破常识的数量）！
5.  闭关的关键时刻，一道满怀恶意的身影，悄然撕裂了护法大阵。
6.  面对那足以碾碎星辰的轰击，他只是抬起手，轻吐二字：“……（神通名）。”
7.  记忆的封印层层剥落，他终于看清，那梦中反复出现的祭坛上，跪拜的竟是……自己。
8.  “你刚才施展的，可是……自创神通？”败者的颤声发问，印证了一个传奇的诞生。
9.  一股他很久没有感受过的生死危机，骤然降临！
10. 所有的攻击，在触碰到那层薄光的瞬间，无声消散。
11. 答案就在眼前，但他伸出的手，却停在了半空。
12. 一声惊天动地的雀鸣，撕裂了此界虚空，也传入了所有巨擘老祖的耳中！
13. 一张没有双眼、流淌黑血的脸，自煞气中缓缓抬起。

## 4) 冲突模板与推进套路
*用于快速生成有效矛盾，推动情节发展。*

- **<内部隐患消化>**
    - **套路**：收服强力角色→其因惩罚暂时屈服→在主角脆弱期（悟道）试探/反叛→被主角以新力量碾压→彻底归心。
    - **关键操作**：反叛目的必须是“试探”而非“真杀”，战后需有角色心态彻底转化的描写。

- **<认知颠覆碾压>**
    - **套路**：配角基于常识预判主角行为→主角行为结果远超其认知→配角世界观受冲击，产生敬畏/恐惧。
    - **关键操作**：用于强化主角特殊性。配角的常识越坚实，颠覆时的震撼感越强。

- **<规则/环境型冲突>**
    - **套路**：主角陷入未知环境，环境本身或其规则（如“攻击使敌人倍增”）成为主要矛盾。
    - **关键操作**：**绝不事先说明规则**。让主角通过试错（常规攻击无效且加剧危机）来惨痛总结，读者同步学习。

- **<信息差博弈>**
    - **套路**：配角知晓部分秘密→向主角求证→主角掌握更核心信息但无法全盘托出→产生猜疑、追随或依赖的关系张力。
    - **关键操作**：信息差是高级冲突燃料，可用于制造悬疑、促成临时结盟或引发背叛。

- **<代价破局>**
    - **套路**：为达成核心目标（进入秘地、获得力量），必须接受某方提出的交易或付出某种明确代价（形貌大变、根基受损）。
    - **关键操作**：代价必须清晰、严重，且支付后能立即获得阶段性关键回报，让“痛苦”与“收益”对等。

- **<守护/救援冲突>**
    - **套路**：外部强敌为夺宝/杀人闯入，或同伴陷入绝境（中毒、坠落），主角方被迫迎战或逆流救援。
    - **关键操作**：在集体逃生场景中，安排主角**放弃率先逃生，选择逆流救援**，将个人冲突升华为“情义与生存”的冲突。

## 5) 升级/爽点/回报机制（公式）
*用于设计让读者感到满足和兴奋的情节回报。*

- **<专属认证式爽点>**
    - **公式**：宝物/神通设有极高门槛（仅古神血脉可炼）→主角恰好满足→轻松获得他人无法使用的至宝。
    - **编辑动作**：强调门槛的绝对性，渲染他人尝试失败的狼狈，反衬主角获得的轻松与必然。

- **<自创神通验证>**
    - **公式**：悟出独有神通→立刻安排足够分量的对手（净涅修士）进行实战检验→造成震撼效果→伴随旁观者震惊确认。
    - **编辑动作**：检验战必须快速、碾压，对手的骇然与道心崩溃是爽点的重要组成部分。
