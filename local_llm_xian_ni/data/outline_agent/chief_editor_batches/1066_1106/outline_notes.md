# 主编知识库总纲｜通用网文写作

## 1) 主线推进与阶段节点（模板）
*   **<阶段突破/觉醒>**：以一次标志性突破（破境、获宝、血脉觉醒）作为当前地图/副本的胜利点，强行扭转绝望局势。**触发条件**：主角被逼至绝境、重要配角牺牲、倒计时结束。**编辑动作**：详细描写突破时的异象、代价及对周边战局的即时影响。
*   **<连锁反应>**：主角的关键行动（突破、击杀）引发高阶存在、远方势力或世界规则（如命牌碎裂、天地钟鸣）的响应。**检查点**：主角行动后，必须切1-2个外部视角，展现涟漪效应。
*   **<计谋揭晓/阳谋驱动>**：当事件按表面逻辑发展时，揭露某方（常为反派或主角自身）更深层的算计，或将个人恩怨升维绑定宏大主线。**触发条件**：局势陷入僵局或看似尘埃落定时。**写法**：通过角色自白、信息差揭露，将此前所有“意外”串联为必然；或摆出对手无法拒绝的“阳谋”。
*   **<责任召唤/使命绑定>**：设置超越个人恩怨的宏大使命（对抗外敌、光复宗门、复活至亲），与主角情感线交织。**检查点**：在主角获得重大力量或身份后，通过“临终托付”或“传承揭秘”节点投放。
*   **<绝地反转/底牌逆转>**：反派胜券在握时，利用其未察觉的规则漏洞、主角预留的暗手或临时解锁的终极底牌实现逆转。**关键**：底牌必须前文有伏笔（能力预埋、物品预置），反转逻辑需自洽。
*   **<牺牲铺路>**：安排重要配角在关键时刻牺牲（自爆、献祭），为主角争取时间或创造破局条件。**编辑动作**：牺牲前必须完成该配角的情感或使命刻画，牺牲瞬间应有慢镜头描写及主角的情绪爆发。
*   **<新势介入/格局升级>**：当内部矛盾激化到顶点，引入强大的第三方外部势力（主角背后宗门、世界守护者、跨界存在）打破僵局，或将个人冲突直接上升为势力战争、全域通缉。**写法**：新势力登场需伴随“仪式性展示”（撕裂空间、圣器现世）和他人反应烘托。
*   **<多线收束/冲突总爆发>**：将此前分散的剧情线（不同角色的探索、远方布局）在同一时间点、同一场景下强行收拢，制造信息爆炸与终极围杀局。**节奏**：收束前需通过快速视角切换铺垫各方动向。
*   **<新地图开启/传承接引>**：当前地图因大战崩溃或核心目标达成后，通过“传承接引”、“坐标锁定”或“碎片化星图”自然过渡到更广阔的世界。**检查点**：必须结算当前阶段的得失（代价清算），并点明下一阶段核心目标（如修习某传承）。
*   **<身份认证与权威建立>**：主角通过考验或战绩，被权威势力“盖章”赋予新身份（圣皇、宗主），此身份将成为后续所有冲突的新引力源。**必要环节**：安排“内部挑战”和“首次行使权柄”剧情以立威。

## 2) 节奏结构与卡点（规则库）
*   **<张弛交替法则>**：高密度战斗/解密章节（2-3章）后，必须插入短暂的情感闪回、世界观阐述或势力反应章节，调节读者神经。**检查清单**：是否有连续五章都在高强度战斗？
*   **<倒计时压迫>**：设置明确危机倒计时（封印瓦解、强敌降临）。**写法**：每一章都需通过环境描写、角色心理或直接提示，展现时间流逝和危机临近感。
*   **<信息分层释放>**：关键信息分三层释放：本章给线索（如异常现象），下章给部分真相（角色推测），隔章再给完整全景（权威角色解释或记忆揭示）。
*   **<中断高潮>**：在绝招对轰、生死一瞬的关键帧，果断切到另一条剧情线（远方援军动态、重要人物回忆）。**卡点位置**：招式名喊出后、对撞结果未明时。
*   **<情绪与战斗的螺旋>**：
    *   **濒死反击节奏**：被逼至绝境 → 内心爆发不屈意志/回忆杀 → 施展预留或临阵突破的终极手段。
    *   **毁灭宣泄节奏**：详细描写终极神通的施展过程、天地异象与碾压式摧毁。
    *   **代价插入节奏**：胜利描述后，立即插入主角内部视角的伤势剧痛、元神虚弱描写，形成爽感与压力的张弛。
*   **<旁观者反应镜头组>**：主角突破或施展震撼神通时，节奏需从个人视角拉远，切换到多个地点、多个相关角色的观察与震惊反应，营造“万众瞩目”感。
*   **<战斗嵌套与视角切换>**：多场战斗同时进行时，通过快速视角切换制造平行紧张感，并在关键时刻进行交叉影响（如A战场余波影响B战场）。
*   **<仪式感段落>**：大战结束后，描写战场清理、力量吸收、天地复归平静的“仪式感”段落，或安排“登基大典”等盛大场景，用于情绪沉淀和情报释放。
*   **<最后变数>**：在看似一切尘埃落定时，引入一个全新的、意料之外但情理之中的变数（隐藏守护者出现、规则第二层触发），将剧情再次推向未知。**用于章节结尾**。
*   **<缓冲带设置>**：在连续高压情节后，必须插入“老友重逢、把酒论道”或“照料灵兽”的舒缓剧情，调节叙事呼吸感。

## 4) 冲突模板与推进套路
*   **<三方混战与博弈>**：构建A（主角）、B（反派）、C（第三方）三方互相牵制、敌友难分的局面。**推进**：任何两方交战都可能让第三方得利，冲突随信息揭露和利益变化而摇摆。
*   **<认知/规则碾压>**：反派自以为掌控一切，实则其行动完全在更高层次存在的计算/规则之内；或主角施展超出当前世界普遍认知的神通，形成降维打击。**关键**：通过对手的惊骇自语或旁观高手点出来解释。
*   **<护短触发（最稳固根源）>**：主角核心关系圈（宠物、亲友、宗门）遭受侵犯。**推进**：情感纽带越深，反击理由越充分→坐标锁定→客场威慑→精确复仇。
*   **<阳谋压迫/钓鱼执法>**：给出无法拒绝但不利的选择题，或主动释放诱饵信息，让对手明知是局也不得不入。**写法**：冲突根源在于战略选择，而非误会。
*   **<信息差博弈>**：各方因掌握信息不同（真假、多少）而产生误判、猜疑链与联合。**推进**：冲突随信息逐步揭露而升级、反转。
*   **<内部挑战（权威建立）>**：新领袖上位，原有既得利益者公开质疑。**模板**：质疑→以规则/传统为名发起挑战→主角以碾压性力量瞬间解决立威。
*   **<情感与责任对冲>**：重要角色身处敌对面，或主角个人目标与集体责任冲突。**触发**：在高压情境下迫使主角做出艰难选择，并立刻展现代价。
*   **<生存空间争夺>**：冲突本质上升至种群、文明生存资源的争夺（气运、地域），使矛盾具备必然性与宏大性。
*   **<困兽之斗与绝望梯度>**：敌人在绝境下解开封印、燃烧本源进入“第二阶段”。**写法**：详细描写敌方从傲慢、惊讶、恐惧到绝望的情绪跌落过程。
*   **<援军阻断与孤岛困境>**：主角盟友被敌方分兵纠缠或援军被阻，使主角陷入短暂孤立，必须独自面对强敌。

## 5) 升级/爽点/回报机制（公式）
*   **<绝境融合/代价突破>**：濒死绝境中，被迫吸收多种同源力量，或燃烧本源/寿元换取临时境界暴涨。**公式**：详细描写痛苦与代价 → 突破后获得夸张能力增幅与专属特效 → 立即实证（越级碾压挑战者）。
*   **<认知即力量/规则认证>**：领悟世界观底层规则（因果、初之规则）。**爽点**：即使修为未升，也能碾压同阶。需通过对手或旁观者震惊叫破名称（“这是……规则之力！”）完成认证。
*   **<身份揭露/跃迁>**：隐藏身份（古神后裔）在关键时刻引发天地异象或被权威公开承认。**回报**：社会地位飙升，获得势力加持与庇护。
*   **<神器认主/传承归位>**：至高神器主动护主，或远古传承主动选择主角并当众融合。**写法**：伴随宏大仪式和旁观者朝拜般反应。
*   **<以彼之道还施彼身>**：用反派最擅长的手段在其面前施展得更完美，或将其攻击（天劫）吸收转化并反掷回去。**爽点**：实现精神与实力的双重打击。
*   **<资源收割公式>**：完成打脸或谈判后，获得“功法+法宝+材料+情报”组合包。**检查点**：每次冲突解决后，必须清晰展示战利品。
*   **<痛苦投资回报>**：详细描写修炼/突破的极致痛苦过程（经脉欲裂、肉身燃烧）。**规则**：痛苦描写越深，突破后的能力描述与特效需越夸张。
*   **<旁观烘托式>**：通过周围所有人（敌我双方）的集体沉默、骇然、恐惧反应，指数级放大主角战绩的震撼效果。
*   **<计划通快感>**：主角前期布下的局，在本阶段看到各方势力如预料般行动。**写法**：通过主角内心淡然或简短评价（“果然来了”）展现。
*   **<威慑留存>**：战后即使主角虚弱，但因余威骇人，敌人不敢趁虚而入。**写法**：通过敌方视角描写其恐惧与猜疑来展现。
