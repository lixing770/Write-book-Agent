## **模块1：主线推进与阶段节点（编剧引擎）**
**核心逻辑**：将长期目标拆解为可视化的阶段任务，通过“压力-破局-代价-晋级”循环驱动剧情。

### 可执行模板与检查点：
1.  **<阶段目标锚定>**：
    *   **触发条件**：主角进入新地图或完成上一阶段目标后。
    *   **编辑动作**：立即将主线拆解为当前场景下**具体、可衡量、有时限**的目标（如：“十日内，于宗门大比夺取第一”）。
    *   **检查点**：目标是否清晰到读者可以想象出达成的画面？

2.  **<张弛交替律>**：
    *   **触发条件**：连续高强度剧情（逃生/战斗/谈判）约2-3章后。
    *   **编辑动作**：**必须**插入“过渡章”，用于：①清点收获并锚定长期价值；②情感互动或日常描写；③通过配角对话铺垫下一舞台。
    *   **检查点**：读者情绪是否得到沉淀？信息是否消化？下阶段期待是否建立？

3.  **<舞台预搭与缺席威慑>**：
    *   **触发条件**：主角即将回归/抵达核心冲突场景（如大比、拍卖会）前。
    *   **编辑动作**：
        1.  **预搭舞台**：通过多方对话，充分铺垫场景的“传奇性”与众人对主角的“期待/质疑”。
        2.  **施压盟友**：在主角缺席时，将其盟友/红颜置于最不利境地（受辱、濒败），将读者期待转化为对“打脸”的迫切需求。
        3.  **侧面印证**：通过高手会议、传说转述，系统性披露主角未知的侧面战绩，二次拉升逼格。
    *   **检查点**：主角登场前，读者的期待值和情绪是否已蓄满？

4.  **<三段式回归与清算>**：
    *   **触发条件**：主角在万般期待中登场。
    *   **编辑动作**：严格按照“**天地异象 → 身影显现 → 威压笼罩/熟人反应**”的递进模板书写。登场即对前期所有矛盾进行一次性清算宣告。
    *   **检查点**：登场场面是否具有仪式感和戏剧张力？是否解决了旧矛盾并引入了新冲突？

5.  **<资源置换与地图跃迁>**：
    *   **触发条件**：主角在局部舞台（如分宗）证明绝对价值后。
    *   **编辑动作**：让主角以实力为筹码，与顶层势力谈判，直接换取**核心资源**或**整体晋升资格**（如：全宗迁往高阶地图）。这是推进主线的关键杠杆。
    *   **检查点**：交易是否清晰？主角的付出（战力展示）与回报（资源/地位）是否对等？

6.  **<生死锁局与破限>**：
    *   **触发条件**：主线进入中期，需要制造终极压力。
    *   **编辑动作**：
        1.  **设锁**：让主角被远超自身境界的强敌（如第三步大能）锁定为必杀目标。
        2.  **推演**：利用神通推演未来，呈现“所有可能皆为死局”的绝对绝望。
        3.  **锚点**：揭示唯一生机指向一个具体物品或地点，驱动主角从“逃避”转向“主动探寻/备战”。
    *   **检查点**：危机是否无法逃避？唯一生机的揭示是否合理且充满悬念？

## **模块2：节奏结构与卡点设计（导演手册）**
**核心逻辑**：通过控制信息释放、情绪涨落和视角切换，制造持续的吸引力与情绪体验。

### 可执行规则库：
1.  **<战斗节奏变速器>**：
    *   **通用公式**：“快（清杂）-> 慢（对峙/对话）-> 快（爆发决胜）”。
    *   **群体战**：明确划分敌人等级（红、蓝、金），规定何种等级参与何种层次战斗，乱中有序。
    *   **王战**：强制安排“王者单挑”环节，清空低阶单位，聚焦高端对决。
    *   **检查点**：战斗描写是否避免了冗长的“回合制”？是否有清晰的层次和焦点？

2.  **<情绪与张力控制>**：
    *   **窒息开局**：章节开头可直接抛出新危机或绝望推演结果，瞬间拉满张力。
    *   **张弛死锁**：在连续高潮（约3章）后，**必须**接入“静默期”（如疗伤、沉睡、日常），让情绪沉淀。
    *   **蓄势章节**：大战前，可用整章描写主角竭尽所能的战前准备，过程即是看点，积累“势能”。
    *   **震慑间隔**：主角两次强力出手之间，**必须**插入旁观者的集体反应描写，拉长情绪体验。
    *   **检查点**：章节间的情绪曲线是否有起伏？读者是否会感到持续疲劳或无聊？

3.  **<卡点与悬念手册>**：
    *   **视角切换卡点**：在主角线最紧张时（如逃生中途），硬切至另一条故事线（如宗门大比），利用牵挂制造抓心感。
    *   **信息差悬念**：利用视角差，让其他角色讨论主角时，信息滞后于读者已知的主角经历。
    *   **倒计时压迫**：明确给出危机降临的剩余时间（如“七日”），每一章都在消耗，营造窒息感。
    *   **终幕拉开**：倒计时归零时，让敌人以最具压迫感的方式（巨手破空）准时降临。
    *   **检查点**：每一章结尾是否留有明确的悬念或期待？是否能促使读者点击下一章？

4.  **<多线叙事与收束>**：
    *   **并置**：同一时间段，穿插描写主角、盟友、敌人、旁观者多线动态，制造全局紧张感。
    *   **收束**：前期分散的伏笔（人物、宝物、恩怨），需在核心冲突章节快速汇聚，形成合力。
    *   **检查点**：多线切换是否自然？是否服务于同一个核心冲突？

## **模块4：冲突模板与推进套路（冲突发生器）**
**核心逻辑**：冲突需层层升级，并混合外部动作与内部情感。

### 标准化冲突链：
1.  **<规则内碾压>**：
    *   **模板**：主角迟到 -> 盟友受辱/濒败 -> 主角登场 -> 以规则允许的方式（如大比挑战）碾压寻衅者 -> 瞬间解决小冲突。
    *   **推进**：立刻埋下更大冲突引线（围观者中的仇敌、高层审视）。

2.  **<强闯山门/资源征用>**：
    *   **模板**：目标明确（用传送阵）-> 遭遇本地规则阻碍 -> 以杀气与实力威慑 -> 暴力破局（眼神伤人、强充能量）-> 留下破坏与补偿承诺。
    *   **核心**：展示“效率碾压”与“恐惧统治”，冲突在于“流程与暴力的矛盾”。

3.  **<认知碾压与身份天堑>**：
    *   **模板**：反派基于旧认知（主角百年前修为）行动 -> 主角展现颠覆性实力 -> 反派认知崩溃，冲突从“胜负”升维为“生存恐惧”。
    *   **高阶变体**：第三步大能对第二步主角的“绝对力量碾压”，冲突核心是主角的“绝境反击意志”。

4.  **<情感绑架与牵连之劫>**：
    *   **模板**：主角的危机迅速波及其在乎的人（红颜、宗门）-> 配角面临残酷抉择（宗门vs主角）-> 其牺牲或付出“绑架”读者情感，深化对反派的憎恶。
    *   **内部冲突**：主角得知真相后，情感愧疚转化为救援的绝对驱动力。

5.  **<谈判与规则博弈>**：
    *   **模板**：武力展示到顶峰后 -> 冲突焦点转向与顶层势力的“规则解释权”争夺或利益谈判 -> 主角以价值为筹码，换取资源或地位。
    *   **关键**：谈判中主角需把握节奏，显得游刃有余。

## **模块5：升级/爽点/回报机制（爽点配方）**
**核心逻辑**：爽点来自“预期违背”、“情感共鸣”和“成长可视化”。

### 高回报公式：
1.  **<延迟满足与天神下凡>**：
    *   **配方**：主角承诺回归 -> 盟友陷入绝境，希望渺茫 -> 在绝望顶点，主角以最震撼方式登场并瞬解危机。
    *   **关键**：前期的压抑必须足够充分。

2.  **<侧面印证与声望碾压>**：
    *   **配方**：不直接描写主角修炼，而是通过：①高手会议的震惊讨论；②旧识的惊叹回忆；③对手不战而怯的心理活动，来完成实力“认证”。
    *   **爽点**：读者享受“全知视角”的优越感。

3.  **<底蕴爆发与融合创新>**：
    *   **配方**：绝境下，主角将以往获得的、未完全炼化的多种力量（古神血、剑气、禁制）创造性融合，形成独有底牌，产生“1+1>2”效果。
    *   **关键**：需提前埋设这些组件。

4.  **<越级创伤与代价美学>**：
    *   **配方**：主角以毁灭自身部分根基（生机、法宝）为代价，对无法战胜的强敌造成 **“一滴血”** 级别的有效伤害。强调“蝼蚁亦可咬人”的悲壮爽感。
    *   **检查点**：代价必须具体、可视、让读者感到“肉痛”。

5.  **<认知刷新与信息特权>**：
    *   **配方**：当众人认为“这已是主角极限”时，立刻展示更颠覆认知的能力（如五道本源）；或让主角接触古老存在，获得关于世界本质的独家信息。
    *   **爽点**：持续突破期待天花板，享受认知层面的优越。

6.  **<情感偿付与守护成功>**：
    *   **配方**：配角默默付出巨大牺牲（十年精血滋养）-> 主角知悉后，愧疚感转化为不顾一切的救援行动 -> 成功守护。
    *   **回报**：不仅是事件解决，更是情感债务的清偿，带来深沉满足感。
