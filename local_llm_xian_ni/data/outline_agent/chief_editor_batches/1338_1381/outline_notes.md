# 主编知识库总纲｜通用网文写作（融合最终版）

## 1) 主线推进与阶段节点（模板）
*【核心：提供从破局到颠覆的完整剧情链条，每个节点都应是明确的行动指令。】*

1.  **潜入与破局**：
    *   **<扮猪吃虎>**：主角以伪装身份进入高阶区域。**触发条件**：需获取新地图核心资源/信息。**检查点**：伪装逻辑需自洽，且需安排一个“验明正身”的小危机。
    *   **<规则破门>**：利用敌对势力内部规则（任务、禁地）的缝隙达成目的。**编辑动作**：进入新地图后，必须立刻通过NPC对话或告示，明确1-2条核心规则及其潜在漏洞。

2.  **探索与升级**：
    *   **<地图转换>**：从旧场景过渡到拥有独立规则的新核心区域（秘境、小世界）。**检查点**：转换需有明确理由（任务、追杀、追寻线索）和方法（通道、信物）。
    *   **<认知升级>**：主角发现颠覆性的世界真相（如世界为牢笼）。**触发条件**：接触核心区域遗迹或关键NPC。**编辑动作**：真相需分层次揭露，先由引导者讲述，后由主角亲眼验证。
    *   **<目标重构>**：将模糊目标（变强）重构为清晰、可收集的成长路径（集齐九道伴雷）。**检查点**：需在认知升级后立刻发生，并给出明确的“收集清单”。

3.  **冲突与清算**：
    *   **<狩猎模式/钓鱼执法>**：在封闭地图内，从被动转为主动，设饵批量清除敌人。**触发条件**：主角实力足以碾压地图内多数敌人，且拥有独特诱饵（如渡劫异象）。
    *   **<矛盾转移>**：将个人恩怨转化为与体制、规则的对抗。**检查点**：需有敌方高层代表出面，以规则压人，主角反抗的不仅是人，更是其代表的秩序。
    *   **<阶段清算>**：解决主要矛盾后，立即回头清算次要矛盾（惩罚算计者）。**编辑动作**：清算要快、狠、具有公开性，实现“现世报”爽感。

4.  **高潮与终局**：
    *   **<身份反转/战力展示>**：通过公开战斗或高层介入，颠覆旁观者认知，获得新身份（如少帝）。**检查点**：战斗必须公开，且有足够分量的观众；身份赋予需来自本世界顶级权力者。
    *   **<强敌显威与绝境反转>**：引入远超阶段的强敌（远古存在），将主角逼入绝境，后依靠至宝觉醒或能力吞噬实现反转。**触发条件**：主角触及世界核心秘密或资源时。**编辑动作**：反转需有伏笔（宝物长期陪伴），过程需描写“压迫-绝望-觉醒”的心理链条。
    *   **<终局之战与战利品收割>**：倾尽底牌解决长期铺垫的矛盾，并立即兑现战利品。**检查点**：必须回收前期伏笔；战利品清算需详细，转化为即战力。

5.  **转折与新篇**：
    *   **<新地图开放>**：通过打破囚笼、开启通道，进入更广阔世界。**编辑动作**：在终局尾声，通过NPC对话或天地异象，强烈暗示下一个舞台的存在。
    *   **<主动隐匿>**：制造大事件后，主角主动潜入凡俗消化收获。**检查点**：此阶段需有“暴风雨前的宁静”感，可穿插日常生活细节与内部修炼的凶险。

## 2) 节奏结构与卡点（规则库）
*【核心：控制情绪曲线，明确何时铺陈、何时爆发、何时缓冲。】*

1.  **铺垫期（缓）**：
    *   **<氛围定调/环境压迫>**：开篇用环境描写奠定基调，渲染新地图的奇异与压迫感。**检查点**：环境描写需与主角核心能力或后续冲突遥相呼应（如雷修入雷域）。
    *   **<旁白投料/信息前置>**：通过路人对话、交易见闻，自然投放基础世界观和危机信息。**编辑动作**：信息要碎，用生活化场景承载。
    *   **<转场预冲突>**：在新地图入口安排小型冲突，预示丛林法则。**检查点**：冲突要小，但需体现地图核心规则。

2.  **发展期（张）**：
    *   **<内景外显>**：修炼时，内部对抗与外部异象同步描写。**编辑动作**：修炼不是静坐，是内外两场战斗。
    *   **<群体蒙昧/旁观者震撼>**：描写配角的“常态”狂热，与主角的“异常”冷静形成对比，制造张力。
    *   **<危机倒计时/延迟救援>**：给出明确时间限制，或将支线危机与主线并行，拉伸期待感。

3.  **高潮期（急）**：
    *   **<压迫感三段式>**：1.敌展现实力；2.主角常规手段无效；3.主角濒临崩溃。**编辑动作**：逐步剥夺主角的优势，将读者情绪压至谷底。
    *   **<五息绝杀/回合制攻防>**：极限时间压迫，或将高手对决拆解为清晰回合。**检查点**：每回合需点明神通原理与心理博弈。
    *   **<视觉奇观层层加码>**：战斗规模从个人神通升级到世界结构崩溃。**编辑动作**：用环境崩溃侧面烘托战斗层级。
    *   **<悬念瞬时转移>**：一个高潮刚结束，立刻用更高位存在介入来衔接悬念。

4.  **回落期（弛）**：
    *   **<余波描写/心理防线瓦解>**：描写战斗对环境和敌人士气的毁灭性影响。
    *   **<对话缓释/追忆式讲述>**：用长对话释放世界观信息，缓冲节奏。
    *   **<凡间缓冲>**：大战后必须让主角“落地”，接触平凡生活，反衬消化此前经历。
    *   **<收尾即开篇>**：在平静尾声，埋下新悬念的引信。

## 3) 章末钩子库（可直接抄）
*【核心：在章节最关键时刻切断，迫使读者翻页。】*

1.  **危机降临**：一股他此生最为强烈的危机之感，轰然降临！/ 就在他即将捏碎逃生符的刹那，异变突生！
2.  **身份揭露**：“你，可知此物来历？”/ “这……这不可能！此物怎么会出现在你手中？！”
3.  **宣言挑衅**：“你要杀我？”/ “我在这里等你，可敢一战？”/ “XX，今日来此，收XX，灭你XX一族！”
4.  **惊骇发现**：他双眼瞳孔猛地一缩，露出无法置信之色。/ 看到这一幕的刹那，他神色轰然大变！
5.  **援手登场**：在他身后，传来一个冰冷至极的声音。/ 一道剑光，自天边呼啸而来。/ “道友，现在，轮到我的七成把握了。”
6.  **绝境抉择**：他眼中血丝弥漫，心中低吼：“只能赌一把了！”/ 面对绝杀一击，他不再后退，反而向前一步……
7.  **高层介入**：星空深处，数道目光，骤然凝聚于此。/ 一个陌生的声音，如天威般轰然降临！
8.  **悬念闪现**：记忆的尽头，是一道他熟悉的身影。/ 眼前这一幕，让他想起了数百年前的那场噩梦……
9.  **代价降临**：这，就是代价！/ 代价，才刚刚开始显现。
10. **新篇预告**：一切才刚刚开始，真正的风暴，还在后头。/ 他握紧手中之物，知道平静的日子，结束了。

## 4) 冲突模板与推进套路
*【核心：明确冲突类型、规模及升级路径。】*

1.  **小型冲突（立威、试探）**：
    *   **<层级碾压>**：低阶挑衅，高阶反杀。**核心**：描写被碾压者从嚣张到绝望的心理变化。
    *   **<主辱仆死>**：下属受辱，主角出手。**功能**：快速建立主角“护短”人设及行动合理性。
    *   **<新手陷阱>**：遭遇“热心引导者”团伙。**功能**：展示主角手段与地图险恶。

2.  **中型冲突（资源争夺、阵营对抗）**：
    *   **<钓鱼执法/阳谋交易>**：设饵或交易引敌上钩。**关键**：双方各怀鬼胎，交易即冲突。
    *   **<规则内击杀/围点打援>**：在无法监控区杀敌，或攻击次要目标引主力分批出动。**目的**：合理规避麻烦，实现逐个击破。
    *   **<认知冲突>**：主角真相 vs 配角常识。**推进**：冲突不仅是武力，更是世界观碰撞，最终以事实碾压。
    *   **<信息差冲突>**：一方掌握关键信息（宝物价值、规则漏洞）。**爽点**：另一方从轻视到落入陷阱。

3.  **大型冲突（势力对决、文明对抗）**：
    *   **<破阵诛心连环套>**：力破阵、言惑心、证诛心，三步摧毁敌方组织抵抗。
    *   **<第三方搅局/螳螂捕蝉>**：主角与A激战，更强第三方B介入抢夺核心资源。**效果**：瞬间拔高矛盾层次。
    *   **<信仰崩塌式冲突>**：公开击败敌方精神信仰，引发群体心理崩溃。**准备**：需长期铺垫该信仰的权威性。
    *   **<自救与救世绑定>**：个人目标与帮助受压迫群体反抗绑定，赋予行动宏大意义。

4.  **终极冲突（绝境反转、底牌对耗）**：
    *   **<以下克上>**：依靠地利、神通克制、外力、心理算计四要素弥补境界差。
    *   **<吞噬与反夺舍>**：体内形成“第二战场”，凶险异常。
    *   **<资源耗尽战>**：双方底牌与资源（寿元、分身、至宝）逐层对耗。
    *   **<意志对抗>**：上升至个人意志 vs 群体意志、逆天改命 vs 顺从命运的哲学层面。
