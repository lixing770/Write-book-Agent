# 仙逆 501-800｜情绪戏方法论总纲

## 1) 触发器谱系
**【外部触发】**
*   **规则/环境挑战**：极端试炼、规则羞辱、环境施压、条件赌约、时间压力。制造物理或规则困境，挤压情绪。
*   **信息/认知冲击**：真相揭露、谎言暴露、信息差显现、关联确认。冲击角色固有认知，引爆信任危机。
*   **人际关系对抗**：公开挑衅、行为羞辱、闯入对峙、身份冒犯（无视/俯视）。直接挑起人际冲突。
*   **存在/核心威胁**：身体/元神入侵、至亲/底线受胁、命令/威压降临、巅峰时刻突袭。威胁角色生存或根本安全。

**【内部触发】**
*   **欲望/执念引导**：希望诱饵、核心筹码、绝境交易邀约、瓶颈点拨。精准切入深层欲望，驱动角色行动。
*   **感官/情感共鸣**：感官体验（味、声、景）、记忆钥匙、求救/托付信号。触发深层情感与记忆，引发内心波澜。

**【交互触发】**
*   **行动-反应连锁**：先采取一个打破平衡的行动（如闯入、破坏规则），迫使对方反应，形成连锁冲突。

## 2) 阻力模型
**【内阻】角色内在障碍**
*   **心性/道义枷锁**：内心挣扎、道义责任、情感羁绊、承诺束缚、心魔/状态不稳。使角色在行动前自我辩论与抑制。
*   **认知/信息迷雾**：信息不对等、真相不明、自我欺骗、专业壁垒。阻碍角色做出清晰判断，情绪在猜疑中发酵。
*   **代价/风险恐惧**：行动代价过高（生命、底牌、资源）、目标冲突、如影随形的危机感。迫使角色极度谨慎，压制冲动。

**【外阻】外部环境压力**
*   **力量/层次压制**：绝对实力差、身份/权威压制、规则/制度牢笼、封印限制。形成难以逾越的客观障碍。
*   **环境/物理隔绝**：险恶环境、阵法禁制、物理距离、时间过程需求。从物理上限制情绪的直接碰撞。
*   **群体/关系牵制**：群体压力与从众、盟友依赖、内部猜忌、目标错位。使个人情绪受制于集体或复杂关系网。

## 3) 升级台阶模板（可复制）
**【三阶模板 · 快速对抗】**
1.  **触发与试探**：触发器激活，一方初步行动或展示（挑衅、试探），另一方产生反应（戒备、轻视）。
2.  **对抗与升级**：冲突显化，进行言语交锋、力量试探或认知挑战，情绪张力初步拉高。
3.  **爆发与决断**：阻力被短暂突破或情绪积累至顶点，以关键行动、宣言或决定释放，形成阶段性爆点。
*（适配：日常冲突、快速战斗、简短谈判）*

**【四阶模板 · 完整博弈】**
1.  **姿态确立**：展示初始实力对比或情绪基线（如A方展示/轻视，B方隐忍）。
2.  **反击与僵持**：弱势方反击或亮出筹码，取得短暂平衡，但未能解决根本矛盾，陷入对峙。
3.  **底牌与逆转**：一方动用底牌或施加重压，形势发生逆转，将另一方逼入看似绝境。
4.  **破局与清算**：被压制方展现真正实力/智慧，或外部因素介入，彻底破解危机，完成情绪清算或形成新平衡。
*（适配：高手对决、重要谈判、中型副本冲突）*

**【五阶模板 · 深度酝酿】**
1.  **设局与入瓮**：主动方抛出诱饵或制造局面，引导被动方踏入预设情境；或长期压抑的伏笔开始显现。
2.  **表演与观察**：双方在局中进行心理、言语或力量的试探与表演（炫耀、伪装、挣扎），积累疑点与情绪。
3.  **施压与抉择**：压力层层加码，或关键信息被部分揭露，迫使角色面临重大道义或情感抉择，内心撕裂。
4.  **假象与悬崖**：一方做出妥协或假意服从，制造危机暂缓的假象；或情绪被推至悬崖边缘，即将崩溃。
5.  **颠覆与终结**：所有铺垫收束，真相彻底揭露或力量终极爆发，实现认知、情感或战局的完全反转与终结。
*（适配：复仇戏、大型阴谋揭晓、道心拷问、史诗级战斗）*

## 4) 爆点形式与适配条件
*   **意志宣言式**（“我的道，你击不碎！”）：适配信念对抗、绝境反击。需前置足够的道义或生存压迫。
*   **认知颠覆式**（平静道破核心秘密）：适配智斗、身份揭露。需前置信息迷雾和对方的自信表演。
*   **力量碾压式**（随手化解终极攻势）：适配实力悬殊的打脸。需前置对手的嚣张铺垫与观众的低预期。
*   **行动逆转式**（态度/行为180度转变）：适配恐惧降临、希望破灭。需前置施压方的绝对掌控姿态。
*   **规则刃锋式**（用规则包装复仇）：适配公开场合的惩戒。需前置规则的存在与对手的违规。
*   **沉默引力式**（以极致沉默吸收所有挑衅）：适配塑造深不可测的形象。需前置环境的嘈杂与多方施压。
*   **牺牲献祭式**（微笑中完成自我毁灭）：适配情感升华、悲剧结局。需前置深厚的羁绊与无解绝境。
*   **集体咆哮式**（众人齐吼，意志共鸣）：适配群体热血、绝地冲锋。需前置共同的压迫与绝望。

## 5) 余波与情绪债：不断供公式
1.  **悬念转场法**：在爆点最高潮或冲突白热化时切换视角/场景，将释放转为期待。
2.  **明确债务法**：直接点明未履行的承诺、未解决的恩怨、待完成的目标（“X年后，我来取你命”）。
3.  **代价显化法**：爆点后立刻展示角色付出的惨重代价（重伤、失宝、心累），或获得力量伴随的隐患。
4.  **情感绑架法**：利用对方无法割舍的执念（亲情、传承）作为枷锁，迫使接受屈辱结局，埋下不甘。
5.  **高层扩散法**：个体冲突后，立刻切入更高层势力（妖帝、宗门）的震怒与决策，将矛盾升级。
6.  **旁观定调法**：通过其他强者/势力的震惊、恐惧、重新评估，将爆点影响固化并辐射开来。
7.  **平行埋线法**：主情节余波中，切入反派阵营获得新力量或制定新计划的场景，预告下一波危机。
8.  **希望期权法**：给予一个微小且关乎执念的未来希望（“修炼有成则传你核心”），换取当下服从，形成长期牵绊。

## 6) 泄压黑名单
*   **过早同情/解释**：在反派施暴时，立即插入其悲惨过去；在情绪高潮时，用大段内心独白解释原理。
*   **机械降神解围**：主角绝境时，毫无铺垫地引入无敌外力直接解决问题。
*   **情绪反复横跳**：角色在“愤怒-冷静-愤怒”间无理由频繁切换，破坏积累。
*   **对手强行降智**：为让主角破局，强行降低反派智商或反应（有底牌不用）。
*   **伤害轻描淡写**：角色遭受重创后，情绪和生理反应平淡或恢复过快。
*   **爆点重复滥用**：短时间内多次使用同一种爆点形式（如连续“震惊”）。
*   **关键对话儿戏**：重要谈判、传承场景的对话内容空洞，逻辑儿戏。
*   **余波过度煽情**：爆点后使用过量抒情段落，拖沓节奏，冲淡力量。
*   **忽视环境反馈**：主角做出震撼行为后，不描写周围人群（尤其强者）的反应。
*   **群体无脑工具化**：作为背景的群体完全丧失个体意志，成为纯背景板。

## 7) Prompt Blocks（弱/中/强）
**【弱 · 日常情绪波动】**
> 场景：角色在【安静环境】中，因【看到某物/听到某声】触发了关于【故人/故乡】的回忆。请描写角色从平静到陷入回忆的细微情绪变化，包括片刻的失神、细微的表情或动作停顿，以及最终如何将情绪收敛，回归当下。避免直接抒情，用细节呈现。

**【中 · 重要冲突对峙】**
> 场景：A与B因【核心利益/原则问题】在【公开/半公开场合】对峙。A率先以【规则羞辱/言语挑衅】发起攻击。请设计一个四阶情绪升级：1）B的初始隐忍与观察；2）A加大羞辱力度，B开始冷冽回应；3）A动用【身份/实力】施压，形势对B极度不利；4）B抛出【关键信息/颠覆性证据】实现认知反转，让A陷入被动。重点刻画每一步双方眼神、气势及周围旁观者反应的细微变化。

**【强 · 绝境生死爆发】**
> 场景：角色濒临死亡（肉身崩溃/元神将散），毕生执念（复仇/守护）即将落空。此时，其内心产生一个“大胆念头”——利用导致自身毁灭的【外部毁灭性能量/自身残破状态】进行终极一跃。请描写：1）放弃抵抗，主动引导毁灭能量入体的决绝；2）承受超越极限的痛苦与形态剧变；3）在毁灭中捕捉到的一线明悟或契机；4）将所有痛苦、执念、明悟融合，完成【形态转化/神通诞生】的瞬间爆发，并伴有一句宣告自身“道”的终极宣言。需充满痛苦、疯狂与升华的混合质感。
