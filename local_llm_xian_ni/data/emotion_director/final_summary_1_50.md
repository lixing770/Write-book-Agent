# 仙逆 1-50｜情绪戏方法论总纲
## 1) 触发器谱系
（根据已知章节归纳的八类核心情绪引爆装置）
1.  **当众宣判/羞辱**：利用公开场合与权力差，对角色进行社会性人格否定，制造无法回避的耻感与愤怒。
2.  **希望悬崖**：先予后夺，在角色付出极限努力后，将触手可及的目标于临界点前摧毁，制造极致的挫败与不甘。
3.  **关键信息揭露**：通过颠覆认知的真相，瞬间改变角色处境与自我评估，引发惊愕、醒悟或危机感。
4.  **意外相遇/介入**：打破角色暂时的安全或低调状态，让积压的矛盾在无准备的情况下被迫面对，引爆紧张感。
5.  **生死危机/身体异变**：用直接的物理死亡威胁或身体失控，激发最原始的恐惧与求生欲。
6.  **发现异常物品/现象**：通过微小但违背常理的细节，引发好奇、困惑与对潜在巨变（机遇或危险）的预感。
7.  **“为你好”式打压**：以关怀、责任为包装的贬低与控制，制造情感上的混淆与更深的屈辱感。
8.  **规则/权威的蛮横运用**：利用不可抗的规则或权力，下达侮辱性或不可能的任务，制造结构性的无力感。

## 2) 阻力模型
（八种压制情绪、延迟爆发、积蓄张力的核心枷锁）
1.  **实力/地位悬殊压制**：绝对的力量或阶层差距，使正面冲突等于自杀，必须隐忍。
2.  **目标未达成/有求于人**：对更高目标的渴求（如入门、变强）成为软肋，迫使角色忍受当下屈辱。
3.  **秘密必须隐藏**：怀有不能暴露的核心机密（宝物、修为、真相），任何情绪失控都可能引来窥探与杀身之祸。
4.  **场合/环境限制**：公开、礼仪性或危险的环境，限制了冲突爆发的形式与可能性。
5.  **情感牵绊/道德束缚**：对至亲的爱、对恩情的亏欠、基本道德底线，成为抑制报复或极端行动的内在锁链。
6.  **生理/认知局限**：重伤、疲惫、无知等状态，使角色无力处理或理解当前的情绪冲击。
7.  **群体氛围裹挟**：被集体的狂热、沉默或规则所包围，个体情绪难以突破“大势”的围墙。
8.  **沉没成本不甘**：双方因已投入过多（时间、资源、期待）而不愿轻易放弃或撕破脸，在僵持中持续加码。

## 3) 升级台阶模板（可复制）
**基础三阶（快速构建情绪弧）**：
1.  **压抑/承受**：触发器作用→因阻力而沉默/服从/掩饰（表面平静，内心惊涛）。
2.  **试探/对抗升级**：压力持续→有限回应（事实反驳/内心誓言/消极顺从）→施压方行为升级。
3.  **临界/爆发**：压力顶点→阻力被突破/绕开→情绪内爆（苦笑/决断）或外爆（语言/行动对抗）。

**递进四阶（营造希望与跌落）**：
1.  **期望堆叠/氛围营造**：通过环境或配角抬高预期，营造特定氛围（喜庆/严肃）。
2.  **希望闪现/短暂舒缓**：在压抑中给予一丝微光（看到终点/获得温情），情绪短暂提振。
3.  **希望破灭/压力具象**：微光被掐灭，压力转化为具体威胁（如山大的水缸、当众指派）。
4.  **终极宣判/行动转折**：关键人物做出最终判定（失败/驱逐）→角色做出不可逆决断（离家/交易）。

**复杂五阶（人际博弈与表演）**：
1.  **面具入场**：双方戴社交面具（恭敬弟子/威严师长）进入场景。
2.  **话术试探/规则建立**：一方用话术（关心/指责）试探，或利用规则建立优势。
3.  **亮出筹码/遭遇破绽**：一方亮出真实意图（请求/威胁）→另一方发现其话语/行为破绽。
4.  **心理攻防/表演深化**：弱势方表演（顺从/困惑）麻痹对手，强势方表演（大度/失望）施加压力。
5.  **达成扭曲共识/关系定格**：表面达成共识（交易/拜师），实则关系定格于互相利用与不信任，埋下冲突雷管。

## 4) 爆点形式与适配条件
**内爆型（情绪向内塌陷，张力持久）**：
*   **沉默/无言**：适配于信息过载、极度震惊或彻底心死的场景。用空白承载万钧情绪。
*   **苦笑/冷哼**：适配于醒悟、自嘲、或对荒诞处境的鄙夷。用微表情替代激烈言语。
*   **内心确认/决断**：适配于外部冲突暂时悬置，角色需要完成关键认知切换或做出孤独决定的时刻。
*   **生理性崩溃**：适配于情绪压力远超生理极限，通过晕倒、发抖等生理反应外化崩溃。
*   **表情瞬间切换**：适配于公开表演结束、独处开始的瞬间，展现角色真实的阴沉与愤怒。

**外爆型（情绪向外宣泄，释放压力）**：
*   **语言对抗**：适配于阻力出现裂缝（如目标已无望、无需再忍），角色从隐忍转为直接反驳或宣言。
*   **行为决裂**：适配于对关系、环境彻底失望，用沉默但决绝的行动（转身离开、捡起被弃之物）宣告终结。
*   **暴力宣泄**：适配于最原始的冲突场景（家庭、生死搏杀），或强势方欺人太甚、退无可退之时。
*   **当众出丑/失控**：适配于对手精密算计得逞，或角色自身失误导致社会性死亡。
*   **能力/身份展示**：适配于扮猪吃虎、打脸复仇场景，在对手最得意时轻描淡写地实现碾压。

## 5) 余波与情绪债：不断供公式
（确保情绪爆发后，能量不散失，转化为后续动力）
1.  **缓冲公式**：爆点 + 短暂缓冲行为（轻叹/清洗/打坐）。让情绪自然回落，而非叙事骤停。
2.  **定性公式**：爆点 + 关系永久性改变（名存实亡/信任破裂）。将情绪转化为持续的人物关系动力。
3.  **隐患公式**：爆点 + 具体未来麻烦（怀璧其罪/待验谎言）。将情绪转化为新的悬念与压力源。
4.  **执念公式**：爆点 + 强化核心目标（“十年我忍了”/“志在必得”）。将痛苦转化为成长的燃料。
5.  **行动公式**：激烈情绪 + 务实解决行动（检查环境/规划修炼）。将情绪能量导向下一段剧情。
6.  **扩散公式**：个体冲突结束 + 群体反应（议论/耻笑）。将个人情绪扩散为集体氛围，延续张力。
7.  **关怀公式**：极致冷漠/羞辱后 + 微小温暖（无关者赠物）。制造复杂情绪光谱，避免情绪单一化。

## 6) 泄压黑名单
（破坏情绪张力积累与释放的致命写法，务必避免）
1.  **过早解释/原谅**：在误会或羞辱高潮前，安排解释或原谅，瓦解前期所有情绪积累。
2.  **崩溃后立刻安抚**：角色生理/心理崩溃后，立刻被全方位关爱包围并解决问题，导致情绪弧光虎头蛇尾。
3.  **爆点前泄压**：在情绪升级的关键台阶，插入无关喜剧或琐事，打断情绪积累的连续性。
4.  **让角色过于理智**：在应情绪化的核心场景（至亲受辱、梦想破碎），主角立刻进行冷静利益分析，削弱共情。
5.  **滥用内心独白**：在需要“沉默力量”或“表演反差”的场景，用过多内心独白解释感受，破坏留白与张力。
6.  **对手突然降智**：为让主角爆发或获胜，让强势对手逻辑崩坏或突然心软，削弱冲突合理性与胜利质感。
7.  **上帝视角打断**：在情绪紧绷的对峙中，插入作者解释性旁白或过长环境描写，打断读者沉浸的情绪流。

## 7) Prompt Blocks（弱/中/强 三套）
**弱级（日常压抑与微小刺痛）**
> 请写一段情绪戏，展现角色在看似平静的日常中，因他人一句“无心之言”或一个微小动作而感到刺痛与疏离。要求：1）场景为日常活动（如吃饭、劳作、行走）；2）刺痛源来自关系不远不近的配角；3）角色因【阻力模型，如场合限制/目标未达成】选择不回应，仅通过一个细微的肢体停顿或眼神变化泄露情绪；4）后续通过一个独处的务实小动作（如用力擦拭某物、反复检查某物）来延续并消化此情绪。

**中级（希望建立与规则性剥夺）**
> 请写一段情绪戏，展现角色为达成一个具体、微小的目标（如换取某物、通过某处）而遵循苛刻规则、付出艰辛努力，却在即将成功时被规则本身或权威者无情否决。要求：1）清晰描写角色遵循规则的努力过程（生理或心理消耗）；2）在终点前设置一个明确的“希望闪现”时刻；3）由规则代言人或权威者，以冷漠、公事公办的口吻宣告失败，并强调规则的“公平性”；4）爆点采用【内爆型，如沉默/苦笑】，后续通过【余波公式，如埋下具体隐患/强化核心执念】处理。

**强级（公开场合下的尊严绞杀）**
> 请写一段高张力情绪戏，发生在公开典礼、宴会或集会场合。要求：1）先通过周围人的期待、议论或庆典氛围【堆叠期望】；2）由一名【实力/地位悬殊】的权威者或宿敌，以【“为你好”式打压】或【当众宣判】为触发器，对主角进行人格贬低或命运裁定；3）主角因【多重阻力模型，如场合限制+秘密必须隐藏+有求于人】而被迫承受；4）在压力达到顶点时，安排一个意外的【关键信息揭露】（如关于贬低者自身的丑闻、或关于主角真实价值的线索）瞬间扭转局势；5）爆点采用【外爆型，如能力展示/语言对抗】或极致的【内爆型，如沉默】，并立刻以【群体情绪扩散】和【关系永久定性】作为余波。
