# 仙逆 51-100｜情绪戏方法论总纲

## 1) 触发器谱系
*   **行为触发**：角色可观测的动作，直接引动矛盾。
    *   *公开挑衅/碾压*：当众击败、轻蔑点评、强行索要。
    *   *私下胁迫*：以性命、重要之物相逼。
    *   *反常行动*：违反常理或预期的行为，制造悬念。
    *   *信号动作*：出示信物、划定界限等具有明确象征意义的动作。
*   **信息宣告触发**：通过言语传递，改变认知与局势。
    *   *颠覆性真相*：宣告靠山倒塌、揭露隐藏身份或修为、告知残酷现实。
    *   *预言/威胁*：指出灾祸、以毁灭性后果相胁。
    *   *利诱/交易*：提出带有诱惑或唯一性的条件。
*   **环境/事实触发**：客观世界的变化，迫使角色应对。
    *   *环境异变*：防御被破、氛围诡谲、天象剧变。
    *   *物品异变*：法宝、秘宝出现异常反应。
    *   *自身状态异变*：修炼失控、濒临极限、常规手段失效。
*   **记忆/感知触发**：作用于角色内在，唤醒情感或恐惧。
    *   *记忆锚点*：接触与过往强烈关联的特定物品。
    *   *时间对比*：通过时间跨度强调物是人非。
    *   *威压感知*：被更高层次的存在神识扫过或凝视。

## 2) 阻力模型
*   **外部现实阻力**：客观存在的、难以逾越的障碍。
    *   *实力碾压*：敌我境界或力量存在绝对差距。
    *   *制度/规则压制*：必须遵守的、来自更高权威的残酷规则。
    *   *环境限制*：身处敌营、密闭空间或受严密监视。
    *   *第三方威胁*：有更强大的敌人或势力在旁窥伺。
*   **内部心理/认知阻力**：源于角色自身的矛盾与局限。
    *   *信息差与未知恐惧*：对对手、环境或现象了解不全，不敢贸然行动。
    *   *责任与私心的冲突*：在保护他人/集体与自身求生欲之间挣扎。
    *   *谨慎多疑的天性*：对任何信息进行逻辑拷问，难以建立信任。
    *   *情感隔阂与试探*：因久别、疏离或复杂关系导致的沟通缓冲。
*   **过程/条件阻力**：在行动中消耗或面临的客观困难。
    *   *资源消耗极限*：灵力、神识、底牌即将耗尽。
    *   *功法/仪式的客观难度*：修炼过程痛苦漫长，或祭炼异常艰难。
    *   *沟通障碍*：语言不通，意图无法直接传达。

## 3) 升级台阶模板
*   **三步台阶（基础范式）**
    1.  **挑衅/试探 → 压制/展示 → 逼问/抉择**：（用于碾压局）先引战，再展示绝对优势，最后逼迫对方做出屈辱选择。
    2.  **观察/预警 → 接触/对抗 → 爆发/反转**：（用于遭遇战）发现异常，初步接触试探，随即能力爆发或局势反转。
    3.  **否定/压抑 → 反抗/代价 → 哀求/决断**：（用于情感冲突）一方压抑情感，在压迫下反抗并付出代价，最终情感爆发或做出决断。
*   **四步台阶（推进探索）**
    1.  **发现异常 → 逐步验证 → 遭遇阻碍 → 决绝突破**：（用于破解谜题或困境）从好奇到确认，遇到外部封锁，最终以坚定意志尝试突破。
    2.  **建立表面和谐 → 内部怀疑滋生 → 外部危机介入 → 彻底摊牌**：（用于身份伪装或潜伏）获得初步信任，自身或对方起疑，外部危机催化，面临直接质问。
*   **五步台阶（营造绝望）**
    1.  **预警降临 → 初步抵抗 → 希望破灭 → 全面压制 → 精神摧毁**：（用于势力碾压或降维打击）强敌到来，象征性抵抗后，靠山倒塌，物理与尊严被双重碾压，最终集体精神崩溃。

## 4) 爆点形式与适配条件
*   **言语羞辱/宣告类**
    *   *形式*：极致嘲讽、夺宝宣言、真相补刀。
    *   *适配条件*：适用于实力、地位或信息存在绝对优势的一方，用于彻底摧毁对方心理防线，适合作为冲突的终结或转折点。
*   **物理/法术行动类**
    *   *形式*：果断击杀、残酷炼化、陷阱触发、赌命对决。
    *   *适配条件*：适用于仇恨累积至顶点、或陷入你死我活绝境时。赌命对决特别适合实力相近、意志比拼的生死关头。
*   **环境/规则引爆类**
    *   *形式*：规则施压、能力揭露、异象降临。
    *   *适配条件*：用于引入无法反抗的更高层次力量（如制度、宗门、大能），或将冲突从个人升级到体系层面，制造宏大压迫感。
*   **情感/认知反转类**
    *   *形式*：卑微哀求、无声决断、平静释放。
    *   *适配条件*：适用于长时间心理博弈、情感压抑或经历巨大痛苦后的节点。以“收”代“放”，用克制动作表达剧烈情感转折，余味悠长。

## 5) 余波与情绪债：不断供公式
*   **当下余波写法**：爆点后不立刻切走，通过**集体沉默、人心离散、冷静复盘、悬置决策**等手法，让情绪沉淀、蔓延或悬而未决。
*   **埋设情绪债方法**：
    1.  **设置反向目标**：让失败方留下明确的诅咒或誓言，转化为长期悬念。
    2.  **成功即负债**：让达成目标的方法附带严重副作用或引发新危机。
    3.  **体系化恐惧**：构建无法反抗的残酷制度，让安全只是暂时，压力无处不在。
    4.  **平行威胁铺垫**：主线收尾时，切入其他威胁方的动态，预告风暴来临。
    5.  **悬置核心秘密**：让角色发现巨大秘密但因风险无法获取，保留“渴望与恐惧”的矛盾动力。
*   **不断供公式**：
    > **【埋债】** 在情绪爆点中或之后，留下一个**负面标记**（如诅咒、副作用、未解之谜）或一个**未完成的正向目标**（如渴望的宝藏）。
    > **【转化】** 立即或稍后，将该标记/目标**转化为明确的动力**（如修炼目标）或**显性的新危机**（如追兵锁定）。
    > **【追偿】** 在后续情节中设置明确的节点，让该动力推动剧情，或让该危机**周期性显现、升级并最终爆发**。

## 6) 泄压黑名单
1.  **过早宣泄**：阻力未足、压力未顶时让主角轻易反杀。
2.  **反派降智**：优势方突然话多解释，给对手创造翻盘机会。
3.  **直白呐喊**：用“我好恨”等直白台词代替细腻的侧面刻画。
4.  **情绪断崖**：爆点后无任何余波，立刻跳转至无关轻松情节。
5.  **旁观煽情**：用大量配角的夸张反应强行烘托情绪，失真且过猛。
6.  **忽略逻辑**：为升级情绪，让角色做出违背其性格或客观条件的行动。
7.  **爆点单一**：连续多场情绪戏采用同一种爆发形式，导致读者疲劳。

## 7) Prompt Blocks（弱/中/强）
*   **【弱】** 场景速写
    > 要求：仅快速勾勒一个高张力场景的核心步骤。
    > Prompt：“设计一场【赌命对决】。双方绝招同时发出（描述A的招式 vs B的招式），在攻击及体的瞬间，插入一个【记忆锚点】的闪回（如：A眼前闪过某个物品/面容），随后描写结果。用【冷静复盘】或【悬置决策】收尾。”
*   **【中】** 情节构建
    > 要求：构建一个包含完整情绪升级台阶的段落。
    > Prompt：“运用【四步台阶】模板，写一段主角发现并试图获取某【物品异变】宝物的情节。步骤：1) 发现异常；2) 逐步验证（遇到【过程阻力】）；3) 遭遇阻碍（【环境限制】或【第三方威胁】介入）；4) 决绝突破（采用【情感/认知反转类】爆点，如‘无声决断’）。最后，遵循【不断供公式】，为此成功埋下一个‘情绪债’。”
*   **【强】** 系统构思
    > 要求：系统设计一场多层次、有余波、能牵连后续的大情绪戏。
    > Prompt：“构思一场【势力碾压】戏，核心是【制造集体屈辱】。使用【五步台阶】模板。**触发器**用【环境异变】（大阵被破）和【信息宣告触发】（宣告靠山已倒）。**主要阻力**为【实力碾压】和【制度压制】。**爆点**选用【言语羞辱类】的极致嘲讽。**余波**重点描写【集体沉默】和【人心离散】。结束后，立即通过【平行威胁铺垫】切入另一个反派视角，并将此次羞辱的后果转化为一个长期的【反向目标】（如：幸存者立誓复仇），嵌入【不断供公式】循环。”
