# 仙逆 101-200｜情绪戏方法论总纲

## 1) 触发器谱系
*按“触发源”与“冲击强度”分类，构成情绪张力的起点。*
* **外部强刺激型**：直接威胁角色生存或核心利益。
    * **危机宣告**：强者以语言/行动宣告毁灭（如“灭全族”）。
    * **至亲/核心受虐**：目睹珍视之人/物被摧残。
    * **行为挑衅**：强者居高临下的直接攻击或命令。
* **认知颠覆型**：瞬间粉碎角色（及读者）的原有认知框架。
    * **力量展示/身份揭露**：展示隐藏实力或真实身份。
    * **预期反转**：行为与长期形成的预期形成巨大反差。
    * **认知逆转**：关键证据（如镜中脸、传承认可）颠覆身份/局势认知。
* **环境与信息压迫型**：营造弥漫的、未知的恐惧。
    * **环境突变/诡异发现**：突现异象、发现恐怖景象。
    * **群体恶意**：被大量贪婪者围观、尾随形成的压力。
    * **规则/真相揭露**：触及核心秘密的残酷信息被道破。
* **内部引爆型**：源于角色自身状态或记忆的冲击。
    * **关键节点到达**：时间耗尽、地点边界、目标现身。
    * **自身状态临界**：被迫现身、身体/神识达到承受极限。
    * **记忆闪回**：独处时被痛苦或温馨的回忆击中。
* **算计与背叛型**：源于信任关系或精心布局的崩坏。
    * **背叛暴露**：信任者突然翻脸或算计被证实为陷阱。
    * **信息差引爆**：一方掌握的关键信息在临界点揭露。

## 2) 阻力模型
*解释“情绪为何不能立刻爆发”，构建压抑期与张力。*
* **绝对力量差（生存本能）**：任何直接的情绪爆发都等同于自杀，必须隐忍。
* **场合约束力（规则庇护）**：公开场合、上位者在场、宗门规则等迫使维持表面姿态。
* **认知黑洞（信息迷雾）**：对真相、意图、处境不了解，情绪找不到明确出口。
* **目标压制（优先级）**：有更紧迫的目标（逃生、夺宝、修炼）必须优先处理，压抑当下情绪。
* **道德枷锁（情感羁绊）**：因愧疚、承诺、旧情而无法做出最直接的反应。
* **刻板印象（认知惯性）**：长期形成的固有印象，阻碍了对当前异常的理解与情绪调整。
* **算计博弈（筹码平衡）**：双方互有所需，在信任破产基础上进行利益谈判，情绪让位于理性。

## 3) 升级台阶模板（可复制）
*提供标准化的情绪推进路径。*
* **【反杀/清场模板】（3步）- 用于快速情绪释放**
    1.  **挑衅/警告**：反派基于错误认知施压，或主角对群体发出最后通牒。
    2.  **揭露/清洗**：主角动用底牌瞬间破解攻势，或以压倒性效率进行范围清除。
    3.  **定调/仪式化**：反派态度崩溃臣服，或通过收集/展示战果将恐惧固化。
* **【情感破防模板】（3步）- 用于深度情绪挖掘**
    1.  **安全独处**：外部冲突结束，卸下伪装，进入封闭安全环境。
    2.  **记忆累积**：从迷茫到具体记忆细节闪回，悲伤/痛苦势能积累。
    3.  **生理转化**：以“血泪”等超越常规的生理反应宣泄，并迅速转化为具体誓言或行动。
* **【谈判博弈模板】（4步）- 用于智力对抗与情绪压抑**
    1.  **武力胁迫开场**：强者展示控制力，提出非对称要求。
    2.  **冷静反向施压**：弱者以沉默、讥讽点明不足，反弹压力，迫使进入谈判。
    3.  **信息试探加码**：双方围绕风险与报酬拉锯，筹码升级。
    4.  **表面妥协算计**：弱者基于理性算计同意，但立刻借势达成其他目的，埋下不信任。
* **【绝境谋算模板】（5步）- 用于复杂局势下的逆袭**
    1.  **观察铺垫**：冷静观察各方矛盾与规则漏洞，提前测试关键手段。
    2.  **诱饵试探**：用替身或次要资源试探，摸清对手反应模式，培养其轻敌心理。
    3.  **制造混乱**：主动引爆混乱，吸引并分散所有监视者的注意力。
    4.  **情绪对冲**：利用巨头因彼此贪婪、愤怒而互相牵制的瞬间，执行真实计划。
    5.  **逆转脱身**：以出乎意料的方式完成身份或局势逆转，趁对手错愕时成功脱身。

## 4) 爆点形式与适配条件
*定义情绪宣泄的终极形态及其最佳使用场景。*
| 爆点形式 | 核心特征 | 最佳适配条件 |
| :--- | :--- | :--- |
| **行动碾压型** | 简洁、冷酷、超越认知的暴力终结。 | 主角隐藏实力后反杀；需快速立威清场。 |
| **言语定调型** | 一句冰冷宣言完成情绪定调和权力确认。 | 长期压抑后；实力碾压需要仪式感宣告。 |
| **沉默施压型** | 通过凝视、威压、沉默等静态方式达到爆发效果。 | 身份或实力悬殊时，不宜直接动手的场合。 |
| **态度反转型** | 从极端嚣张到极端恐惧的戏剧性肢体转变。 | 用于羞辱对手，彻底粉碎其尊严与认知。 |
| **认知颠覆型** | 揭露真相或展示事实，瞬间粉碎所有旁观者认知。 | 身份反转、王牌失效、颠覆世界观的关键时刻。 |
| **内心决堤型** | 内心世界的崩溃、领悟或最终决断，常伴生理异象。 | 至亲惨剧后独处；信念崩塌与重建的转折点。 |
| **规则揭露型** | 环境/功法以颠覆方式揭示答案，带来绝望或希望。 | 漫长徒劳探索后；世界规则展露冰山一角时。 |
| **背叛收割型** | 布局者在高潮时现身，宣告“祭品”命运，完成残酷反转。 | 精心策划的陷阱收网；信任被彻底践踏时。 |

## 5) 余波与情绪债：不断供公式
*确保每一次情绪爆发都不是终点，而是新张力的起点。公式：`冷却动作 + 关系定性 + 埋债一项`*
1.  **冷却动作**：用“沉默许久”、“轻叹”、“转身即走”等简短描述，让激烈情绪短暂沉淀，避免拖沓。
2.  **关系定性**：用一句话明确冲突后人物关系的新状态（如“利用关系更赤裸”、“恨意滔天但无可奈何”）。
3.  **埋下情绪债（必须至少一项）**：
    *   **仇恨/杀意债**：失败方刻骨铭心的怨恨（标记债主）。
    *   **内部隐患债**：阵营内因嫉妒、不满产生的新矛盾。
    *   **承诺/执念债**：对逝者或对自己许下的、尚未达成的艰难诺言。
    *   **情感隔阂债**：因性格或遭遇，与他人形成的无法弥合的距离感。
    *   **生存压力债**：一个明确的倒计时或环境性死亡威胁。
    *   **工具依赖债**：新获得的力量或宝物附带控制、反噬等未知代价。

## 6) 泄压黑名单
*破坏情绪张力和读者代入感的致命写法，必须避免。*
1.  **提前泄压**：在触发器出现前，过度描写角色内心活动，削弱事件冲击力。
2.  **视角漂移**：在单一情绪场景中，频繁切换旁观者视角，破坏情绪连贯性。
3.  **解释性对话**：角色在情绪高潮时，用大段对话解释动机或计划，显得虚假且拖慢节奏。
4.  **工具人旁观**：旁观者只有“震惊”、“骇然”等标签化反应，无自身立场与算计。
5.  **情绪断层**：经历巨大冲击后，角色立刻恢复绝对理性进行分析，缺乏情感余韵。
6.  **爆点同质化**：连续使用同一种爆点形式（如多次跪地求饶），导致情绪疲劳。
7.  **细节缺失**：在极端情绪下，忽略身体的本能反应（颤抖、瞳孔变化、血泪），使情绪流于表面。

## 7) Prompt Blocks（弱/中/强 三套）
**弱强度 - 日常冲突/小试牛刀**
> 角色[A]在[日常场景]中，遭遇[小反派B]基于[错误认知]的挑衅（如嘲讽、抢位）。[A]起初隐忍（遵守规则/不想生事），但[B]得寸进尺，触及[A]的[微小底线]（如推搡其同伴、污蔑一句关键话语）。[A]不再废话，动用[基础底牌C]（如一招制敌的法术、显露部分实力）瞬间制服[B]。在[B]的错愕与求饶中，[A]冷漠拿走[象征性战利品D]，留下警告后离去。旁观者[E]对此事留下印象，为后续偶遇埋下伏笔。

**中强度 - 重要对决/身份博弈**
> 强者[A]为获取[关键信息/物品X]，以武力控制住弱者[B]。谈判中，[A]姿态高傲，抛出[不公平交易Y]。[B]在恐惧中保持惊人冷静，不仅点出交易漏洞，还反向揭示[A]的[自身困境Z]（如急需X的原因），迫使[A]不得不加码并透露部分真相。[B]深思后表面同意，但立刻提出一个作为“信任保障”的额外条件（如保管对方一件重要物品）。[A]冷笑应允，双方达成合作，但内心各怀算计。[B]在独处时，查看/摩挲[A]的那件物品，眼神深邃。

**高强度 - 核心转折/绝境逆袭**
> 主角[A]身怀重宝或秘密，被两方巨头[B]和[C]在[绝地D]（如古战场、秘境核心）围堵。双方互相忌惮，对[A]形成威压，要求其交出东西。[A]示敌以弱，抛出[诱饵或替身E]制造短暂混乱，真身则利用提前布下的[环境特性或后手F]（如小裂缝、阵法）潜入地下/暗处。[B]与[C]为争夺E发生冲突。就在他们战斗白热化、情绪（贪婪/愤怒）达到顶点的瞬间，[A]突然从意想不到的角度（如从地下、从某巨头身后）出现，以燃烧精血/动用禁忌手段的方式，强行夺取真正的目标[G]，并借助冲突余波和预先设好的[唯一逃生路径H]遁走。留给[B]和[C]的，只有被戏耍的暴怒和[A]消失前冰冷的回眸。
