# 第1-50章｜情绪戏套路库（基于第4-35章、第39-50章整理）
## A) 触发器类型库
1.  **当众宣判/羞辱**：在公开场合，由权威者（如师门长辈、家族首领）或对手（如同辈、仇敌）宣布主角的失败、低劣或进行人格贬低。（例：第4章“无缘”、第6章“废物”、第47章“只用五成力”）
2.  **希望悬崖**：在角色历经磨难、耗尽心力后，给予一个触手可及的希望（如看到终点、发现宝物），然后立刻由外部规则或他人无情夺走。（例：第4章看到山顶后宣布时间到、第8章发现石珠后又失望）
3.  **关键信息揭露**：通过对话或发现，揭示一个颠覆角色认知或处境的核心信息。（例：第5章测试结果揭晓、第11章水缸大小真相、第33章“任何人可兑换”的隐含杀机、第50章始祖身亡）
4.  **意外相遇/介入**：在主角日常或低调行动时，与旧敌/监视者/高位者意外相遇或被其介入，瞬间引爆积压矛盾。（例：第20章丹房遇王卓、第27章黑衣师兄到访、第41章王卓看见王林与周姓女子交谈）
5.  **生死危机/身体异变**：遭遇直接的物理死亡威胁（如猛兽、爆体、攻击），或身体出现无法控制的恐怖变化。（例：第7章遇白虎、第22章灵气失控、第26章目睹杀人）
6.  **发现异常物品/现象**：发现一个具体、微小但违背常理或承载巨大潜在价值的物品或现象。（例：第8章发现石珠、第14章石珠云朵变化与吸水、第23章第十云出现）
7.  **“为你好”式打压**：以关怀、指点、责任为名，行贬低、控制、羞辱之实。（例：第12章孙长老的“斩断凡尘”训斥、第35章张狂的“帮助”、第41章王卓的“修炼是浪费时间”）
8.  **规则/权威的蛮横运用**：利用规则、身份或实力差距，下达一个不可能完成或极具侮辱性的指令。（例：第11章不可能完成的挑水任务、第28章强制负责杂务处、第34章强制参加集训）

## B) 阻力模型库
1.  **实力/地位悬殊压制**：主角处于绝对弱势方（如记名弟子、凡人），无法与对手（师父、师兄、家族长辈）进行正面冲突，必须隐忍。
2.  **目标未达成/有求于人**：主角有明确且迫切的目标（如入门、拿仙符、借东西、打探消息），为达目的不得不忍受当下的屈辱或压力。
3.  **秘密必须隐藏**：主角怀有绝对不能暴露的核心秘密（如神秘石珠、真实修为、目睹的真相），任何情绪爆发都可能引起怀疑，危及秘密。
4.  **场合/环境限制**：事件发生在需要维持表面和谐、礼节或安全的公开场合（如家族宴席、门派大殿、交易会），不便直接爆发冲突。
5.  **情感牵绊/道德束缚**：因对至亲（父母）的爱与愧疚、对恩情（王浩赠丹）的回报、或基本的道德认知（不可滥杀），抑制了本能的反击或行动。
6.  **生理/认知局限**：角色处于重伤、疲惫、弥留或认知困惑（如不懂规则、不明白现象原理）的状态，无力处理或理解当前的情绪冲击。
7.  **群体氛围裹挟**：主角被集体情绪（如家族的狂欢期待、门派的集体沉默、交易会的谨慎规则）所包围，个体情绪难以突破。
8.  **沉没成本不甘**：施压方（如孙大柱）因前期投入巨大而不愿立刻放弃，被迫方因已付出太多而不愿前功尽弃，双方都在僵持中积累情绪。

## C) 升级台阶模板库
### 三阶模板（基础）
1.  **压抑/承受**：角色在触发器作用下，因阻力而选择沉默、服从、掩饰或内心惊涛骇浪但表面平静。
2.  **试探/对抗升级**：压力持续，角色进行有限度的回应（如事实反驳、内心誓言、消极顺从、暗中观察），冲突从单向承受转为双向互动，施压方行为升级。
3.  **临界/爆发**：压力达到顶点，阻力被突破或绕开，情绪通过内爆（苦笑、决断、内心确认）或外爆（语言对抗、行动决裂、生理崩溃）形式释放。

### 四阶模板（递进）
1.  **期望堆叠/氛围营造**：通过第三方（环境、配角）不断抬高对主角的预期或营造特定氛围（喜庆、严肃、诡异），为跌落积蓄势能。
2.  **希望闪现/短暂舒缓**：在压抑中给予一丝微光（看到终点、获得温情、交易有望），让角色和读者情绪得到短暂提振。
3.  **希望破灭/压力具象**：微光被无情掐灭，或压力转化为具体、可感的威胁（如山大的水缸、当众的指派、身体的剧痛）。
4.  **终极宣判/行动转折**：由关键人物做出最终判定（失败、驱逐、死亡宣告），或角色做出不可逆的决断行动（留书离家、同意交易、开始实验）。

### 五阶模板（复杂博弈）
1.  **面具入场**：双方戴着社交面具（恭敬弟子/威严师长、热情卖家/谨慎买家）进入场景，进行初步接触。
2.  **话术试探/规则建立**：一方通过话术（煽动、关心、指责）试探，或利用规则/权力建立初步优势。
3.  **亮出筹码/遭遇破绽**：一方亮出真实意图或筹码（请求、交易物、威胁），另一方发现其话语或行为中的破绽。
4.  **心理攻防/表演深化**：双方进行心理博弈，弱势方表演（顺从、感激、困惑）以麻痹对手，强势方表演（大度、失望、不耐烦）以施加压力。
5.  **达成扭曲共识/关系定格**：在各自算计下，达成表面共识（如师徒交易、买卖成交），实则关系定格于互相利用与不信任，为后续冲突埋雷。

## D) 爆点形式库
### 内爆型（情绪向内塌陷，更具张力）
1.  **沉默/无言**：在极致压力或信息冲击下，失去语言能力，用空白承载情绪。（例：第5章结尾的留白、第43章众人目瞪口呆）
2.  **苦笑/冷哼**：用自嘲或鄙夷的细微表情，替代激烈的言语，表达无奈、醒悟或割裂。（例：第9章王林的苦笑、第13章内心的冷哼）
3.  **内心确认/决断**：在外部冲突悬置时，内心完成关键认知的切换（如“记在心头”、“斩不断亲情”、“这是个宝贝”）或做出重大决定。
4.  **生理性崩溃**：情绪压力超越生理极限，表现为晕倒、惨笑昏迷、发抖等。（例：第4章昏迷、第29章弟子晕倒）
5.  **表情瞬间切换**：从公开场合的表演性表情（恭敬、微笑），在独处时瞬间切换为真实情绪（阴沉、愤怒）。（例：第35章进入洞穴后）

### 外爆型（情绪向外宣泄，释放压力）
1.  **语言对抗**：从隐忍转为直接的语言反驳、讽刺或宣言。（例：第12章“弟子并未学习仙法”、第16章“走就走”、第21章“谢谢你了啊”）
2.  **行为决裂**：用沉默但决绝的行动回应一切，如留书离家、转身离开、捡起被丢在地上的物品。（例：第7章留书离家、第12章捡起仙符）
3.  **暴力宣泄**：从语言升级为肢体冲突或破坏行为。（例：第6章父亲抄板凳、第34章孙大柱摔打王林）
4.  **当众出丑/失控**：因对手算计或自身失误，在公开场合行为失控，形象尽毁。（例：第49章孙浩自爆）
5.  **能力/身份展示**：在对手最得意时，轻描淡写地展示远超对方认知的实力或身份，实现碾压。（例：第20章展示红衣、第39章轻松踏入禁制）

## E) 余波与情绪债（不断供的方法）
1.  **当下缓冲层**：爆点后不立刻结束，描写一个短暂的缓冲行为（如轻叹、清洗身体、盘膝打坐、躲藏至天明），让情绪自然回落，而非骤停。
2.  **关系定性/恶化**：明确爆点对人物关系的永久性改变（如“师徒名存实亡”、“信任彻底破裂”、“他将一一报复”），将情绪转化为持续的人物动力。
3.  **埋下具体隐患**：爆点直接导致一个具体的、未来的麻烦（如“怀璧其罪”的危险、一个待验证的谎言、一件沾染命案的物品），成为新的悬念和压力源。
4.  **强化核心执念**：将爆点的痛苦转化为角色更坚定的核心目标（“十年我忍了”、“对修仙有了十足把握”、“志在必得”），让情绪成为成长的燃料。
5.  **转入务实行动**：激烈的情绪爆发后，角色迅速转为解决实际问题的行动（检查环境、规划修炼、准备交易品），将情绪能量导向下一段剧情。
6.  **群体情绪扩散**：个体冲突结束后，立刻切入围观群体的反应（议论、耻笑、沉默），将个人情绪扩散为集体氛围，延续张力。
7.  **对比性关怀**：在极致的冷漠或羞辱后，安排一个来自无关者或对手阵营的微小温暖（如王浩赠丹、张虎分享甘薯），制造复杂情绪，避免角色情绪单一化。

## F) 泄压黑名单（避免写法）
1.  **过早解释/原谅**：在误会或羞辱场景中，让角色过早获得解释机会或被轻易原谅，会瓦解前期积累的情绪张力。
2.  **崩溃后立刻安抚**：角色情绪崩溃（如昏迷、痛哭）后，立刻被全方位关爱包围，问题被迅速解决，会导致情绪弧光虎头蛇尾。
3.  **爆点前泄压**：在情绪升级台阶中，插入无关的喜剧片段或分散注意力的琐事，会打断情绪积累的连续性。
4.  **让角色过于理智**：在应情绪化的场景（如至亲受辱、梦想破碎），让主角立刻进行冷静的利益分析，会削弱代入感和共情。
5.  **滥用内心独白**：在需要“沉默力量”或“表演反差”的场景，用过多的内心独白解释角色感受，会破坏留白和表演的张力。
6.  **对手突然降智**：为了让主角爆发或获胜，在关键时刻让强势对手行为逻辑崩坏或突然心软，会削弱冲突的合理性和胜利的质感。
7.  **上帝视角打断**：在情绪紧绷的对话或对峙中，插入作者解释性的旁白或过长的环境描写，会打断读者沉浸的情绪流。

## G) Prompt Blocks（可直接复制）
**1. 绝望攀升模板**
> 请写一段情绪戏，展现角色在绝境中为了一线希望耗尽所有。要求：1）用持续的生理痛苦（如攀爬、饥饿、伤痛）外化其努力与消耗；2）在耗尽一切时，给予一个清晰的、触手可及的希望景象（如光亮、终点、救援信号）；3）通过一个外部声音或规则，冷酷地宣告希望破灭/时间截止；
