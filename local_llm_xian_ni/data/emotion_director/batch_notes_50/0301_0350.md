# 第301-350章｜情绪戏套路库
## A) 触发器类型库
1.  **珍宝被夺/触及逆鳞**：角色最珍视之人/物被抢夺或侮辱，引爆极端情绪。（例：周佚的女尸被夺；王林的李慕婉受辱）
2.  **期望落空**：历经艰辛抵达目标，却发现一片空白或被毁，激发愤怒与失望。（例：寻宝发现洞府空空；轮回树枯萎）
3.  **身份/实力揭露**：隐藏的身份、修为或故人关系被突然点破，制造震惊与地位反转。（例：王林被认出是曾牛；故人重逢修为碾压）
4.  **危机制造抉择**：突发致命危机（怪物、强敌、环境崩溃），逼迫角色在合作、背叛或牺牲间做出选择。（例：仙兽府怪物围攻；天道巨手追杀）
5.  **信息/言语刺激**：通过对话、质问或揭露信息，直接冲击对手道心或尊严。（例：王林质问红蝶“不忠不孝”；展白羞辱李慕婉）
6.  **单向情感输出**：一方持续的情感倾诉（爱意、思念、怨恨）得不到回应，压力累积至爆发。（例：周佚对女尸倾诉；李慕婉生命倒计时）
7.  **环境/天道压迫**：超越个人的宏大力量（仙界崩溃、天道轮回）作为终极对手，激发绝望或逆天豪情。（例：对抗轮回灰气；仙界使者降临）

## B) 阻力模型库
1.  **内部心理阻力**：
    *   **心理防御/幻觉维持**：角色自我欺骗，维持脆弱的情感幻觉。（周佚与女尸“对话”）
    *   **实力隐藏/谨慎多疑**：隐藏真实修为或意图，因忌惮而不敢轻易爆发。（王林、孙雷互相试探）
    *   **性格特质**：冷静、坚韧的性格强行压抑情绪。（王林面对困境的沉默）
    *   **情感克制**：为不增加所爱之人负担而强颜欢笑。（李慕婉面对王林）
2.  **外部情境阻力**：
    *   **共同目标锁死**：存在必须合作才能完成的更高目标（取宝、逃生），压制内讧。（王林、孙雷、红蝶等人的临时同盟）
    *   **第三方调停/威慑**：有分量的中间人劝阻，或更强者在场形成威慑。（叱虎调停；周佚、尸阴宗老者威压全场）
    *   **环境/规则限制**：战斗会导致共同毁灭（碎片崩溃），或有身份规则限制（朱雀国弟子不可杀）。（仙府碎片战斗；红蝶身份保护）
    *   **绝对实力差距**：敌人过于强大，反抗无效，只能恐惧或隐忍。（化神面对婴变期）
    *   **物理/信息隔阂**：距离遥远、信息不通，情绪无法直接传递或释放。（王林与李慕婉相隔万里）

## C) 升级台阶模板库
1.  **【通用】冲突三步爆发模板**：
    *   **台阶1 (试探/施压)**：一方通过言语、行为或展示实力进行初步挑衅或施压。（例：展白破阵、邱四平掀帘）
    *   **台阶2 (反击/抵抗)**：另一方做出防御或反击，但未能解决根本矛盾，反而激化冲突。（例：王林冷眼击退邱四平、李慕婉为保宗门屈服）
    *   **台阶3 (反转/爆发)**：力量对比反转，或冲突性质升维，以绝对手段（击杀、宣言、意境碾压）完成情绪释放。（例：王林宣告身份、仙剑斩爆头颅、生死意境展开）
2.  **【谈判博弈】五步加压模板**：
    *   **台阶1 (提出要价)**：A方提出初步合作方案或利益分配。（孙雷要仙剑）
    *   **台阶2 (还价/拒绝)**：B方拒绝或提出截然相反的条件。（王林要洗灵葫）
    *   **台阶3 (施压/亮底牌)**：A方展示实力、威胁或透露关键信息试图施压。（红蝶以朱雀国权威施压）
    *   **台阶4 (反制/拉锯)**：B方从容反制，展示见识或底牌，将压力反弹。（王林点破轮回果特征）
    *   **台阶5 (妥协/破裂)**：达成表面协议但埋下隐患，或彻底谈崩转向对抗。（胡老内心冷笑妥协）
3.  **【绝境反杀】四步递进模板**：
    *   **台阶1 (遇敌示弱/被围)**：主角看似陷入绝境，敌人占据绝对优势。（王林重伤被觊觎；全宗被展白屠杀）
    *   **台阶2 (敌人猖狂/试探)**：敌人步步紧逼，展示残忍手段或言语羞辱。（虫群噬体、逼问姓名）
    *   **台阶3 (底牌初显/受挫)**：主角动用一项底牌，但仅能暂时抵挡或击伤敌人，未能逆转。（王林以生死意境震慑；仙剑斩击齿木）
    *   **台阶4 (终极爆发/碾压)**：主角祭出真正杀招（终极意境、射神车、召唤强者），以震撼方式彻底消灭敌人。（兽魂透体、意境吞噬、孙泰屠杀）
4.  **【牺牲悲情】四步升华模板**：
    *   **台阶1 (平静铺垫)**：牺牲者平静安排后事，或进行最后的温馨互动。（李慕婉交代后事；周佚托付女尸）
    *   **台阶2 (代价初显)**：展示牺牲行为需要支付的惨重代价（生命、仙气、永世沉睡）。（白衣女子死气涌现；周佚燃烧元神）
    *   **台阶3 (仪式行动)**：牺牲者进行最后的、带有仪式感的行动（展开仙幕、撞向敌人）。（白衣女子释放仙力；周佚化作流星）
    *   **台阶4 (悲壮爆发/余韵)**：牺牲完成，伴随震撼景象（万剑齐碎、天地共鸣）和生者的爆发（嘶吼、穿透拥抱），情绪升华为崇高悲剧。（周佚悟道；王林抱空女尸）

## D) 爆点形式库
1.  **言语质问爆点**：以一句极具冲击力的质问或宣言，直接拷问对手道心或宣告立场。（“你修的是什么道！”“天让你死，我也把你抢回来！！！”）
2.  **意境/法则碾压爆点**：用更高维度的力量（生死意境、轮回天道）进行精神或物理上的彻底镇压。（展开生死画轴、轮回灰气缠绕）
3.  **行动背叛/反转爆点**：用突然、果断的行动撕破表面关系，实现算计反转。（孙雷抢先进入洞穴；六师弟反杀师兄）
4.  **牺牲/殉道宣言爆点**：在自我献祭时刻，吐露升华性的感悟，将个人情感爆发与天地共鸣绑定。（“闻道者，朝生夕死”）
5.  **实力展示爆点**：通过一个眼神、一次轻描淡写的攻击，瞬间瓦解对手的嚣张气焰，建立绝对权威。（王林冷眼击退元婴；无形大手抓住使者）
6.  **信息揭露爆点**：突然点破对手隐藏的身份、罪行或双方过往的隐秘联系，引发震惊与局势重构。（“王林！！你居然化神了！”“巨富！！”）
7.  **同归于尽威胁爆点**：打出毁灭共同依存环境（仙界碎片）的底牌，强行制造威慑平衡，打断对手攻势。（“你信不信我让此处崩溃！”）
8.  **仪式性胜利爆点**：在无法彻底战胜绝对力量时，以达成某个阶段性目标（成功转世、夺回尸体）并进行宣言，作为情绪胜利的落点。（“下一次，我依然还会阻止！”）

## E) 余波与情绪债（不断供的方法）
1.  **制造未解悬念**：爆点后，立刻用一句指向不明的问话或一个细微异常，将情绪引向更深层的谜团。（“你，还不出现么？”；洞府内的异常）
2.  **仇恨/目标转移**：将当下的情绪矛盾（愤怒、杀意）明确转移或延后到一个新的目标或时间点。（朱雀星死战约定；十九年后再对抗）
3.  **留下战利品/誓言**：让爆点产生一个具体的、带有情绪印记的“物品”或“承诺”，作为未来剧情和情绪复燃的凭证。（红蝶断臂；叱虎以种族发誓）
4.  **设置代价倒计时**：明确一个未来的时间点或条件，届时未解决的情绪冲突（生死、承诺）将爆发，形成持续的压力。（李慕婉十九年魂凝期；轮回果成熟半个时辰）
5.  **旁观者认知颠覆**：通过旁观者的震惊、悔恨或猜疑，将爆点的影响扩散开来，并埋下人际关系的变数。（叱虎的滔天悔意；胡老对王林忌惮加深）
6.  **力量反噬伏笔**：让用于爆发的强大手段（射神车、禁幡）本身带有隐患或代价，成为新的情绪债务。（兽魂不甘的反视；器灵哀嚎）
7.  **身份保密引发猜疑**：让主角身份成为秘密，知情者被迫保密，从而在更大的舆论风暴中成为沉默的焦点，背负压力。（叱虎发誓保密曾牛身份）

## F) 泄压黑名单（避免写法）
1.  **过早崩溃**：主要角色在压力初期就彻底情绪失控（嚎啕大哭、疯狂呐喊），失去情绪升级空间。
2.  **反派死于话多**：反派在占据绝对优势时，进行长篇大论的解说或嘲讽，给主角预留不合理的翻盘时间。
3.  **旁观者过度解说**：通过旁观者之口，直白地讲解主角情绪多么“痛苦”、“伟大”，代替具体的细节和行为展示。
4.  **冲突被轻易调解**：经由激烈冲突后，被第三方轻易说服或一个简单理由就彻底化解恩怨，情绪张力凭空消失。
5.  **底牌无代价**：主角动用终极底牌扭转局势后，没有任何副作用、消耗或后续隐患，削弱决策的沉重感和真实感。
6.  **情绪单一宣泄**：爆点只有纯粹的力量对轰或言语对骂，缺乏更层次的意境对抗、心理博弈或命运仪式感。
