# 第201-250章｜情绪戏套路库
## A) 触发器类型库
*基于“触发变化的具体点”整理*
1.  **信息揭露类**：一个关键信息被说出或发现，瞬间改变认知与情绪。
    *   **核心信息**：如“二百年过去”、“归息中的元婴”、“高启明”（第201、205、246章）
    *   **身份揭破**：如点破伪装修为、认出故人、叫出旧名（第202、214、227章）
    *   **往事关联**：如“你父亲，不该姓藤”、“四百年前，你的小徒弟，是我杀的”（第231、237章）
2.  **行为冲突类**：一个具体的动作直接引发对抗或情绪转折。
    *   **攻击/偷袭**：如扔出毒沙、祭出飞剑、五彩之光袭击（第202、215、248章）
    *   **阻拦/控制**：如挡在身前、布下禁制、神识横扫封锁（第217、230、242章）
    *   **宣告/挑衅**：如“生生抢来”、“今日，此地不会有任何活口”（第205、245章）
    *   **决绝行动**：如转身离开、跪下磕头、自爆元婴（第218、234、239章）
3.  **环境事实类**：客观环境的变化或状态，成为无法回避的情绪导火索。
    *   **危机降临**：如黑云压顶、传送阵突然启动、强敌追至（第240、233、247章）
    *   **象征物出现**：如发现灵猿尸体、看到父母灵位、人头塔（第216、235、245章）
    *   **状态异变**：如金丹萎缩、煞气可视、修为突破（第207、250章）
4.  **感知确认类**：通过非视觉的感知（声音、神识、魂血）触发深层情感连接。
    *   **声音/神识**：如故人声音、庞大神识威压、魂血波动（第210、214、217章）
5.  **日常互动类**：在平凡场景中，通过细微差异或请求触发情绪线。
    *   **特征吸引**：如粗布衣衫、被叫住问诊（第211、249章）
    *   **赠予/索取**：如赠予毕生心得玉简、索要元婴期丹药（第213、219章）

## B) 阻力模型库
*基于“为什么不能立刻爆”整理*
1.  **内部心理阻力**
    *   **性格与目标**：角色内敛、多疑、目标宏大（需谋划），压制即时反应（第203、218、234章）。
    *   **情感牵绊**：对他人有感情（爱、同情、责任），无法立刻狠下心肠（第218、240、241章）。
    *   **认知惯性/尊严**：对自身实力、地位的认知，或作为强者/长辈的尊严，不愿失态（第201、210、236章）。
    *   **道德/身份门槛**：过往行为准则与当前被迫行为冲突，存在心理障碍（第207章）。
2.  **外部现实阻力**
    *   **实力/信息差距**：明确感知到对方实力远超自己，或信息不全不敢妄动（第205、227、242章）。
    *   **环境/规则限制**：身处敌方腹地、有禁制监视、阵法启动需要时间（第222、233、247章）。
    *   **第三方在场/牵制**：有需要保护的人、或有其他旁观者，不便直接冲突（第211、215、241章）。
    *   **物理/法术约束**：渴望之物易毁，或身体被种下禁制、毒素（第209、231章）。
3.  **关系与策略阻力**
    *   **虚伪的和平**：双方处于表面合作或试探期，不愿率先撕破脸（第206、221章）。
    *   **表演与伪装**：一方或双方都在演戏，需要维持人设以达成更深目的（第204、212章）。
    *   **目的特殊性**：目的不是简单的击杀，而是驯服、逼问或获取特定情绪产物（第229、239、246章）。

## C) 升级台阶模板库
*基于“情绪升级台阶”整理，可灵活组合*
**1. 三步递进模板（基础款）**
*   **台阶1（触发/试探）**：A方行动或信息触及B方。结果：B方产生初步情绪反应（警惕、惊讶、反感）。
*   **台阶2（升级/对抗）**：B方回应，可能伴随小规模冲突或更深信息揭露。结果：情绪烈度上升（愤怒、恐惧、杀意），冲突表面化。
*   **台阶3（顶点/爆点前奏）**：一方采取决定性行动或将矛盾推到非解决不可的境地。结果：情绪张力达到临界点，为爆点蓄满力。
*   *例句*：1) 你可知我为何杀藤家人？ 2) 红色闪电，慢慢地收缩。 3) 你必须要死，因为你姓藤！（第239章）

**2. 四步升级模板（增强款）**
*   **台阶1（铺垫/埋钩）**：铺垫情绪背景或人物关系，埋下微小矛盾或期待。
*   **台阶2（触发/首次交锋）**：触发器出现，双方进行第一回合互动（言语或轻微行动）。
*   **台阶3（加压/多次博弈）**：A方施加压力，B方尝试抵抗或谈判（可能多次反复），但均被化解或无效，压力持续增加。
*   **台阶4（临界/最后通牒）**：给出最终选项、倒计时或进行终极威慑，将对手逼至抉择悬崖边。
*   *例句*：1) 周紫虹对粗布衣少年产生兴趣。 2) “这不是废话么？” 3) 追上并行，分享荔枝被拒。 4) 周紫虹羞恼放弃。（第211章）

**3. 五步心理碾压模板（用于逼问、驯服）**
*   **台阶1（绝对控制）**：以实力或环境彻底限制对方自由，剥夺其反抗能力。
*   **台阶2（希望剥夺）**：逐一破解或展示对方所有逃脱、反抗手段的无效性。
*   **台阶3（痛苦施加）**：开始施加生理或心理上的痛苦（目睹珍视之物被毁）。
*   **台阶4（意志摧残）**：通过重复性动作或言语，持续折磨，使其心理防线出现裂痕。
*   **台阶5（最终屈服）**：在极致的痛苦或绝望中，对方意志崩溃，完成屈服或交代。
*   *例句*：1) 禁制黑幕笼罩。2) 极境神识被硬扛。3) 禁气轰击，身体裂开。4) 持续游斗消耗。5) （后续章节）决出胜负。（第242章）

## D) 爆点形式库
*基于“爆发的形式与落点”整理*
1.  **言语爆发**
    *   **冰冷宣告**：用最平静的语气说出最决绝的话（“扔了！”、“恭喜！”）。
    *   **绝望呐喊**：情绪崩溃时的痛苦吼叫（“王林！！！”、“我恨你！！”）。
    *   **屈服交代**：心理防线被击垮后，仓皇说出秘密（“我……说！”）。
2.  **行为爆发**
    *   **身体失控**：跪地、颤抖、灵力暴走、泪流不止。
    *   **决绝行动**：自杀式冲锋、震断心脉、引爆禁幡（同归于尽姿态）。
    *   **仪式性动作**：磕头立誓、抚摸信物后冲锋、堆砌人头塔。
3.  **环境/事实引爆**
    *   **天地异象**：立誓时雷鸣电闪，呼应情绪。
    *   **阵法/法宝启动**：传送阵亮起、禁制收缩、天劫细丝显现。
    *   **认知颠覆**：权威者认出一件平凡之物的非凡价值（“百年柳树叶！”）。
4.  **对峙转折爆点**
    *   **追逃逆转**：逃亡者突然停下，亮出最终底牌，转为对峙。
    *   **杀机转兴趣**：强者因认出对方特殊体质或能力，瞬间收手并抛出合作线索。

## E) 余波与情绪债（不断供的方法）
1.  **清单法**：在爆点后，立刻通过角色内心或叙述，列出未解决的情绪问题和待办事项（如复仇名单、修炼瓶颈、未来威胁），形成“情绪待办清单”。（第203、244章）
2.  **钩子法**：在爆点收尾时，自然引入一个新的、更高级的悬念、目标或人物关系。例如：逼问出下一个仇人名字；获得关于“修星之晶”的线索；收服灵兽但对其来历产生兴趣。（第246、248、229章）
3.  **状态固化法**：将一次性的情绪冲击，转化为长期存在的**状态**。例如：种下周期性发作的禁制（恐惧制度化）；煞气成为可见且需修炼掌控的实体（心魔物质化）。（第202、250章）
4.  **旁观者发酵法**：爆点影响的不仅是当事人。描写目睹全过程的旁观者（盟友、敌人、路人）的事后反应、解读与传播，让情绪在更大的范围内发酵和变形。（第207、210、236章）
5.  **情感账户法**：在温情或冲突场景中，进行不对等的“情感存取”。例如：王林接受周林的真诚，但内心无法等额回报，这份“情感债”成为未来愧疚或抉择的伏笔。（第213章）
6.  **环境沉淀法**：让爆点发生地的环境留下不可磨灭的痕迹（血腥味、废墟、异象），之后角色或他人重临旧地，环境会自动触发当时的情绪回响。（第216章）

## F) 泄压黑名单（避免写法）
1.  **过早释放**：阻力尚未充分构建，情绪台阶仅一两步就匆忙爆发，导致爆发无力。
2.  **雷声大雨点小**：铺垫了漫长的升级台阶，但爆点形式过于普通（如只是吵一架），与铺垫不匹配。
3.  **爆后无事发生**：情绪爆发后，场景立刻切走，或人物心态恢复如常，没有余波和情绪债，仿佛无事发生。
4.  **情绪与人物割裂**：角色的爆发形式严重不符合其已建立的身份、性格和实力（如冷酷魔头突然痛哭流涕且无充分理由）。
5.  **重复性爆点**：连续多个场景使用同一种爆点形式（如每次都靠“突然偷袭”引爆），缺乏变化。
6.  **解说型余波**：通过作者旁白或角色内心独白，直接总结“这件事给他留下了深深的阴影”，而不是通过后续行为、选择或他人之口来展现。
7.  **阻力儿戏化**：阻力被轻易绕过或突然消失（如强大的敌人突然降智），使得升级台阶和爆点价值大打折扣。

## G) Prompt Blocks（可直接复制）
**用于构思情绪戏的指令模块，可组合使用。**
---
**触发器模块：**
*   `[主角]在[某个场景]中，意外发现/听到/感知到[一个关键信息/事实]，这个信息直接关联到他内心深处的[某个执念/恐惧/渴望]。`
*   `[角色A]一个[看似平常/充满挑衅]的行为（如赠礼、拍肩、转身），被[角色B]严重误解或视为不可饶恕的冒犯。`
*   `一个[强大的外部危机]（如天劫、阵法启动、追杀者现身）突然降临，打断了[角色]当前的[计划/平静]。`
---
**阻力构建模块：**
*   `虽然[情绪强烈]，但[角色]因为[身份/尊严/在某人面前的形象]而不能立刻发作，必须强忍。`
*   `[角色A]想立刻[达成情绪目标]，但[角色B]掌握着[一件易毁的关键物品/一个重要
