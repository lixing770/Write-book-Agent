# 第701-750章｜情绪戏套路库

## A) 触发器类型库
1.  **至亲/底线受胁**：角色最珍视之人（子嗣、伴侣、故友）或最不可触碰的伤疤（如已故之人）受到威胁、侮辱或探查。这是引爆最高强度情绪（暴怒、决绝）的万能火种。
    *   *例*：雷道子欲杀王平、辱及王平已死；许立国嚣张挑衅主仆地位。
2.  **不敬言行挑衅**：通过语言（贬低、命令、嘲讽）或行为（无视、居高临下的审视）直接冒犯角色的尊严、身份或实力，点燃怒火与对抗欲。
    *   *例*：“小辈，滚开！”；许立国叫嚣“小林子，放你许大爷出来”。
3.  **认知/规则颠覆**：亲眼目睹或亲身经历完全违背常识、规则的现象，引发震惊、恐惧与茫然。
    *   *例*：王林提前撞入未开启的雷之仙界大门；雷鼎被毁，永恒规则被打破。
4.  **关键信息揭露**：被动或主动地获知颠覆性的真相，导致情绪崩塌或剧烈转折。
    *   *例*：周茹打开空储物袋，记忆解封，明白王林“一直不想我去找他”；李元揭露家族世代奴印的悲剧。
5.  **意外发现与机遇**：在危险或平凡环境中，意外发现能解决当前核心困境的宝物、信息或路径，引发狂喜、贪念与强烈期待。
    *   *例*：王林发现“雷元术”玉简；在望月体内发现贪狼遗留的仙山石。
6.  **环境/状态剧变**：外部环境（如空间禁锢、强敌降临）或自身状态（如重伤初愈、顿悟苏醒）的突然变化，成为新情绪场的起点。
    *   *例*：被神秘老者以“倒转”神通强行拉回；于雷池悟道后睁眼，目光残留道韵。
7.  **成功后的转折**：在角色达成一个小目标、正处于喜悦顶峰时，安排一个源自成功本身的、完全意外的突变，瞬间颠覆情绪基调。
    *   *例*：王林炼出第一丝元力，却被天逆珠吸收，引发天地之门重现。

## B) 阻力模型库
1.  **实力/层次碾压**：对手或环境的力量层次远高于角色，带来本能的恐惧与无力感，使愤怒、反抗等情绪被强行压制。
    *   *例*：面对古神一指、神秘老者的“倒转”神通。
2.  **信息未知与猜疑**：对局势、对手意图、物品功效缺乏了解，导致不敢贸然行动或投入情感，情绪在警惕与困惑中徘徊。
    *   *例*：王林对天逆巨门的召唤、对李元的真实目的心存疑虑。
3.  **规则/代价约束**：受限于某种公认规则、天道制约，或需要付出巨大代价（寿元、本源、珍视之物），情绪释放受到阻碍。
    *   *例*：雷道子珍惜元力；王林炼制仙卫需消耗珍贵材料；家族规则限制（如神通不传外人）。
4.  **心性/状态惯性**：角色固有的性格（多疑、隐忍、桀骜）或当前状态（重伤、修炼关键期、情绪低谷）构成内在阻力。
    *   *例*：申公虎的桀骜；王林刚平复心绪后的平静基线；战空烈的极度谨慎。
5.  **多重目标冲突**：同时需要处理多个目标或顾及多方关系，情绪需要在不同指向间权衡和压抑。
    *   *例*：既要守护王平安全，又要对抗雷道子；既想探究宝物秘密，又需警惕外界危险。
6.  **虚假安全与希望**：对手或环境给予一个看似可行的妥协方案或生路，使角色产生侥幸心理，延迟了决裂或爆发。
    *   *例*：雷道子假意认主；幻家、千家看似顺从的谈判。

## C) 升级台阶模板库
**三步模板（基础）：**
1.  **试探/施压**：一方通过语言、气势或初步手段进行试探或施加压力。
2.  **对抗/升级**：另一方做出反应，冲突在力量、语言或认知层面升级。
3.  **逆转/爆发**：优劣势发生反转，或情绪积累到顶，以某种形式爆发。
> *例（728章）*：申公虎驱赶 -> 王林宣称为“考验” -> 申公虎称“尊主”，战空烈骇然退缩。

**四步模板（进阶）：**
1.  **起势/铺垫**：建立情绪基线，或展示初始的实力/地位对比。
2.  **意外/转折**：发生意外事件，或一方展示出超出预期的能力，打破平衡。
3.  **深化/对峙**：冲突深化，双方亮出更多底牌，情绪在对抗中持续加码。
4.  **引爆/终结**：情绪或力量对决达到顶点，以宣言、决胜或规则破坏等形式引爆。
> *例（705章）*：围攻施压 -> 提出认主假象 -> 入洞府降低戒心 -> 突然抽魂炼傀。

**五步模板（史诗）：**
1.  **伏笔/预感**：提前铺垫不安的预感或潜在冲突点。
2.  **触发与抑制**：触发器出现，但因各种阻力（实力、规则、顾忌）被强行抑制。
3.  **阶梯式加压**：通过多次、多层面的对抗（言语、神通、道念）逐步加压，每次都将情绪推向更高点。
4.  **临界与抉择**：压力达到临界点，角色面临重大抉择（屈服/反抗、牺牲/保全）。
5.  **释放与余震**：情绪以终极形式释放，并立刻产生深远影响或留下新的悬念。
> *例（704章王平消散）*：预感死亡 -> 战后平静求证 -> 列举异常、感谢父亲、发现无泪 -> 闭眼，肉身化剑 -> 王林落泪安置，青宜追随，埋下情感债。

## D) 爆点形式库
1.  **言语宣言判决**：用最平静或最斩钉截铁的语言，宣布对方的结局或阐明不可动摇的立场。
    *   *例*：“今日，必死！”；“天若杀人，我便灭天，你若反我，我便碎逆！”
2.  **力量对轰毁灭**：将所有压抑的情绪灌注到终极神通的对撞中，以外在的毁灭性景象作为情绪能量的释放。
    *   *例*：斩罗决 vs 雷鼎；古神一指按碎肉身。
3.  **物理形态转变**：强烈的情绪通过角色“存在形式”的安静改变来具象化，如消散、化为光、变成他物。
    *   *例*：王平肉身化为剑气光团；许封寒被斩罗决斩杀后如裂纹般消散。
4.  **内心认知重构**：外部事实引发内心世界的地震，将长期疑惑、崇拜或恐惧瞬间推向全新高度。
    *   *例*：申公虎目睹王林踏雷而行，认知颠覆；周茹悟出“原来叔叔一直不想我去找他”。
5.  **规则破坏背叛**：在刚刚建立临时规则或信任后，强势方突然撕毁协议，实施物理或精神上的终极控制。
    *   *例*：王林在雷道子闭眼配合时突然用昆极鞭抽其元神。
6.  **无声威压抹除**：无需动作，仅凭目光、气息或存在本身，使对手产生被从世间抹除的恐惧感。
    *   *例*：王林悟道后的目光让黑发男子肉身有瓦解之感。
7.  **仪式化宣泄终结**：通过一个具有象征意义的仪式性行为（如血祭、跪拜、献出核心之物），完成长期压抑情绪的宣泄。
    *   *例*：李元血祭葛虹告慰族魂；申公虎献出道魂求依附。

## E) 余波与情绪债（不断供的方法）
1.  **情感托付承栽**：让爆发后存活的主要角色，承担起对逝者或离去者的情感责任（守护魂魄、完成遗愿、延续承诺），将情绪线延长。
    *   *例*：王林将王平魂魄置于天逆，承诺轮回；带走青宜之魂，许诺黄泉相伴。
2.  **盟约关系绑定**：通过建立新的主从、合作、敌对关系，并将控制物（道魂、命魂、把柄）交于一方，形成长期的情绪张力源。
    *   *例*：王林收下申公虎的道魂；抽走葛虹一魂作为“信物”。
3.  **愧疚亏欠维持**：让一方意识到自己占了便宜、有所隐瞒或利用了对方的感情，产生愧疚感，为未来关系的调整或冲突埋下伏笔。
    *   *例*：王林用有隐患的杀戮仙诀换神通后感到“占了便宜，有些过意不去”。
4.  **未解谜团悬置**：在情绪爆发后，立即引入一个新的、更具体的未解之谜，将读者的情绪从释放转为新的好奇与期待。
    *   *例*：雷鼎崩溃后，王林面临未知仙界反噬；获得老者赠与的光球，却听闻“气吹多了”。
5.  **规则后果反噬**：角色的爆发行为永久性改变了某种规则或平衡，其后果将成为长期悬于头顶的达摩克利斯之剑。
    *   *例*：破坏雷鼎导致“永恒失去一个进入名额”；吞噬仙雷可能招致仙界排斥。
6.  **牺牲代价心痛**：让角色在爆发或对抗中，永久性牺牲某样有情感联系的重要之物（法宝、分身、记忆），损失感成为持续的情绪烙印。
    *   *例*：王林为逃遁自爆禁幡（内有幡魂）；李元家族世代为奴的悲惨代价。

## F) 泄压黑名单（避免写法）
1.  **机械降神解围**：在情绪积累至关键点时，凭空插入一个毫无铺垫的强大外力（新角色、无敌法宝）瞬间解决所有冲突，导致情绪泄压无效。
2.  **对手突然降智**：为了凸显主角爆发，让前期塑造精明的对手在关键时刻做出违背其性格和利益的愚蠢选择，削弱对抗的真实性与情绪张力。
3.  **情绪无脑宣泄**：让角色陷入单一的、无止境的咆哮或哭喊，缺乏层次变化和内心挣扎的刻画，使情绪流于表面，令读者疲劳。
4.  **重复桥段疲劳**：在相近章节内，多次使用同一种情绪触发和爆发模式（如“你敢动我亲人？”->“你找死！”->爆发），缺乏新意。
5.  **逻辑硬伤破功**：情绪戏的关键情节存在明显逻辑漏洞，导致读者出戏，精心营造的情绪氛围瞬间崩塌。
6.  **旁白强行定性**：过多使用作者旁白直接告诉读者“他非常愤怒”、“她感到无比悲伤”，而非通过角色的言行、神态和环境让读者自行感受。

## G) Prompt Blocks（可直接复制）
**Block 1: “绝境威望”场景**
