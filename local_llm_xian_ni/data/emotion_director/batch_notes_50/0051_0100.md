# 第51-100章｜情绪戏套路库

## A) 触发器类型库
**1. 行为触发**
*   **公开挑衅/碾压**：如当众秒败对方代表（51章）、轻蔑点评（62章）、强索佩剑（63章）。
*   **私下胁迫**：如逼喝毒茶（52章）、以性命相威胁（76章）。
*   **反常行动**：如停止逃跑静等追兵（83章）、去而复返（89章）。
*   **信号动作**：如拿出信物（76章）、画图分界（89章）、递上承载记忆的物品（78章）。

**2. 信息宣告触发**
*   **颠覆性真相**：如宣告门派始祖全部阵亡（51章）、揭露自身真实修为（51章）、告知残酷规则（98章）。
*   **预言/威胁**：如相面指出血光之灾（74章）、以灭门相胁（63章）、下达追杀令（98章）。
*   **利诱/交易**：如提出用传送阵逃生并附赠利益（94章）。

**3. 环境/事实触发**
*   **环境异变**：如护山大阵被攻破（62、63章）、客栈异常寂静（81章）、天空凝聚黑雾棺材（92章）。
*   **物品异变**：如天逆珠子泌出液体（99章）、飞剑有灵性反抗祭炼（79章）。
*   **自身状态异变**：如修炼时能量失控（90章）、常规手段无效/濒临极限（77、80章）。

**4. 记忆/感知触发**
*   **记忆锚点**：如看到/尝到与过往强烈关联的物品（甘薯）（78章）。
*   **时间对比**：如“四年前”与“现在”的物是人非（71章）。
*   **威压感知**：如神识横扫被看透（72章）、高阶修士虚影降临（95章）。

## B) 阻力模型库
**1. 外部现实阻力**
*   **实力碾压**：对方境界或力量绝对高于己方，反抗即死（63章朴南子、62章护山大阵被破）。
*   **制度/规则压制**：必须遵守更高权威定下的残酷规则，无法违抗（96章尸阴宗制度、98章联盟规则）。
*   **环境限制**：身处敌营或密闭空间，行动受监视，无法自由行动（95、99章）。
*   **第三方威胁**：有更强大的敌人在旁窥伺或即将到来，不敢轻举妄动（76章师尊在场）。

**2. 内部心理/认知阻力**
*   **信息差与未知恐惧**：不完全了解对手、环境或现象，不敢贸然行动（74章血光之灾不明、88章怪人未知、81章摸不着头绪）。
*   **责任与私心的冲突**：作为领袖需要在保护同伴/集体与自身求生欲间挣扎（72章历海）。
*   **谨慎多疑的天性**：对任何信息都进行逻辑拷问，难以建立信任（93、94章王林对吴宇）。
*   **情感隔阂与试探**：久别重逢或关系复杂，存在疏离感，需要缓冲（64章父母、78章张虎）。

**3. 过程/条件阻力**
*   **资源消耗极限**：灵力、神识、底牌使用次数即将耗尽，无力持续（81、82章王林逃亡）。
*   **功法/仪式的客观难度**：修炼过程痛苦漫长，或祭炼法宝异常艰难（80、87章）。
*   **沟通障碍**：语言不通，意图难以直接传达（88、89章与怪人）。

## C) 升级台阶模板库
**三步台阶（最常用）**
1.  **挑衅/试探 → 压制/展示 → 逼问/抉择**
    *   *范例（51章）*：公开挑衅 → 轻松击败代表 → 冷眼逼问谁还敢上。
2.  **观察/预警 → 接触/对抗 → 爆发/反转**
    *   *范例（88章）*：野兽尸体失踪（预警） → 布饵观察，怪人现身 → 战斗爆发，怪人展现诡异能力。
3.  **否定/压抑 → 反抗/代价 → 哀求/决断**
    *   *范例（76章）*：张虎口头否认 → 师尊要杀人，张虎求情遭禁制反噬 → 王林出手救人。

**四步台阶**
1.  **发现异常 → 逐步验证 → 遭遇阻碍 → 决绝突破**
    *   *范例（99章）*：发现珠子泌液 → 反复试验确认 → 试探出路发现被严密封锁 → 凝聚神识冲击“门”后景象。
2.  **建立表面和谐 → 内部怀疑滋生 → 外部危机介入 → 彻底摊牌**
    *   *范例（95章）*：冒充身份获初步接纳 → 长老言语试探 → 宗主威压虚影降临 → 面临直接质询。

**五步台阶（用于复杂对峙或渐进绝望）**
1.  **预警降临 → 初步抵抗 → 希望破灭 → 全面压制 → 精神摧毁**
    *   *范例（62-63章）*：朴南子降临 → 大阵首次抵挡 → 长老重伤，防线被破 → 宣告始祖死讯，强索山门 → 嘲讽“借十万年”，集体沉默。

## D) 爆点形式库
**1. 言语羞辱/宣告类**
*   **极致嘲讽**：用一句话彻底碾碎对方所有幻想和尊严（“借？行，借我玄道宗十万年吧。” - 63章）。
*   **夺宝宣言**：在追杀中公开宣称要夺取对方宝物，将冲突复杂化（“这宝贝，归我了！” - 81章）。
*   **真相补刀**：在胜利离场时，抛出比胜利本身更致命的真相（“所有元婴始祖，全部阵亡！” - 51章）。

**2. 物理/法术行动类**
*   **果断击杀**：情绪累积到顶点的瞬间，干脆利落的下杀手（一掌拍死师父 - 52章）。
*   **残酷炼化**：展示一个漫长而痛苦的毁灭过程（抽魂炼魄 - 85章）。
*   **陷阱触发**：精心布置的陷阱生效，猎物落入圈套（蓝线藤暴起 - 82章）。
*   **赌命对决**：双方攻击同步发出，看谁先倒下的瞬间（飞剑穿心 vs 巨剑临头 - 84章）。

**3. 环境/规则引爆类**
*   **规则施压**：宣布一条无法反抗的、株连广泛的残酷规则（“所在修真国屠杀一净” - 98章）。
*   **能力揭露**：对手展现出完全打破常规认知的诡异能力（怪人撕下黄纸，伤势瞬间痊愈 - 88章）。
*   **异象降临**：环境剧变，标志更高层次威胁介入（黑雾成棺，虚影浮现 - 92章）。

**4. 情感/认知反转类**
*   **卑微哀求**：此前姿态甚高者，在绝境中放下一切尊严恳求（“老夫恳求小友，帮帮我……” - 93章）。
*   **无声决断**：在漫长心理博弈后，用简单的动作代替语言（“点了点头”，冲入传送阵 - 94章）。
*   **平静释放**：经历巨大痛苦后，以微小的成功标志作为爆点（一声剑鸣，面带微笑 - 80章）。

## E) 余波与情绪债（不断供的方法）
**1. 当下余波写法**
*   **集体沉默**：在极致冲突后，描写死寂般的沉默，体现精神溃败（63章）。
*   **人心离散**：危机中描写个体开始为自己打算，体现组织凝聚力崩溃（63章）。
*   **冷静复盘**：爆发后不让角色沉浸情绪，立刻转入得失分析与后续计划（90章）。
*   **悬置决策**：在对方哀求或抛出关键选择时，以主角的沉默收尾，让压力延续（93章）。

**2. 埋设情绪债的方法**
*   **设置明确的反向目标**：让反派在失败/死亡时立下明确的诅咒或誓言（“藤化元终有一日会找到你” - 85章），成为长期悬念。
*   **成功即负债**：让主角达成目标的瞬间，立刻揭示该方法附带的严重副作用或引发的新问题（血炼飞剑后的血腥隐患 - 80章）。
*   **体系化恐惧**：构建一个无法反抗的残酷制度（如抽魂炼傀），让角色即便暂时安全，也身处无形的压力系统中（96章）。
*   **平行威胁铺垫**：在主线情绪戏收尾时，平行切入其他威胁方的动态，制造“风暴即将来临”的预感（90章藤化元寻仇）。
*   **悬置核心秘密**：让角色发现一个巨大的秘密或宝藏，但因风险暂时无法获取，将“渴望与恐惧”的矛盾留作长期动力（100章地底紫青植物）。

**3. 情绪债“不断供”公式**
> **“负面标记/诅咒 → 转化为动力或新危机 → 在后续情节中定时‘追债’”**
> *   *范例*：王林被种下诅咒（标记）→ 司徒南提出可反向利用（转化契机）→ 未来藤化元必将循迹追来（追债事件）。确保每个重大情绪冲突留下的“债”，都在后续有明确的兑现或演化节点。

## F) 泄压黑名单（避免写法）
1.  **过早让主角宣泄**：在情绪阻力未充分构建、压力未累积到顶点时，就让主角轻易爆发或反杀，削弱张力。
2.  **反派死于话多**：在占据绝对优势时，反派突然开始长篇大论地解释计划，给主角制造翻盘机会，显得降智。
3.  **用直白呐喊代替细腻刻画**：让角色用“我好恨啊！”“我好绝望！”等直接喊出情绪，而非通过动作、神态、生理反应等侧面烘托。
4.  **情绪断崖式下跌**：爆点之后，情绪没有任何余波和沉淀，立刻跳到完全无关的轻松日常，切断情绪连贯性。
5.  **旁观者过度煽情**：通过大量配角的夸张反应（如“所有人都哭了”、“天地为之变色”）来烘托情绪，显得虚假和用力过猛。
6.  **忽略阻力逻辑**：为了让情绪升级，强行让角色做出不符合其性格（如极度谨慎者突然鲁莽）或无视客观条件（如实力悬殊却硬拼）的行为。
7.  **重复使用单一爆点**：连续多场情绪戏都采用同一种爆发形式（如总是大吼一声爆发小宇宙），导致读者疲劳。

## G) Prompt Blocks（可直接复制）
