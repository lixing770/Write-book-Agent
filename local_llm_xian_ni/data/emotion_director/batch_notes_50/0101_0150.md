# 第101-150章｜情绪戏套路库

## A) 触发器类型库
*   **1. 危机宣告型**: 用言语或行为直接宣告对角色核心利益的威胁或毁灭。
    *   *案例*: “今日此地，鸡犬不留！”(103章)；“我就灭他全族！”(104章)；尸阴宗捏碎玉简启动尸变(102章)。
    *   *情绪*: 绝望、恐惧、仇恨聚焦。
*   **2. 力量展示/身份揭露型**: 通过展示颠覆性的实力或揭露隐藏身份，瞬间改变权力关系和角色认知。
    *   *案例*: 王林当众修为攀升至元婴中期(115章)；王林（马良）瞬杀七人引爆全场震惊(138章)；徐思听到“马良”二字瞬间暴怒(136章)。
    *   *情绪*: 震惊、敬畏、恐惧、认知颠覆。
*   **3. 至亲/核心受虐型**: 让角色目睹或感知其至亲、核心信念、珍贵物品被伤害或掠夺。
    *   *案例*: 藤化元在王浩面前捏碎其父母头颅(104章)；王林在魂群中看到父亲痛苦的脸(117章)；王林要求李慕婉交出魂血(141章)。
    *   *情绪*: 极致的悲痛、愤怒、无力、崩溃。
*   **4. 预期反转型**: 角色行为与对方或自身长期预期形成剧烈反差，打破固有认知。
    *   *案例*: 王林主动熟练交出魂魄，让夜自在一怔(101章)；王林彻底无视长期纠缠他的徐思(127章)；周紫虹提出“帮我杀两个人”作为帮忙条件(140章)。
    *   *情绪*: 困惑、茫然、心理落差、警惕。
*   **5. 环境突变/诡异发现型**: 通过环境剧变或发现异常现象，营造未知的恐惧与压力。
    *   *案例*: 天空突现古镜与藤化元(103章)；在岩浆中看到“三角形的眼睛”(132章)；火焚国官道遍地尸体(133章)。
    *   *情绪*: 惊骇、不安、危机感、悬疑。
*   **6. 信息差引爆型**: 一方掌握关键信息，在临界点揭露，将暗流涌动的诡异感转化为明确危机。
    *   *案例*: 合欢宗女弟子崩溃式交代“三个名额”的残酷规则(109章)；司徒南告知“魂魄未散，可复活”(106章)；凤栾收徒前，众人皆以为王林必死(136章)。
    *   *情绪*: 恍然大悟、希望/绝望的转折、压力释放。

## B) 阻力模型库
*   **1. 生存本能力 (实力/生命威胁)**： 绝对的实力差距使任何直接的情绪爆发（如反抗、质问）都等同于自杀。
    *   *案例*: 王林面对夜自在(101章)、藤化元(103章)时的隐忍。
*   **2. 规则庇护力 (场合/身份约束)**： 公开场合、上位者在场、宗门规则等，迫使角色维持表面姿态，抑制情绪外露。
    *   *案例*: 辛海在众门派前强忍怒火(113章)；周瑾顾忌凤栾道侣而不敢强行动手(136章)。
*   **3. 信息迷雾力 (未知/疑惑)**： 对事件真相、对方意图、自身处境不了解，导致情绪无法找到明确目标和宣泄口。
    *   *案例*: 王家众人不知为何遭屠杀(104章)；藤化元因飘渺、合欢宗的诡异态度而疑窦丛生(114章)。
*   **4. 目标优先力 (更高优先级任务)**： 有更紧迫、更重要的目标（如抢回魂魄、完成实验、安全撤离），必须暂时压抑当下情绪。
    *   *案例*: 王林先抢玉简再观察尸变(102章)；为结丹而压下对李慕婉的杀意(148章)。
*   **5. 情感羁绊力 (愧疚/承诺/旧情)**： 因对他人怀有愧疚、受承诺约束或存有旧情，无法做出最直接的情绪反应。
    *   *案例*: 徐思对欺骗“马良”赴死有愧，无法立刻质问(127章)；王林因承诺而保护李慕婉(148章)。
*   **6. 认知惯性力 (固有印象)**： 长期形成的对某人/某事的刻板印象，阻碍了对当前异常情况的即时理解和情绪调整。
    *   *案例*: 战神殿众人无法接受“胆小马良”变得强大冷酷(122、126章)。

## C) 升级台阶模板库
*   **【3步模板】常规观察-蓄力-爆发**
    1.  **观察/试探**：主角或冲突一方通过言行进行初步接触或信息收集，情绪开始酝酿。
    2.  **对抗/施压**：冲突升级，出现直接对抗行为（攻击、威胁、惩罚），情绪张力拉高。
    3.  **爆发/逆转**：在压力临界点，通过实力展示、关键抉择或真相揭露完成情绪释放或局势逆转。
    *   *案例*: 王林vs尸阴宗弟子(128章)：喝止威胁 -> 放出尸傀围攻 -> 神识秒杀。
*   **【4步模板】日常-异变-加压-聚焦**
    1.  **平凡日常**：描绘温馨或平凡的日常，建立情感基础。
    2.  **危机降临**：外部威胁突然出现，打破日常，引发恐慌。
    3.  **逐步施虐**：威胁方通过具体行动（如杀人、毁物）逐步加剧受害方的痛苦与绝望。
    4.  **仇恨聚焦**：揭示悲剧根源，将弥漫的绝望情绪聚焦到一个具体对象或名字上。
    *   *案例*: 王家灭门(103-104章)：送酸梅汤 -> 古镜降临 -> 杀伙计、虐杀父母 -> “因王林杀人而灭族”。
*   **【5步模板】压抑-探索-受挫-决断-蜕变**
    1.  **情绪低谷/目标确立**：角色处于巨大悲痛或明确困境中，确立一个遥远目标。
    2.  **尝试与探索**：角色开始尝试各种方法解决问题或提升实力，过程艰难。
    3.  **重大受挫/认知颠覆**：遭遇意外失败或得知残酷真相，情绪受挫，认知被刷新。
    4.  **关键决断/内心宣言**：在绝境中做出极端抉择或形成坚定信念，完成情绪转化。
    5.  **行动与蜕变**：将决断付诸行动，并伴随能力的实质性蜕变或突破。
    *   *案例*: 王林复仇心路(112章)：回忆司徒南警告 -> 思考修真界法则 -> 关联自身惨痛 -> “只有成为强者” -> 开始修炼。

## D) 爆点形式库
*   **1. 行动碾压型**: 用简洁、冷酷、超越认知的暴力行为瞬间终结冲突，实现地位反转。
    *   *形式*: 秒杀、瞬移反杀、神识抹除。
    *   *案例*: 王林飞剑瞬杀华服青年(102章)；极境神识冰封无锋谷全队(109章)。
*   **2. 言语定调型**: 在充分铺垫后，用一句简短、冰冷、充满权威的宣言或威胁，完成情绪定调和权力确认。
    *   *形式*: 死亡通牒、身份宣告、规则定义。
    *   *案例*: “否则的话，死。”(108章)；“从这一刻起，王某将是元婴期下第一人。”(149章)。
*   **3. 沉默施压型**: 非外放的情绪宣泄，而是通过凝视、沉默、气势压迫等静态方式，达到情绪爆发的效果。
    *   *形式*: 冰冷凝视、威压笼罩、长时间沉默。
    *   *案例*: 王林因一丝杀气转身凝视魔道弟子(105章)；王林（马良）现身时的灵魂威压(126章)。
*   **4. 认知颠覆型**: 通过揭露真相、展示颠覆性事实（如真实修为），瞬间粉碎所有旁观者乃至对手的原有认知。
    *   *形式*: 修为暴涨、身份揭晓、王牌失效。
    *   *案例*: 王林修为攀升至元婴中期(115章)；幻象巨龙被穿透，揭示其为假(116章)。
*   **5. 内心决堤型**: 在外部压力或内部情感积累到极致后，角色内心世界的崩溃、领悟或最终决断。
    *   *形式*: 血泪、惨笑独白、顿悟式宣言。
    *   *案例*: “修仙，原来这就是修仙……”(117章)；“脑子一片空白”(127章徐思)。
*   **6. 环境共鸣型**: 个人的情绪爆发与宏大的环境异变或群体事件同步发生，互相烘托。
    *   *形式*: 天地异象中完成反杀、仪式进行时爆发冲突。
    *   *案例*: 域外战场开启仪式中，王林与藤化元对峙(115章)；火焚国开启锁国大阵后，集体转向侵略(137章)。

## E) 余波与情绪债（不断供的方法）
1.  **债主标记法**: 在被迫承受损失时，清晰标记施加者或关键物品持有者。
    *   *公式*: [主角] 记住了/看向了/感知到了 [施加者/物品]。
    *   *案例*: 王林记住谁持其魂魄玉简(101章)；王林盯住藤化元，血仇锁定(117章)。
2.  **承诺悬置法**: 做出一个关于未来的、重要的承诺，但暂不兑现，使其成为牵引情绪的钩子。
    *   *公式*: “待我[达成条件]之日，便是你[获得回报/获得自由]之时。”
    *   *案例*: “我结丹之日，定是送你回洛河门之时！”(144章)。
3.  **痛苦链接法**: 将抽象的世界规则或宏大危机，与角色最私人的痛苦记忆直接关联，使仇恨或动力个人化、深刻化。
    *   *公式*: [宏观规则/危机] -> 这正是导致我[个人惨剧]的原因 -> 因此我必须[采取行动]。
    *   *案例*: 修真界弱肉强食 -> 父母因我弱小被杀 -> 我必须成为强者(112章)。
4.  **资源/能力代价法**: 让角色获得强大能力或资源时，明确其代价、限制或隐患，使“力量”本身成为未来的情绪压力源。
