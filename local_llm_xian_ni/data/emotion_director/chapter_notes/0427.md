# 第427章｜情绪戏学习笔记（导演视角）
## 0) 情绪场景定位（剧情1-2句）
仙遗族四祖主持北部轮回树召唤，司徒南暗中吞噬其祖灵之种后，四祖发现并展开疯狂追击。
## 1) 情绪目标（谁想让谁产生什么感受）
- 角色A（司徒南）：想让四祖产生极致的愤怒与无力感。
- 角色B（四祖）：想让司徒南产生恐惧并被杀死，以泄心头之恨。
## 2) 情绪触发器（触发变化的具体点）
- 触发点：司徒南吞噬祖灵之种，导致轮回树崩溃。
- 触发形式：行为 / 结果事实
## 3) 情绪阻力（为什么不能立刻爆）
- 阻力1：四祖最初并未察觉司徒南的存在，需要一个发现的过程（原文：司徒南寄生在内，其内主持此处的仙遗族四祖，也丝毫不知）。
- 阻力2：仙遗族四祖作为老祖，本应沉着冷静，需要一个使其崩溃的强烈刺激点。
## 4) 情绪升级台阶（至少3步）
1) 手段：司徒南悄然吞噬祖灵之种，导致轮回树消散。
   结果：四祖及所有族人“震惊”，这是情绪冲击的起点。
2) 手段：四祖不惜牺牲符文，以秘术终于看到司徒南。
   结果：锁定目标，情绪从“震惊”转为具体的“愤怒”。
3) 手段：司徒南对四祖进行言语羞辱与嘲笑（“真他娘的难吃”）。
   结果：四祖情绪被彻底点燃，达到“愤怒之下，不惜牺牲符文”、“双目通红，几欲滴血”的暴怒状态。
## 5) 爆点（爆发的形式与落点）
- 爆点发生处：司徒南嘲笑之后，四祖的反应。
- 爆点形式：咆哮“我要杀了你！！！”。
- 爆点为何有效：①前置的情绪台阶已将愤怒值拉满；②祖灵的珍贵性被点明（数万年五个，关乎十叶术师），其价值与毁灭结果形成巨大反差；③司徒南轻佻的态度与极端重要的损失形成对比，侮辱性极强。
## 6) 情绪余波（爆后走向）
- 当下余波：四祖丧失理智，铁了心一般疯狂追击司徒南，誓言杀人。
- 埋下的后续情绪债：①司徒南计划未来有了肉身要“把这疯狗小娃娃给煮了”并吞噬，仇恨升级。②四祖的恨意“笔墨无法形容”，这成为他后续行动的核心驱动力。
## 7) 可复用“情绪戏配方”（3-7条）
1. **“珍贵之物当面毁”配方**：设置一个对角色而言价值连城、意义非凡的宝物或目标（如祖灵），然后让对手当面、轻易地摧毁/夺取它，这是触发顶级愤怒的强效触发器。
2. **“羞辱性补刀”配方**：在造成实质性伤害后，施加轻蔑的言语或行为嘲讽（如“真难吃”），能将被伤害者的情绪从“受损的愤怒”推向“被侮辱的暴怒”。
3. **“理智剥离”三部曲**：震惊（事件发生） -> 确认并锁定（发现罪魁祸首） -> 被激怒（受到挑衅），三步完成角色从冷静到完全情绪化的转变。
4. **“恨意具象化”**：用“双目通红，几欲滴血”、“咆哮”、“撕心裂肺”等生理与行为描写，将抽象的恨意转化为可感的、强烈的角色状态。
## 8) 短引用/句式样本（最多3条，<=20字）
- 咆哮一声，立刻冲出，紧追不舍。
- 我要杀了你！！！
- 恨意，笔墨无法形容。
