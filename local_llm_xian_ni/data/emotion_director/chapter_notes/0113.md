# 第113章｜情绪戏学习笔记（导演视角）
## 0) 情绪场景定位（剧情1-2句）
域外战场资格赛结束，飘渺宗仅存八名弟子走出决明谷，面对始祖辛海与其他门派修士。
## 1) 情绪目标（谁想让谁产生什么感受）
- 角色A：辛海。想让魔道仇敌（尤其是藤化元）感受到他的愤怒与威慑，并想压制门下弟子的恐惧与羞愧。
- 角色B：飘渺宗弟子。想让始祖辛海理解他们的惨痛经历与恐惧，并寻求庇护。
## 2) 情绪触发器（触发变化的具体点）
- 触发点：弟子汇报“全死了……除了我们之外，其他弟子全都死了。”
- 触发形式：对话 / 行为（下跪汇报）
## 3) 情绪阻力（为什么不能立刻爆）
- 阻力1：公开场合。辛海作为一派始祖，在众多其他门派（尤其是有对头上官云）面前，需维持威严与克制。
- 阻力2：信息不明。辛海起初不知凶手是谁，怒气需要定向，无法立刻转化为具体行动。
## 4) 情绪升级台阶（至少3步）
1) 手段：辛海强忍怒火，先应付上官云的讽刺，再沉声询问弟子大师兄下落。
   结果：愤怒被暂时压抑，但已开始酝酿，并引导至核心问题（伤亡）。
2) 手段：弟子集体下跪，恐惧地汇报“全死了”。
   结果：辛海的怒火从对结果的不满，升级为对惨重损失的心痛与对外部威胁的怒意。
3) 手段：辛海布下光幕私下询问细节，得知真相。
   结果：愤怒找到明确目标（凶手），情绪从内部的压抑与痛苦，转化为对外的冰冷杀意与公开对峙的决心。
## 5) 爆点（爆发的形式与落点）
- 爆点发生处：辛海得知真相后，在撤去光幕的公开场合说“我倒要看看，他到底是何方神圣。”
- 爆点形式：冷冽的宣言。非情绪化的爆发，而是将汹涌的怒意转化为明确、公开的敌意与行动预告。
- 爆点为何有效：此前所有的压抑、询问、私密沟通都在为此蓄力。这句宣言将个人怒火上升为门派公开的对抗姿态，在众目睽睽下完成情绪从内到外的转折。
## 6) 情绪余波（爆后走向）
- 当下余波：辛海让弟子站到身后，形成庇护与同仇敌忾的姿态。光幕撤去，准备应对后续。
- 埋下的后续情绪债：辛海与魔道（尤其是藤化元）之间的敌对情绪公开化，为后续冲突埋下伏笔。飘渺宗弟子劫后余生的恐惧暂时被始祖的庇护承接，但转化为对未来的不安。
## 7) 可复用“情绪戏配方”（3-7条）
1. **“强忍-探问-定向”怒气三段式**：角色在公开场合强压怒火 -> 私下或直接追问关键信息 -> 获得信息后将怒火转化为对特定目标的行动宣言。
2. **公开场合的克制与暗涌**：利用旁观者（如上官云）的讽刺或观察，反衬核心角色内心情绪的剧烈波动与表面的强行克制。
3. **群体行为强化情绪冲击**：通过“集体下跪”等一致性行为，将个人的恐惧、羞愧放大为群体的情绪状态，增强对质询者的冲击力。
4. **情绪屏障（光幕）**：用物理或法术手段制造私密空间进行关键对话，既符合逻辑（防窥听），又象征情绪从公开压抑到私下释放的过渡阶段。
5. **从数字到具体的情绪催化**：从得知“损失惨重”的抽象愤怒，到明确“谁杀的”的具体仇恨，引导情绪完成从弥漫到聚焦的升级。

- 其中一人，噗通一声跪在地上
- 辛海面沉如水，冷笑道
