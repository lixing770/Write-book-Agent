# 仙逆 401-500｜情绪戏方法论总纲

## 1) 触发器谱系
**【核心逻辑】将外部事件转化为内部情绪风暴的导火索，按冲击维度分类。**
*  **生存/尊严压榨型**：针对角色的生存底线或人格尊严进行极限施压。包括：①**被逼入绝境**（常规手段耗尽）；②**珍视之物/人被当面毁伤或侮辱**；③**身份符号挑衅/确认**（辱骂称谓、篡改符号）。
*  **认知/信任撕裂型**：颠覆角色对世界或人际关系的根本认知。包括：①**身份/真相被揭露**；②**被信任者背叛或伤害**；③**颠覆认知的规则信息**（如修星之晶）；④**关键物品/信息揭示**（关联核心情感或阴谋）。
*  **情感/道义绑架型**：利用角色内心的情感或道义责任感制造两难。包括：①**以爱为名的残酷牺牲**（至亲主动牺牲）；②**权威的直接施压/命令**；③**情感与理性的撕扯**（内心矛盾行动受阻）。
*  **环境/规则强制型**：外部环境或既定规则强行推动冲突。包括：①**无法回避的仪式对决**；②**规则性门槛/检验**；③**环境/局势的毁灭性突变**（空间崩溃等）；④**异常感知与呼唤**（心神感应触发行动）。
*  **沧桑/宿命回响型**：触发对时间、命运和过往的深刻情绪。包括：①**故地重游物是人非**；②**故人（意外）现身**。

## 2) 阻力模型
**【核心逻辑】阻碍情绪简单宣泄，迫使其在压制中积蓄、扭曲、升级。**
1.  **不可抗力型壁垒**
    *   **绝对力量差距/鸿沟**：敌我实力存在客观、难以逾越的层级差，使任何正面对抗都显得徒劳。
    *   **物理/环境禁锢**：被法术、宝物或险地完全或部分限制自由，处于“目睹却无法干预”的被动状态。
    *   **环境与规则的双重束缚**：公开场合礼仪、师门规矩与特定规则（如困阵）共同构成行动牢笼。
2.  **内心困境型泥沼**
    *   **内部道德/情感困境**：面临无法两全的选择（保A或保B），任何行动都伴随痛苦与愧疚。
    *   **情感依赖与亏欠**：因恩情、依赖或亏欠感，难以对另一方采取强硬或决绝态度。
    *   **底牌与代价的权衡**：拥有强力底牌但使用代价巨大（消耗本源、暴露秘密），在危机中反复权衡。
3.  **信息与规则型迷雾**
    *   **信息迷雾与认知差**：对对手的真实意图、实力或环境机制不了解，情绪在试探与猜疑中累积。
    *   **信任缺失与信息迷雾**：对动机充满怀疑，或信息被隐瞒扭曲，导致无法直接引爆冲突。
    *   **规则/身份压制**：受限于更高规则（天道）、宗门传统或身份尊卑，不能随心所欲行动。

## 3) 升级台阶模板（可复制）
**【核心逻辑】提供标准化的情绪推进阶梯，确保张力稳步提升至爆点。**
*  **三步台阶（基础型）**
    *  **阻-试-破**：目标受阻（阻） -> 尝试破局（试） -> 破局或反制（破）。适用于由外部危机驱动的快速冲突。
    *  **蓄-击-落**：静静积蓄情感（蓄） -> 外部/内部沉重一击（击） -> 情绪向内坍缩或哲思沉淀（落）。适用于需要深厚情感铺垫的悲怆戏。
    *  **警觉-确认-决断**：发现异常（警觉） -> 确认关联核心目标（确认） -> 情感压倒理性做出决断（决断）。适用于由感知和情感呼唤触发的行动。
*  **四步台阶（标准型）**
    *  **压-挑-反-碾**：反派初始压迫（压） -> 言语挑衅侮辱（挑） -> 主角非常规反击（反） -> 主角展示实力实现碾压（碾）。适用于打脸与复仇戏码。
    *  **忍让-试探-反抗-宣言**：因故退让（忍让） -> 对方得寸进尺后试探（试探） -> 忍无可忍武力反抗（反抗） -> 宣告立场与未来姿态（宣言）。适用于主角从隐忍到爆发的身份转变。
*  **五步台阶（史诗型）**
    *  **压-挑-反-碾-裁**：在“压挑反碾”基础上，增加**裁决与羞辱（裁）**，或将情绪债务具体化转移。适用于需要彻底终结并留下深刻印记的终极冲突。
    *  **觉察-阻拦-确认-爆发-清扫**：感知危险（觉察） -> 遭遇直接阻拦（阻拦） -> 确认情感关联（确认） -> 情感决绝爆发（爆发） -> 雷霆手段清除障碍（清扫）。适用于目标明确、障碍清晰的情感驱动型突击。

## 4) 爆点形式与适配条件
**【核心逻辑】根据冲突性质与积累的情绪类型，选择最适配的爆点释放方式。**
| 爆点形式 | 核心特征 | 适配条件（情绪/冲突类型） |
| :--- | :--- | :--- |
| **力量/规则碾压** | 以绝对实力或高阶规则瞬间粉碎对方所有希望。 | 绝对力量差距模型；复仇、示威；需要展现实力统治感时。 |
| **道心/意境冲击** | 在精神、理念层面给予致命一击，动摇修行根基。 | 理念之争、道心对决；对手的执念是其最大弱点时。 |
| **真相/身份揭露** | 揭露隐藏身份、关系或阴谋，引发角色与读者双重震撼。 | 信息迷雾模型；认知撕裂型触发器；需要剧情重大转折时。 |
| **宣言式抉择** | 以简短、有力的内心独白或对话，宣告道路与决心。 | 角色完成重大心态转变；长期压抑后决定不再隐忍；需要金句凝华情绪时。 |
| **行动宣言爆点** | 用标志心态彻底转变的宣言，替代激烈肢体冲突，作为高潮。 | 同“宣言式抉择”，更侧重于用宣言本身作为爆点动作。 |
| **牺牲与温柔的刀** | 至爱角色出于善意的主动牺牲，在成功前给予最温柔的致命一击。 | 情感绑架型触发器；需要制造极致悲怆与无力感时。 |
| **确认式爆点** | 身份、情感关联被点明的瞬间，通常伴随简短名称呼喊。 | 异常感知、故人现身等触发器；情感积累至临界点只需一个确认时。 |
| **环境降维爆点** | 用远超角色层级的毁灭性环境剧变或力量介入，打破僵局。 | 局势陷入死局；需要引入更高维度变量制造绝望或转机时。 |
| **无声/静态崩溃** | 通过细微动作、静止画面或强颜欢笑表现彻底崩溃。 | 情绪积累到极点却无法或不愿嚎啕时；需要营造巨大悲伤留白时。 |
| **冷静施令** | 在对手最疯狂时，以极致平静和简短指令完成终结。 | 主角实力碾压且心态冷酷；需要制造强烈情绪对比与压迫感时。 |
| **仪式完成爆点** | 通过完成具有象征意义的仪式（跪拜、改名），将情绪具象化释放。 | 承诺兑现、身份更迭、重大决定落地时。 |

## 5) 余波与情绪债：不断供公式
**【核心逻辑】爆点后不让情绪冷却，而是将其转化为驱动后续剧情的新燃料。**
1.  **涟漪扩散公式：【A -> B -> C】**
    *  **A（直接结果）** -> **B（连锁反应）** -> **C（未来压力）**。例：击败仇敌（A）-> 引发其背后势力震怒、恩师坐化（B）-> 主角继承新责任、立下更远大誓言（C）。
2.  **情感物质化公式：【强烈情感 + 具体物品 = 情绪债载体】**
    *   将情感或执念寄托于具体物品（木雕、魂幡、铁剑），使其成为未来触发情节与情绪的关键信物。
3.  **债务转移公式：【割舍A + 转移至B = 复合情绪债】**
    *   当旧情感联结（A）被迫割舍时，将情感与愧疚部分转移到新目标（B）上，形成更复杂、强烈的驱动力。
4.  **执念锚定公式：【创伤事件 + 偏执解读 = 长期执念】**
    *   在重大创伤后，让角色对事件进行偏执解读，形成长期追求或仇恨，成为核心人物驱动力。
5.  **压力制度化公式：【一次性冲突 + 规则设定 = 持续压力】**
    *   将冲突通过世界观规则（如命魂被控）固化为长期存在的潜在威胁，使压力如影随形。
6.  **动能即时转化法**：
    *   爆点释放后，**立即**将释放的能量导向新目标（如击杀后立刻被更强对手追杀），杜绝情绪松弛。
7.  **旁观者反应链**：
    *   通过描写不同旁观者（同门、宾客、灵兽）的复杂反应（震惊、敬畏、算计），将单一爆点的影响涟漪化、社会化，延续情绪场。
8.  **代价显现法**：
    *   在胜利或获得后，**立刻**展现此举带来的副作用、消耗或潜在危机，将喜悦迅速转化为新的紧张感。

## 6) 泄压黑名单
**【核心逻辑】坚决避免这些会稀释情绪张力、破坏真实感的写法。**
1.  **反派降智话多**：在关键对峙时，让反派犯低级错误或突然解释阴谋，为主角创造不合理机会。
2.  **情绪无代价**：重大情感爆发（疯狂、崩溃）后，角色立刻恢复如初，且对心性、修为、人际关系无任何实质影响。
3.  **外力解困境**：当陷入精心构建的两难伦理困境时，引入突兀的外部力量或巧合替主角做出选择，使前期积累廉价化。
4.  **表白说教解心结**：用冗长、直白的内心独白或对话来解释情感、忏悔过错，试图直接说服读者，而非通过行动呈现。
5.  **时间淡化一切**：用“若干年后”简单跳过复杂情感的处理期，让尖锐矛盾自然“愈合”，缺乏过程。
6.  **爆点后真空**：情绪高潮后，场景立刻松弛、切换，缺乏必要的余波描写和情绪债的结转，导致节奏断裂。

## 7) Prompt Blocks（弱/中/强）
**【核心逻辑】提供不同强度、即取即用的情绪戏构造指令。**
*  **弱强度（一步台阶 | 单点触发）**
    *  **【Prompt】**：描写角色在**故地重游**时，发现一处**彻底改变或完全消失**的旧景（如一棵树、一座亭）。要求不直接抒情，而是通过一个**他下意识寻找此物的动作**，以及找到后**片刻的静止**，来传递物是人非的冲击。
*  **中强度（三步台阶 | 冲突升级）**
    *  **【Prompt】**：设计一场 **“规则性门槛”** 冲突。反派（或考官）提出一个看似公平的考验（如“接我一招不退”）。主角**第一次尝试失败（阻）**，反派出言羞辱其珍视之人或信念（**挑**）。主角**第二次尝试**，不再格挡，而是用超出对方理解的方式（如意境、特殊体质）**直面并吸收/化解攻击（反）**，最后以**平静但颠覆规则认知的一句话**作为收尾（例：“你的道，仅此而已？”）。
*  **高强度（五步台阶 | 终极对决）**
    *  **【Prompt】**：构建一场
